# Kivo 0.3.0

Windows本地知识驱动创作工作台，原项目Easel的增量版本。

- Windows x64安装包，自带桌面/Python核心运行环境，114个原技能保留。
- 内置当前可移植知识副本；知识、内容、账号配置、学习与反馈记录保存在本机。API Key与登录态不在安装包中。
- 手动知识、确认后直接使用、数据反馈自动记忆/去重/账号隔离/停用与复测候选。
- 通用API独立运行，无需Codex/OpenClaw等AI客户端；原客户端接入仍可选。
- 配置保存/连接自测的成功、失败、未保存和失败原因有明确提示；编辑后可一键保存并自测。
- 桌面菜单检查GitHub更新，确认后下载/重启，保留用户知识和内容，知识冲突另存。

本地验证：314项后端测试通过、8跳过；80项前端测试、6项配置提醒浏览器检查、5项安装升级/数据保护测试通过。已运行打包后程序，确认本地服务、114技能与受限桌面桥接。没有据此声称所有真实平台登录、媒体服务或营销效果通过。

初次启动准备本地运行环境和知识副本可能需要1—2分钟。请在设置填写自己的模型API地址、Key和模型；完整工具流程需要模型支持工具调用。连接自测检查模型列表接口，具体模型需真实任务验证。云端API会收到您主动发送的任务资料及相关检索片段，完全不出本机请使用本地模型服务。

初版未配置商业代码签名，Windows可能显示未知发布者。只从本仓库下载；默认升级源为本仓库Releases。原作者和第三方许可证继续适用，详见项目说明。
