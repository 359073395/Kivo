# Kivo 0.3.1 · Windows 启动兼容修复

Windows x64 桌面安装版，内置可移植知识副本；保留原114技能、账号、画像、素材、内容库、日历和发布入口。知识检索、手动学习、数据反馈和通用API独立执行均保留。

- 修复实际安装包缺少非x64辅助文件导致的启动失败。
- 修复AppData重定向环境中EXDEV重命名失败，增加校验复制与回退。
- 运行环境在安装目录校验后直接使用；本机存在正式知识库时不再复制一份用不到的副本。
- 补齐扫码识别和原公众号配置的基础依赖。
- 新名称/图标、配置成功/失败/未保存提示、“保存并自测”、确认后检查下载升级。

本机Windows全量后端1429项通过、99项平台/环境跳过；80项前端、6项配置提示浏览器检查、7项桌面数据保护测试通过。发布代码云端15个检查job通过，完整重媒体安装按设计跳过。实际覆盖安装、真实AppData路径、内置知识副本和子进程导入均已通过；安装后的在线检查返回当前最新版0.3.1。没有模拟更高版本在线安装，也不把模拟API测试、代码存在或未登录账号当作真实业务验收。

默认数据位于本机 `%APPDATA%\kivo-desktop`，以菜单“打开数据文件夹”为准；正式知识库存在时优先读取，否则初始化本地可编辑副本。内容在 `platform/outputs`，学习/反馈在 `knowledge`。升级不删除个人内容或知识，冲突保留两份。Key、Cookie、登录态和生产内容不在安装包中。

首次启动可能需要几分钟。请配置自己的模型API；云端API收到任务输入与相关检索片段，完全本地请使用本机模型。平台账号、付费媒体服务及完整重媒体后端仍须按实际功能自行配置，尚未宣称全部可用。

初版没有商业代码签名证书，Windows可能提示未知发布者；请从本仓库Release下载并核对SHA256SUMS.txt。上游和第三方许可证、来源与证据状态保持不变。
