# Kivo 0.3.3

Windows 10 / 11 x64 安装包为 `Kivo-Setup-0.3.3.exe`。

## 更新内容

- 桌面启动校验转到后台，加入校验缓存、进度反馈与失败提示。
- 增加离线新手指南，可通过“帮助 → 新手使用指南”打开。
- 修复对话收尾重复、后台标签页文本提交、历史问题状态和过期回答处理。
- 会话保存失败时保留当前回答并显示提示。
- 改善画像加载、Windows BOM 配置读取、代理继承、OpenCode 启动器识别与 Agent 长消息处理。
- 增加技能同步检查、上下文预算诊断与前端构建过期检查。
- 修复视频分镜中断恢复、字幕换行及音频混音问题。

底层基线为 Easel `8d08b216105bd7c7057c84c97cd637cec44db609`，本次选择性回移稳定性补丁，审核到 `5c12e42e9019d276368130b52385b770749ffa6f`。原有 114 项技能、知识检索、手动学习、反馈学习及通用 API 工具引擎已完成适配。
