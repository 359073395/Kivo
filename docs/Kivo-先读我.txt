Kivo 国内版 0.3.3｜朋友测试包
日期：2026-11-04

1. 先将压缩包完整解压到电脑上的普通文件夹。
2. 双击 Kivo-Setup-0.3.3.exe，按向导安装。
3. 双击 Kivo-新手使用指南.html，跟着“第一次配置 AI”和“十分钟做出第一份草稿”操作。
4. 软件里也可以通过“帮助 → 新手使用指南”打开说明。

只适用于 Windows 10/11 64位电脑。无需 Codex、Python 或 Node。
需要你自己的 AI API 地址、Key、模型以及额度；没有共用账号或内置付费 Key。
本包包含获准分享的本地知识快照，不包含发送人的私有配置、登录态和生产内容。
你的新内容、知识和配置默认保存在本机；使用云端 AI 时，相关任务输入会发送给你选择的供应商。

建议先测试文字创作和本地保存，再按需要配置媒体服务、平台登录和发布。
初次尚未配置API时，工作台可能显示“网关未连接”或“连接中”；先按指南配置通用API，不要因此另外安装Codex或OpenClaw。
首次启动需要准备近3000份内置知识，特殊AppData重定向/安全扫描环境可能明显更慢。进度仍在变化时请继续等待，不要反复双击。
不要直接批量发布。失败时先保留截图和日志，不要删除数据文件夹。
测试版未商业代码签名，来源不明或被安全软件报毒时请先核对，不要关闭安全软件。

SHA256SUMS.txt 是文件校验清单。请勿将自己的数据目录、Key 或账号密码发给别人。
