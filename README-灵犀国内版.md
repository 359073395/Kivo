# 灵犀自媒体平台 · 国内版

基于 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel) commit `8d08b216105bd7c7057c84c97cd637cec44db609` 的增量版本。原五层内容工作流、114个内置技能、七平台发布、画像、日历、素材和执行引擎均保留。原始上游说明见 `README.md`；上游代码保险副本为原始下载ZIP。

## 启动

```powershell
& 'G:\GitHub\IP\lingxi-platform\启动灵犀.ps1'
```

打开 `http://127.0.0.1:7860/`。本机启动器只监听回环地址。默认执行引擎为**通用 API（独立运行）**，不需要安装、启动或登录 Codex、OpenClaw、OpenCode 等客户端。原有客户端引擎全部保留为可选项，旧对话历史不删除。

在“设置 → 通用 API 配置”填写 Base URL、API Key、模型名。使用 OpenAI 兼容 `/chat/completions` 协议；完整技能执行要求模型支持 `tools/tool_calls`，图片需视觉能力。Base URL 是带版本前缀的根地址（例如您的服务商提供的 `https://…/v1`），不是完整的 `/chat/completions` URL。本机/自建无鉴权服务可留空Key。密钥只在服务器本机 `.env`，不返回浏览器明文、不进入知识库或仓库。当前未填真实供应商配置，本地协议模拟测试不代表真实模型已经连通。

首次使用平台账号时在“账号”页扫码登录。媒体生成服务需在原有设置中配置；网页、知识检索、文字学习和文本检查可独立使用。本轮安装核心网页、知识与发布导出依赖；未配置的图像/音视频远端服务不能称已恢复。

## 新增入口

- **检索知识**：中文检索、分类、正文片段、来源与状态。
- **辅助创作与校验**：根据平台、主题与真实事实创建原有对话任务；自动补充相关知识。可做标题、文案、选题、脚本和复盘；确定性文本检查与AI深审分开。
- **学习新资料**：粘贴完整文本或导入UTF-8 Markdown/TXT，保存原文与来源，AI提炼候选方法；核对并审核后加入平台后续创作。
- **手动直接使用**：勾选“这是我已确认的方法”，保存后直接进入国内版创作知识，不必再次走AI审核。长课程仍应先提炼，避免把全文观点当执行规则。
- **数据反馈与自学习**：手动录入/批量JSON导入作品数据；原数据抓取接口成功返回可用账号身份和结构化数值时也自动学习。按账号与平台保存，计算有分母的比率，按相同实验/窗口形成下一版复测假设。重复快照不加样本，同一作品使用最新有效快照。错误反馈可停用和恢复。
- **全库整理清单**：逐文件去向、分类、镜像、历史资料与不索引原因。

`F:\Knowledge` 为唯一来源；默认读取 `knowledge-base.json` 和机器配置，索引/学习资料存 `F:\820\lingxi-platform`。不搬动或重写原始知识。改用其他电脑可设置 `LINGXI_KNOWLEDGE_ROOT` 和 `LINGXI_DATA_ROOT`。

自动知识检索连接原 `/api/chat`、流式对话、API直连和技能运行。`LINGXI_KNOWLEDGE_AUTO=0` 可关闭自动注入，原流程仍可运行。新资料学习区独立于正式规则；批准仅对灵犀国内版生效，写回正式库仍走现有知识迭代流程。

## API独立执行与学习边界

通用API引擎可多步查知识、列出/读取114个原技能、读取本轮附件、创建文字作品。原 `skills/shared/scripts/*.py` 可在流式聊天中经网页逐次确认后执行，参数使用数组，不拼接shell命令；工具循环最多12步，脚本单次上限180秒，可停止。原脚本不是操作系统沙箱，可能联网、调用付费服务或影响账号，确认卡展示完整命令和风险。后台/非流式任务不能跳过这个确认门；出现权限需求请在流式对话继续。`LINGXI_API_TOOLS=0` 可显式切回原纯聊天行为。API失败不会静默调用任何客户端。

“自学习”是持续保存可追溯知识和反馈、检索经验并指导下一次创作，不是自动微调模型权重。默认反馈写在外部运行根 `feedback.sqlite3`，手动方法在 `learned/`；不会改写 `F:/Knowledge` 活动规则。

反馈账号名称与当前画像一致时，创作可自动调用同账号数据。单一平台可直接调用；多平台需在任务中说明目标平台。平台自动抓取身份以返回的账号ID/昵称为准；若与画像不一致，先在反馈页按该账号查看，再点“结合数据复盘与创作”。没有稳定作品ID、账号身份或结构化数值时不猜测归因；可以按实际后台导出手动补录。`LINGXI_FEEDBACK_AUTO=0` 可关闭原数据页的自动摄入，手动录入仍可用。

一次成功或一条高指标不会成为全局规则；对比只给带样本说明的复测候选，缺失指标保持未知，分母为0或口径矛盾时不算比率。默认不跨账号、平台或观察窗口归因，不自动发布/发送/付款。

## 整理原则

全量盘点、全文索引、重新蒸馏和真实业务验证是不同状态。课程/文字稿保存来源观点，已发布方法卡不等于活动规则；历史项目、归档、机器配置和工具不自动进入文案上下文。国内迁移采用运营机制，平台参数保持其原范围。

现有文案校验只检测可见承诺、数字和事实缺口，不能证明平台审核、版权或营销效果通过。真实发布、账号身份和数据回流按原平台流程验收。
