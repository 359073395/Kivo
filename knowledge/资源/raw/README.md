# 最终文字稿存储说明

`资源/raw/` 保存已经从来源转换出来、可检索和可迁移的最终 Markdown 文字稿，不保存大型原始二进制文件或临时转换缓存。

## 目录

- `sources/视频/`：完整视频逐字稿与重要画面文字说明。
- `sources/音频/`：完整音频逐字稿。
- `sources/文档/`：PDF、DOCX、PPTX 等的全文 Markdown 稿。
- `sources/网页/`：在授权和版权边界内保存的网页正文稿或详细释义稿。
- `sources/图片/`：图片 OCR 与视觉关系说明。
- `sources/数据/`：规范化表格、字段说明和口径。
- `transcripts/`：兼容已有历史逐字稿；新稿优先进入对应 `sources/<类型>/`。
- `ocr/`：最终 OCR 汇总稿；OCR 图片和引擎缓存仍放在知识库外。
- `inbox/`：尚未完成分类的轻量文本来源。

每份文字稿必须链接到 `资源/来源索引/` 中的来源卡，并记录完整性、原件外部路径或 URL、哈希（可用时）、转换工具和缺失范围。
