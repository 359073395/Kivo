## 3.3 店铺常年 50% 折扣：Product discount 设置与维护 SOP

- 章节ID：`0db969b5-0b8e-431f-85f3-a58710187730`；原站版本：1；原站更新：2026-09-07T17:24:38.547506+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **为什么常年挂 50% 折扣：**上架时 Retail price 填的是划线价（≈日常售价 2 倍，见 2.9 表 2-4），前台靠 Product discount 打 **5 折**后≈日常售价——**折扣标签 + 划线价**是前台价格力和转化率的基础，没有折扣的链接价格展示和转化都吃亏。

- **新店首次设置：**Promotions 页 → Create promotion → Explore all promotion tools → **Discounts → Product discount → Create**，按引导选商品、设折扣率 50%、时间按自然年设置（覆盖当年 1 月~12 月）。

- **老店日常维护：**进 Manage your promotions 管已有活动。常年活动就是那条 50% 折扣规则，**时间按自然年设置，一年更新一次即可**——每年年初把活动时间续到当年年底。

- **新品上架后必做（高频遗漏点）：**每批新品上架/审核通过后，进 Manage your promotions → 打开常年 50% 折扣活动 → 点 Select products（会列出**还未加入活动的商品**）→ 批量勾选、确认折扣率 → 保存。

- **设置完必须验证：**返回 **商品管理（Manage products）**看商品是否已带折扣、前台价格是否生效；没生效就重新进活动检查商品是否保存成功。**此动作已纳入 2.13 上架自检清单**。

**三个易错点：**① 新品上架后**忘记加折扣活动**是最高频失误——链接在前台以划线价裸奔，转化直接掉；② 折扣率统一 50%，不要单件乱改；个别品要特殊价格走运营定价流程（2.9），不在活动里随手改；③ 不要从商品行的 Set discount 单品入口设折扣（见 2.5 表 2-3，那里标"一般没用"），**折扣一律在 Promotions 统一设置**。

## 3.4 平台大促报名 SOP（Campaigns）

- 章节ID：`b5bb80ff-93e4-4254-856c-69e72e02d8a3`；原站版本：1；原站更新：2026-09-07T17:24:38.608898+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- 入口 seller-id.tokopedia.com/promotion/campaign-tools?shop_region=ID（Marketing → Campaigns 活动）。**按运营要求注册活动。**

- **报哪些：**一般只注册 **斋月、发薪日、双数大促（含 12.12）**等大活动。

- **哪些不报：**要求设置单独折扣券、或**平台服务费需要额外费用**的活动，一般不参加——报名前看清活动条款里的费用和折扣门槛，算不清账的不报。

- **报名前核对：**活动折扣门槛与历史最低价校验、库存要求、店铺评分门槛；确认活动价不亏损（价格口径以价格台账三价为准，见 2.9）。

- **报名后动作：**锁定库存、确认活动价、准备活动主图和挂车视频；大促前配合 M6 提前加广告预算（大促流量贵、竞价高，预算和 ROI 节奏见 6.4/6.5）。

- **关于 Flash sale / 秒杀：**团队不走 Flash sale registration（3.1 表 3-1 标注"没用"），秒杀类玩法不单独报；限时转化靠常年折扣 + 大促活动 + 广告承接。

## 3.7 Growth Xtra Program（GXP）：付费联合补贴券包

- 章节ID：`cec4330b-cc4c-4f6c-a1a9-f240464fbea8`；原站版本：1；原站更新：2026-09-07T17:24:38.788984+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**一句话：**印尼站 TikTok Shop / Tokopedia 的**付费联合补贴券包计划**——你付一笔服务费，平台出资在你店里发一揽子优惠券，换流量和转化。2026 年 5 月 18 日起由 Xtra Boost Program（XBP）升级改名。

**会员权益：**

- **限时券：**商品级个性化补贴，买家一单可叠多张券，会员免费（新主打权益）。

- **Campaign Xtra：**大促期专属高额券（**8%–20%**，上限至 **Rp100 万**）+ 优先锁定核心直播间（KLS）坑位。

- **Live Xtra：**直播专属券，50%–99% 折扣。

- **通用折扣券（Mega Diskon 5%–18%）。**

- 注：Bonus Cashback 自 5/18 起已对全量卖家开放，不再是 GXP 专属（见 3.8）。

**服务费（含税、按类目、无封顶），只对成功妥投订单收取；新卖家 7 天免费试用：**

表 3-3 GXP 服务费率（按类目）

| 类目 | 服务费率 |
| --- | --- |
| 珠宝 / 虚拟 / 办公 / 手机电子 | **2%** |
| 家居 / 宠物 | **2.5%** |
| 厨具 / 玩具 / 家具 / 食品 / 汽车摩托 | **3.5%** |
| 母婴 / 健康 / 运动 / 箱包 / 穆斯林服饰 | **4%** |

- **和佣金的关系（关键）：**加入 GXP 平台佣金全店**立减 1.40%**；GXP + GMV Max 广告支出/GMV ≥3% 可叠加到 **4.00%**（即「最高省 8.18%」那档，佣金口径见 1.12 表 1-2）。所以**净成本 = 类目服务费 − 1.40%**。

- **加入 / 退出路径：**Seller Center → Marketing → Program → Co-funded Bundle Program 报名；**退出审核 14 个自然日**。

**适用建议：**客单价 **Rp120,000 以上**、常做直播的店值得加；客单价低于 **Rp50,000** 的店慎重——券门槛买家够不到，服务费照付。几十家店**按客单价分档决定，别一刀切**。

## 3.8 Bonus Cashback（奖励返现计划）：复购工具与默认生效口径

- 章节ID：`02dda056-7451-491a-a78f-0adfcb2b5486`；原站版本：1；原站更新：2026-09-07T17:24:38.849553+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **本质是复购工具：**买家在你店下单用了 Bonus Cashback 券后，拿到一笔返现奖励，**只能在你店里下次消费抵扣**——平台替你出钱、把买家锁回你店铺复购。商品页挂奖励返现标签，提升点击和转化。

- **收费范围：**只对**使用了 Bonus Cashback 券的已完成订单**（妥投且无退货退款）按比例收服务费；已发货后买家退货退款的，先收后退回；未发货取消不收。

- **收费公式：**（商品净价 − 卖家折扣）× 服务费率。

- **账单查看：**Finance → Settled records → View Details。

- **重要变化：**自 **2026-05-18** 起，印尼站 Bonus Cashback 已并入动态佣金权益、**对全量卖家开放，不再是 GXP 会员专属**——各印尼店大概率已默认生效，这就是账单里这笔扣费的来源（动态佣金口径见 1.12）。

**关闭路径：**

- Seller Center → **运营活动**，搜「奖励返现计划 / Bonus Cashback」→ 活动详情页 → **报名记录** → 「操作」栏点**撤销**。

- 状态「撤销审核中」→ 通过后变「失效」（反悔可点「取消撤销」）。

- 退出后：返现标签消失；**退出前已用券订单服务费照收，退出后新单不再收**。

- 若运营活动里找不到报名记录（随动态佣金自动生效），找客户经理申请关闭，或走 GXP 退出入口（Seller Center → Marketing → Program → My Program，退出审核 14 个自然日）。

## 3.9 Voucher Boost 大促合资券：平台商家一起出钱贴买家

- 章节ID：`c7212cc1-759c-448a-99da-19a5ca93872d`；原站版本：1；原站更新：2026-09-07T17:24:38.909324+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

大促分两级：**双日大促（9.9、10.10、11.11 等）> 发薪日大促（Payday/Gajian Sale，每月 25 日–次月初）**。双日补贴更高、有平台专属线上线下宣发，是主战场；发薪日次之（日历见表 3-2）。

- **核心机制——平台和商家一起出钱贴买家：**商家报名商品、设活动价，平台按分摊比例出资发券。比例各站/各身份不同：如越南 VXP 商家平台出 80%/商家出 20%，非 VXP 商家自担 80%；共资促销计划标准档商家 15%/平台 85%（**比例以报名页显示为准**）。

- 券带专属标签展示在**商品详情页、直播间购物袋、橱窗**。

- **关键规则（最低价）：**合资券**不计入「近 30 天最低价」基准**（只限商家出资部分），但**活动价受最低价机制约束**——大促前临时涨价再打折会被系统识别，直接没资格。

- 部分新档期（如美区秋促/黑五）已改成「平台全资券、商家只付 1% 服务费」模式，**印尼/东南亚仍以合资分摊为主**。

## 3.10 闪购 Flash Sale（商家自设秒杀）：三类型、价格规则与运营要点

- 章节ID：`0a2e4987-1763-42eb-917f-02b2e4be2943`；原站版本：2；原站更新：2026-09-07T17:24:38.969332+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**一句话：**限时 + 限量的降价工具，用「倒计时 + 限购」制造抢购紧张感，换单品爆发式成交。**所有商家营销工具里优先级最高**——商品同时设了秒杀和单品折扣，前台只显示秒杀价。

注意区分：3.1 表 3-1 里标「没用」的 **Flash sale registration** 是**平台闪购场次报名**入口（团队不走）；本节讲的是**商家在营销工具里自设**的三类秒杀，是两件事。

表 3-4 闪购三种类型（商家自设）

| 类型 | 展示渠道 | 时长 | 适用场景 |
| --- | --- | --- | --- |
| **Seller Flash Sale**<br>（全渠道） | 商品页、直播间、短视频、橱窗、商城全部渠道 | 10 分钟–3 天 | 推爆品/新品、清库存 |
| **LIVE Flash Sale**<br>（直播秒杀） | 仅官方号/营销号直播间 | 1 分钟–3 天 | 直播逼单、留人（支持开播前 1–5 分钟倒计时预热） |
| **Creator LIVE Flash Sale**<br>（达人直播秒杀） | 仅联盟达人直播间 | 10 分钟–14 天 | 给达人专属价+专属库存，低佣金也能撬动达人带货 |

**价格规则（硬性）：**

- **有近期订单的商品：**秒杀价必须低于**近 14 天最低成交价**（含卖家折扣价、活动价；官方 Tokopedia 口径 14 天，跨境站点部分文档写 30 天，以后台活动页显示为准）。

- **无订单记录的新品：**秒杀价低于原价即可。

- **不能叠加：**商家单品折扣、平台爆品补贴（同时设置时前台只显示秒杀价）。

- 价格作用到 **SPU** 维度时该 SPU 下所有 SKU 同价；也可按 **SKU** 分别设价（适合滞销色/码单独清库存）。

**库存与限购：**

- 可设「限购总量」和「单人限购量」。

- 达人直播秒杀库存两种模式：**共享库存**（全店和达人抢同一池子，先到先得）或**预留库存**（给选定达人单独留货，达人可分批放库存制造多轮抢购）。

**报名门槛：**店铺评分 + **违规分 <36** + 店铺余额高于 **-100 USD**；印尼/越南/马来/新加坡店铺评分 **≥3.0**，泰国/菲律宾 ≥2.5。不达标无法在 PC/App/API 创建或编辑秒杀（已创建的活动不受影响）。

**买家侧触点：**商品详情页和直播间显示「Flash Sale」标识 + 剩余时间倒计时 + 秒杀价/原价对比。

**运营要点：**
① 闪购的价值不是让利本身，是**短期数据脉冲**——转化率、单量激增带动链接在自然流量池的权重，用在有基础销量的潜力品上，别浪费在死品上；
② 直播型店铺优先用 LIVE Flash Sale 的倒计时预热，配合憋单话术；
③ 清库存按 SKU 设价，别全 SPU 一刀切——好卖的规格不用跟着降；
④ **注意和大促衔接：**秒杀价影响「近 14/30 天最低价」基准，大促报名前别随便开低价秒杀，否则活动价被压得更低甚至审核不过（见 3.9/3.11）；
⑤ 几十家店可用 Open API 批量创建管理秒杀（有 API 权限的话），比逐店手点高效。

## 3.11 大促流量入口与分配逻辑：内容场是主阵地

- 章节ID：`838ee333-1555-4239-be94-06272e98de7e`；原站版本：2；原站更新：2026-09-07T17:24:39.029613+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**① 内容场（GMV 主阵地）：**官方明确内容场是拉动大促 GMV 最主要阵地。

- **入口：**重点直播间、直播挑战赛、短视频挑战赛、直播秒杀。

- **分配逻辑：**开播时长、直播间转化率、挂车短视频互动数据 → 平台给直播券补贴和推流。**不开播 = 自动放弃最大那块流量。**

**② 商城场（货架流量）：**

- **入口：**大促落地页商品池、秒杀专区、Shop Tab、搜索/推荐加权。

- **分配逻辑（重点）：**系统向「优质低价品」倾斜——**券后价越有竞争力、额外折扣越大、店铺体验分越高，资源位和曝光加权越多**。设了「活动价之上额外折扣」的商品有专属曝光加权和大促氛围标签；价格力不够的商品，报名成功也沉底。

- **门槛：****SPS ≥3.5**（印尼站 EU 扩展等要求 ≥4.0）、差评率达标、价格通过审核才进商品池。

**③ 广告放大：**GMV Max 的「促销日」功能在双日/发薪日自动降 ROI 目标、加预算（默认 **+50%**）抢流量——**需提前 3–5 天开启**让系统学习，临时开没用。

**口径提示：**团队既有纪律是 Promotion days 开关「不建议常开、大促 ROI 由系统按近期平均自动定价、不手动乱降」（见 6.10）；本节补充的是平台侧机制：**要用促销日功能就必须提前 3–5 天开**，当天才开等于没开。两者不冲突——开了就别当天临时开、也别盘中手改 ROI。

## 3.12 大促没涨单的 8 条自查

- 章节ID：`7eba1dc9-ce09-46be-8b3e-3fc58c4d9f15`；原站版本：18；原站更新：2026-09-07T16:07:51.089+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **报名了 ≠ 拿到流量。**报名只是入场券，商品池是审核制——价格力不够、SPS 不达标，商品根本没进池。先看后台商品状态是「已入池展示」还是「审核未过/未获资源位」。

- **价格力不够被流量分配过滤。**券后价只比日常低 3%–5% 而竞品低 15%–20%，系统不会给曝光。几十家店尤其容易犯「全店统一小折扣」的错。

- **只挂了商城场，没做内容场。**不开播、不发挂车短视频 = 放弃官方说的大促 GMV 主阵地（见 3.10），商城场只是配角。

- **GMV Max 没配合。**没开促销日功能、或当天才开（没学习期）、或预算没加——大促流量峰值是日常 3–5 倍，预算原地踏步等于被挤出。

- **券门槛买家够不到。**满减门槛高于店铺主流客单价，券发了用不掉。

- **被最低价机制卡住。**大促前 30 天内有更低成交价，活动价审核不过（见 3.9）。

- **存量转移假象。**消费者攒单等大促——大促当天「涨」的只是搬过来的存量，全周期 GMV 没增。按「大促周 vs 前一周」口径看，不是看当天。

- **爆单后遗症反向限流。**备货车不够（官方建议大促备货 = 日均 **10–15 倍**），48 小时发货率掉线、LDR 超标 → 被限流、影响下一场报名资格。

**落地动作：**各店拉四个数——**入池商品数、券后价 vs 竞品价差、开播时长、GMV Max 大促期间消耗**，一对比就看出每家店卡在哪一环。
