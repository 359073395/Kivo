## 2.0 多店铺操作环境：战斧浏览器

- 章节ID：`a48046ab-c9d4-45de-98b3-1269d74a94fe`；原站版本：1；原站更新：2026-09-07T17:24:37.593066+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **所有店铺后台操作必须在战斧浏览器（指纹浏览器）里进行**，一个店铺 = 一个独立环境配置（独立指纹/IP/缓存），**严禁在同一普通浏览器里登录多个店铺**，防关联封号。

- 开店顺序：战斧里打开对应店铺环境 → 进入 seller-id.tokopedia.com（印尼站 TikTok Shop 后台对接 Tokopedia 卖家中心）→ 确认店铺名无误后再操作。

- 环境铁律：不串环境、不共用登录态、不在店铺环境里登录与本店铺无关的账号；环境异常（IP 失效、页面串号）立即停手找主管。

- ERP（店小秘）也按店铺授权隔离，**复制上架时先确认当前授权的是目标店铺**，铺错店等于白干。

## 2.1 印尼市场消费特征与品类认知

- 章节ID：`f0bb950b-f819-456d-8071-ea01157432d0`；原站版本：2；原站更新：2026-09-06T21:29:38.51278+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- 主流价格带与冲动消费区间：印尼电商客单偏低，**低客单 + 强视觉冲击 + 功效直观**的品更容易爆。

- 高潜品类特征：美妆个护、家居小百货、穆斯林时尚、母婴、3C 配件等；热带气候影响需求（防晒、控油、止汗、防潮）。

- 避坑：食品/药品/医疗器械类资质门槛高，侵权大牌周边直接不碰；美妆功效表达走「护理/帮助」路线，不碰医疗声称（见 2.10 违规红线）。

## 2.2 数据化选品方法论

- 章节ID：`8e64025a-6289-4f82-a9e1-e7fc3c0fe682`；原站版本：1；原站更新：2026-09-07T17:24:37.715249+08:00。

- **选品工具：**FastMoss 看热销榜/飙升榜/达人带货榜（账号密码在团队密码表 SECRET，会员到期及时提醒续费）。

- 爆款四看：看销量趋势（持续 vs 脉冲）、看价格带利润空间、看内容门槛（好不好拍视频）、看竞争密度。

- **跨店验证：**团队有销量矩阵台账（行=产品、列=店铺缩写），选品先看该品在现有店铺的跨店动销，已验证的品优先铺新店。

- 跟卖与差异化：同款拼价格和主图，微差异化拼规格/套装（多 PCS）/赠品。

- 季节性与大促备货日历：斋月、开斋节、双数大促前 4-6 周完成选品备货。

## 2.3 上架方式一：手工上架 SOP

- 章节ID：`a269ab35-0de3-4d4d-9f9f-7234e8d10827`；原站版本：1；原站更新：2026-09-07T17:24:37.778556+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

适用于新品首发、需要精细填属性的品。在战斧对应店铺环境内操作：

- **先查价格台账**：打开团队商品价格表，确认该 SKU 的「日常售价 / 平台活动价 / 上架原价」都已填——**铁律：没价格就是不上架**。

- **类目选择：**类目放错会被限流甚至下架；拿不准用后台类目搜索对照同类爆款，或查违规整改表里的「建议类目」。

- **品牌填写：**无授权品牌一律不填他人品牌；从团队**自有品牌池**选择：jawa、SANCELLA、shuma、Bona Vita、Homend、Pondox（按店铺对应品牌用）。

- **属性：**带 * 必填项全部填满；材质、尺寸、功效等关键非必填项也要填，影响搜索曝光。

- **SKU 与价格：**规格命名用印尼语/英语通用写法；按价格台账逐 SKU 填价格和库存，多 PCS 套装按 2.9 公式单独建 SKU。

- **重量物流：**按下方字段地图统一处理：包裹重量填 100 克、配送选 Default、COD 勾选、运费险选 Mandatory。

- **标题/主图/详情：**按 2.6 / 2.7 / 2.8 标准制作后填入，发布前全部过 2.10 违规词库。

- **上架后自检：**前台搜索验证商品卡展示、价格、库存、挂车可售状态；PID 登记回价格台账。

**发布新品页 · 后台字段地图**（入口：seller-id.tokopedia.com/product/create?channel=manage&shop_region=ID）——后台从上到下每个字段「官方怎么要求 / 团队实际怎么填」，新人照着逐格填即可：

## 2.4 上架方式二：店小秘复制上架 SOP

- 章节ID：`6db2332c-39f5-46f5-a19c-10f5d6d49870`；原站版本：1；原站更新：2026-09-07T17:24:37.837787+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **适用场景：**跨店/跨品快速铺货——把已上架店铺（或采集源）的商品通过店小秘 ERP 采集、复制到目标店铺。

- 操作流程：店小秘内**确认授权店铺是目标店** → 采集/选择源商品 → 复制为草稿 → **逐店必改项**：标题（去重防判重复铺货）、价格（按目标店价格台账，不能直接带源店价）、品牌（换成目标店对应自有品牌）、主图（必要时换图防同款雷同）→ 提交上架。

- **复制上架不等于无脑搬运**：类目、属性、重量、库存仍要逐项核对；源商品有违规记录的不得复制。

- 多店铺货节奏：同一批品铺多店时，**标题和主图做差异化**（至少换首图和标题语序），降低平台同质化判定。

**④ Products 主菜单其他子菜单**

- **Sales Accelerator** 销售加速器：平台营销工具包，新人阶段不用。

- **Product ratings** 产品评分：查看具体产品的评价分数；**更快的方式——拿 PID 直接去 FastMoss 查**。

- **Price bidding** 价格竞标：价格类竞价工具，暂不使用。

- **Product opportunities** 产品机会：平台推荐相似商品供上架，**有一定流量扶持**，选品时（2.2）可以翻一翻。

- **Price diagnosis** 价格诊断：平台给出的价格竞争力提示，调价时参考。

## 2.6 主图制作规范

- 章节ID：`24686df0-6778-43f6-ad8d-08ecfd051963`；原站版本：1；原站更新：2026-09-07T17:24:37.957838+08:00。

## 2.12 商品卡优化：曝光 → 点击 → 信任 → 下单

- 章节ID：`06dda5c1-825c-419b-8787-dac303e27ae9`；原站版本：1；原站更新：2026-09-07T17:24:38.311019+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

商品卡是卖货的最后一站，出现在商城、搜索结果、For You 推荐流、视频/直播小黄车、达人橱窗五个场域。**同样 1000 次点击，商品卡烂只转化 5 单（CVR 0.5%），优化到位能转化 20 单（CVR 2%）**——算法会把更多免费商城/搜索流量倾斜给高转化商品，进入「视频爆 → 商品卡承接 → 自然流增长 → 更多订单」的良性循环。

**两个核心指标：**[CTR](#g-ctr)（点击÷曝光，由主图/标题/价格决定，优秀 3%~8%）和 [CVR](#g-cvr)（订单÷点击，由详情/评论/价格/促销决定，1% 是门槛、3%+ 优秀）。

**① 主图：5 张为基础要求**（统一 800×800px，不要全是同一角度）：

- 第 1 张（决胜局）＝卖点演示 + 场景；第 2 张＝对比图；第 3 张＝细节特写；第 4 张＝使用场景/使用说明；第 5 张＝白底图 + 包装盒、品牌 Logo、认证证书（信任）。

- 第 6 张起是补充位：参照物感知尺寸、更多使用场景（办公室/健身房等精准人群）、15 秒短视频主图等，有余力再加。

- 多链接多主图测试，观察曝光和点击变化；拆解同行优秀配图。

**② 标题：**公式＝【核心关键词】+【产品名称】+【核心卖点/材质】+【适用场景/人群】；关键词从 TikTok 搜索框下拉推荐、店铺罗盘热搜/飙升词、第三方工具三处挖（与 2.7 标题公式、7.8 罗盘测品打通）。

**③ 价格与促销（破最后一道心理防线）：**必设划线原价做价格锚定（$59.99 划掉 → $39.99 标 46% OFF，与 2.9 三价体系、3.3 常年 50% 折扣一致）；叠加无门槛优惠券（主图显示红色 Claim 标签）；多件 SKU 更优惠（买三瓶立减、满赠满减），让用户有占便宜的感觉。

**④ 评论与评分（社会认同）：**4.8 分 + 150 条评论（含 20 条带图好评）的版本，即使价格稍高，90%+ 用户也会选它而不是 4.2 分 5 条评论的版本——好评消除决策疑虑。**团队口径：评价只按统一话术回复，不做好评引导、不做差评回访、不做任何客诉干预（见 1.5⑤）；差评内容反哺商品端**——改进品控、主图和描述，从源头减少差评。

**数据诊断路径（Seller Center → Data → Products 看 Impressions/Clicks）：**高曝光（>1万）低 CTR（<3%）→ 问题在主图/标题/价格，优化 2.6/2.7/2.9；高点击低 CVR（<2%）→ 问题在详情/评论/最终价格，优化详情页、上促销券；**评价问题从商品端改（不干预评价，见 1.5⑤）**。**联动提醒：达人视频爆了但商品卡没优化，流量接不住等于白爆**——推达人/投广告前先把商品卡优化到位。

**⑤ 上架 ≠ 进推荐流量池：商品卡流量的本质是「推荐分发」。**系统主动把商品推给「可能会买的人」（详情页同类推荐、下单后猜你喜欢、浏览后相关推荐、商城/频道推荐流等），是系统帮你「找人买」，不是你「等人搜」。能否进池，系统只看一件事：**这个商品有没有更高成交概率**——通过一段时间的数据测 CTR、停留与浏览深度、加购、实际成交、CVR；信号偏弱就判定「暂时不值得加大推荐」，表现为曝光少、推荐弱。

- **动作一 · 先做基础销量（最重要的第一步）：**0 销量链接是「未知商品」，系统不会轻易放量；**没有成交数据系统不会放量，哪怕小单量也比 0 强**——这也呼应 6.10 的投放前提（0 销量 0 评价纯新品直接进 GMV Max，系统不敢花钱）。

- **动作二 · 标题让系统看得懂：**产品词 + 核心卖点 + 使用场景 + 人群关键词；没关键词/没类目/没人群/没场景，系统识别不了卖什么、推不准人（与 2.7 标题公式一致）。

- **动作三 · 主图决定第一波点击：**商品卡第一关是点击不是转化——一眼看懂是什么、有核心卖点信息、干净但不空、有场景感更好（标准见上方①与 2.6）。

- **动作四 · 详情页做决策辅助而非堆图：**回答「解决什么问题、比别人强在哪、有什么优势、是否值得信任」，本质是说服不是展示（与 2.8 一致）。

- **动作五 · 持续稳定数据比爆一波更重要：**系统更喜欢稳定成交、稳定点击、稳定转化的商品——**稳定性 = 可推荐性**。

商品卡承接力与广告效果是同一件事的两面：素材负责让人点，商品卡/详情页负责让人买（见 6.7 漏斗表）；视频卖点、商品卡信息、用户实际体验三者一致，才既能接住广告流量、又能被推荐池持续放大。**新品 0 销量阶段不要指望商品卡自然放量，先用广告 + 基础销量把「成交确定性」喂出来。**
