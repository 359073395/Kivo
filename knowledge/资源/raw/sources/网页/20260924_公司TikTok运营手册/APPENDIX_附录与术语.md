##### A.1

##### 申诉信模板（印尼语，500 字符铁律）

来自 **8.5 申诉信怎么写**。后台表单限 500 字符，一段式、零客套、四要素按序压缩（①定性 → ②证据/已整改 → ③附件提示 → ④请求），写完用代码核字数。

**后台申诉表单限 500 字符**（印尼语含空格标点）。一段式、零客套（无 Subjek/Kepada/Hormat kami 头尾），只保留四要素按序压缩：**①定性**（一句话：差评/违规真实原因）→ **②证据/已整改动作**（1-2 句，冒号列举 1) 2) 3)）→ **③附件提示**（半句：Foto/video terlampir）→ **④请求**（Mohon pelanggaran ditinjau kembali dan dicabut）。写完**必须用代码 len() 核字数**，目标 350-480 字符（留占位符余量），不许凭感觉估算。省字技巧：不写产品全名和 PID（后台单已关联）、列举用「1) 2)」不用完整句、占位符用 [X]。

**模板 A · 履约整改型**（包装破损，339 字符；先完成整改+拍照再提交）：

##### A.2

##### 达人邀约话术（「故意犯错」钩子）

来自 **4.4 邀约话术**。常规邀约回复率极低，团队用「纠正心理/好奇心」开场，达人一回复立即顺势讲合作（佣金、样品、投流支持）。

- 「刚看到样品已经签收了，什么时候开始拍视频呢？」

- 「样品显示签收了！是你本人签的吗？核对下地址没问题我们就安排后续推广了。」

- 「样品收到了吧？拍摄脚本刚发你邮箱了，记得查收，明天前给反馈哦！」

- 「看到样品签收了！这品我们准备了 $500 投流基金，就等你视频了！」

- 「通知：本月单量超过 5000 的达人，额外奖金已全部到账！」

- 「小李（编一个和达人不一样的名字），你的 1000 元奖金收到没？」

- 「银行退回一笔 1000 的奖金，说是账户错误，小李看到重新发我卡号！」

**使用指南：**① 精准投放——选近期活跃、但一直没回复你的达人；② 时机——**工作日白天**发，更像「工作失误」；③ 后续衔接——对方一回复立刻接：「啊？不好意思发错了！不过……（顺势讲合作：佣金、样品、投流支持）」。正式合作话术里同步讲清产品卖点、佣金率、样品政策，并带上广告授权引导（见 4.9）。

##### A.5

##### 商品标题改写公式与 AI 优化提示词

来自 **2.7 标题改写公式**。

- **团队标题铁律：255 个字符尽量用满**，写成**完整、流畅的印尼语句子**——有主语、有修饰成分、有清晰的动词目的，读起来自然通顺，不是堆词。

- 词序公式：核心品类词 + 核心功效/属性词 + 场景/人群词 前置；**自然搜索词、同义词最大限度保留**，拓展词、长尾词放后面。

- 关键词渠道：后台搜索下拉词、FastMoss 关联词、同类爆款标题拆词。

- 红线：不堆砌、不重复、不写与商品无关的热词；所有功效词过一遍 2.10 违规词库（menghilangkan / ampuh / permanen 等一律不用）。

- 新品标题 A/B：上架后按搜索点击数据迭代。

**团队在用 AI 优化提示词（整改/优化商品时直接用）：**

    「需要你检查并根据平台规则优化这个产品。① 标题合规：255 个字符尽量用满，写成完整流畅的印尼语句子，有主语、修饰成分、清晰动词目的，最大限度保留自然搜索词/同义词，增加拓展词，场景词和长尾词放后面。② 图片合规：重点头图，以转化率为主，配合搜索词把最好卖点用文字吸睛体现，信息透明减少『少发/不对版』差评，管理使用预期降低『没效果』差评。③ 详情：符合上架要求，中规中矩，具备产品规格和使用说明，增加合规免责声明（效果因人而异、需要一定使用时间等）。纯文本富文本格式输出，方便复制粘贴。」

- 章节ID：`498ce280-f9be-474c-a099-82e3fc953e0f`；原站版本：9；原站更新：2026-09-08T18:11:57.652+08:00。

##### ① 账户与商品标识（周报/台账天天用）

###### GMV Gross Merchandise Volume 成交总额

**专业定义：**拍下订单的总金额，电商平台最核心的成交指标（含未付款/退款前口径，各报表归因窗口可能不同）。

**大白话：**这家店/这条视频/这个计划「卖了多少钱」。注意 GMV 是成交额不是利润，卖得多不等于赚钱。

GMV ≈ 订单量 × 客单价（ATV）

**影响：**周报第一指标，广告报表里的 Gross revenue（广告归因 GMV）是算 ROAS 的分子。

**团队案例：**广告日报里某店单日总消耗 $37.8、62 单、GMV $148.4——先算总账再下钻素材（见 6.7）。注意 GMV 要结合退款率看：全池退款加权曾达 20.6% 红线，实际到手要再打折。

###### PID Product ID 商品 ID

**专业定义：**平台给每个商品链接分配的唯一编号。

**大白话：**商品的身份证号。标题可以改、图可以换，PID 不变；改链接后 PID 会变。

**影响：****周报铁律：商品必附 PID。**排查问题、登记台账、周报对品、去 FastMoss 查数据，一律用 PID 搜最准；整改重发链接后必须把新 PID 登记回台账。

###### Shop ID / Shop Code / 店名 店铺标识三件套

**专业定义：****Shop Code** 是卖家后台（seller-id.tokopedia.com）给每个店铺分配的唯一编号；**Shop ID** 是店铺在 **TikTok Business Center（TikTok 商务中心）**里的店铺代码，广告开户、账户授权、广告体系内跨系统识别店铺时用；**店名**是店铺的展示名称，也是团队日常对店铺的叫法（如 SehatGlow、APALAGI INI）。

**大白话：**同一家店有三个"名字"，各用各的地方——卖家后台认 Shop Code，TikTok 广告和商务体系认 Shop ID，团队里人和文件认店名。三个不是一回事，但指的是同一家店。

**影响：**开广告户、Business Center 授权、广告对账时用 Shop ID 定位店铺；**周报铁律的文件命名用的是店名**（如 APALAGI INI_0727-0802），不是 Shop Code。几十家店的台账里要把"店名 ↔ Shop Code ↔ Shop ID ↔ 战斧环境"一一对应登记好，防止串店、串数据、开错广告户。

##### ② 钱的效率（投放决策核心）

###### ROI Return On Investment 投资回报率

**专业定义：**衡量全部投入的盈利情况。

财务 ROI =（销售额 − 总成本）÷ 总成本 × 100%
总成本 = 货品成本 + 广告费 + 运营费用 + 人力 + 物流退款等全部支出

**大白话：**这盘生意到底赚不赚钱，把所有本钱都算进去。

**⚠️ 口径提醒（团队高频混用点）：**广告后台和投手日常说的「ROI 目标 7」是**广告口语口径**，数学上等于 [ROAS](#g-roas)（GMV÷广告消耗），**没有扣货品成本**，只是沿用了 ROI 的叫法。看店铺/公司赚不赚钱才用财务 ROI（周报对账、M8 考核口径）。**先看 ROAS 筛高效广告，再用财务 ROI 确认整体盈利。**

**团队案例：**团队 ROI 目标统一 7，指的就是广告 ROAS 口径；M4 达人 ROI 是公司侧核算的投入产出口径（运营只记录 GMV、不算成本）。运营对账以广告后台 ROI（=ROAS）为准。

###### ROAS Return On Ad Spend 广告支出回报率

**专业定义：**广告花费直接带来的营收倍数，只算广告支出，不考虑货品等其他成本。

ROAS = 广告归因 GMV ÷ 广告消耗
例：花 $10 广告费带来 $70 GMV → ROAS = 7

**大白话：**一块钱广告费换回几块钱成交额。GMV Max 计划里填的「ROI 目标」就是这个值。

**影响：****日常广告优化的第一指标**（表 6-3 优先级第 1）。目标设太低容易花量但亏，设太高花不出去——团队统一标准：**ROI 目标 7**（计划跑不动时临时下调 6~6.5，见 6.4/6.11；其他跑法为公司内部小范围测试，不入教材）。

**团队判定线（素材层）：**ROAS ≥ 2 放量、1~2 观察、<1 或有消耗 0 单（过学习期后）关停；零碎消耗 <$3 只存档不动作。计划层整体 ROI 目标统一 7，见 6.4 表 6-5。

###### CPA Cost Per Action 单次转化成本（团队语境=成单成本）

**专业定义：**按转化计费/核算的指标，每完成一个目标动作（注册、购买等）的平均成本。电商投放里 Action 就是「出一单」。

CPA = 广告消耗 ÷ 转化量（订单数）= CPC ÷ CVR
报表里对应 Cost per order 列（有消耗无订单时常显示 0，要自己用 Cost÷订单数 算）

**大白话：**广告买来一单要花多少钱。

**影响：****团队红线：成单成本 $0.5~0.6/单（约 ￥3.3~4.3），美妆品类 $0.3~0.5/单。**破线就压预算/优化素材商品卡/关停，不硬跑。

**团队案例：**实测出单素材 CPA 区间 $0.36~1.24；某计划花了 $30 出 20 单 → CPA = $1.5，已破红线——压预算/优化素材或关停，不硬跑。

###### CPC Cost Per Click 单次点击成本

**专业定义：**广告每次点击的平均价格。

CPC = 广告消耗 ÷ 点击量

**大白话：**把一个人「勾进商品页」花多少钱。CPC 高说明竞争激烈或素材预估差。

**影响：**GMV Max 自动出价不用手动管，但理解链路有用：CPC 高 + [CTR](#g-ctr) 低 = 素材在广告池里竞争力差；CPC 高 + CTR 高 = 品类竞价本身贵（大促期间普遍变贵）。

###### CPM Cost Per Mille 千次展现成本

**专业定义：**广告每展示一千次的价格，衡量买流量的贵贱。

CPM =（消耗 ÷ 展现量）× 1000

**大白话：**让一千个人刷到你的广告要付多少钱。

**影响：**GMV Max 不按 CPM 买量，日常不用操作；但 CPM 是大盘冷热的体温计——大促期间 CPM 普涨，同样预算买到的曝光变少，要提前预留预算（见 3.4/6.4）。

###### CPV Cost Per View 每次展示成本

**专业定义：**按展示计费，广告每被展示一次付一次费（部分场景按独立 IP/有效播放计）。

**团队用法：**TikTok Shop 投放以 GMV Max 智能出价为主，**日常不直接操作 CPV**，了解概念即可。

##### ③ 漏斗效率（决定平台给不给你流量）

###### CTR Click Through Rate 点击率

**专业定义：**广告/内容被点击的比例，衡量素材吸引点击的能力。

CTR = 点击量 ÷ 展现量 × 100%

**大白话：**刷到的人里有多少点进来看/点了小黄车。**CTR 是素材的生命线**——前 3 秒钩子、商品卡主图和价格决定它。

**影响：**CTR 直接进 [ECPM](#g-ecpm) 公式，CTR 低广告根本拿不到曝光。CTR 低 → 改素材（前 3 秒钩子、口播箭头引导挂车）、换商品卡主图，**不是**改商品页。

**团队实测（2401 条创意报表）：**出单素材平均 CTR ≈ 1.21%，零单素材仅 0.38%——差 3 倍；<0.7% 基本没机会。注意广告报表里的 CTR 是「商品点击率」（点商品卡，不是点视频）。

###### CVR Conversion Rate 转化率

**专业定义：**点击后完成目标转化（下单）的比例，衡量广告/商品页促成成交的能力。

CVR = 转化量（订单）÷ 点击量 × 100%

**大白话：**点进商品页的人里，有多少真的掏钱买了。

**影响：****CTR 高但 CVR 低/为 0，问题不在素材在商品页**——价格力、评价数、差评、详情、库存（转 M2/M3 优化）。CVR 同样进 ECPM 公式，是放量的另一半。

###### CTCVR 点击且转化率

**专业定义：**从曝光直接到转化的整体效率。

CTCVR = CTR × CVR（= 转化量 ÷ 展现量）

**大白话：**一百个刷到的人里最终有几个下单，一步到位的总效率。

**影响：**这就是平台 ECPM 竞价里 pCTR×pCVR 那一段——**CTCVR 越高，广告越便宜、拿量越容易**。CTR 和 CVR 任何一个短板都会拖垮总量。

###### ECPM Effective Cost Per Mille 千次曝光预期收益

**专业定义：**平台广告竞价的排序依据：每给你一千次曝光，平台预期能赚多少。

ECPM = pCTR（预估点击率）× pCVR（预估转化率）× 转化出价 × 1000

**大白话：**广告拍卖的「综合得分」。不是谁出价高谁赢，是**出价 × 素材和商品的预估转化能力**一起算——素材烂，出再高价也拿不到量。

**影响：****这解释了为什么团队一切优化都指向 CTR 和 CVR**：转化出价（CPA/ROAS 目标）相对固定，能把 ECPM 拉高的就是素材 CTR 和商品页 CVR。ECPM 高 → 广告又便宜量又大。

###### GPM 千次观看成交金额（电商场景）/ Gross Profit Margin 毛利率（财务场景）

**专业定义（电商/直播）：**每一千次观看/曝光带来的成交额，衡量内容/直播间的流量变现效率。

GPM = GMV × 1000 ÷ 观看人数（曝光量）

**大白话：**自然流量的「ECPM」——平台免费给你一千次曝光，你能产出多少成交。GPM 高，系统就给更多自然流量。

**影响：**短视频和直播间做自然流的核心目标就是把 GPM 做高（挂车引导、客单价、转化都算在内）。**注意歧义：**财务语境里 GPM 也指 Gross Profit Margin 毛利率，看场景区分。

###### OPM Orders Per Mille 千次曝光订单量

OPM = 订单量 × 1000 ÷ 曝光量 ≈ CTCVR × 1000

**大白话：**一千次曝光出几单。GPM 看钱，OPM 看单量，是同一效率的两种表达。

**影响：**低价引流款 OPM 高（单多钱少），高客单利润款 GPM 高（单少钱多）；搭配铺品时两个一起看（商品结构见 2.11）。

###### ATV Average Transaction Value 平均客单价

ATV = GMV ÷ 订单量

**大白话：**平均每一单多少钱。

**影响：**同样的流量和转化率，ATV 越高 GMV 越高。团队用 **3pcs/5pcs 套装 SKU**（5PCS = 原价×5−20,000，见 2.9）拉客单，就是直接做高 ATV 从而做高 GPM/ECPM。

###### UV 价值 / PV / UV 流量基础概念

**PV（Page View）：**页面被访问的次数，刷新/重复进都算。**UV（Unique Visitor）：**独立访客，同一台设备 24 小时内多次访问只算 1 次。

**UV 价值（直播间/店铺常用）：**每一个进房/进店访客平均产出多少成交。

UV 价值 = 场观 × 商品点击率(CTR) × 转化率(CVR) × 客单价(ATV) × 关联件数 ÷（曝光 × 点击率）≈ 成交 GMV ÷ 访客数

**大白话：**一个进店的人平均值多少钱。UV 价值越高，平台越愿意给流量（本质还是 GPM 逻辑）。周报看流量时 PV 看热度、UV 看真实触达人数。

##### ④ 了解即可（团队日常不用，听到不懵）

###### ADPV / ADimp / PV 单价 / RPS / CPT / CTOR

**ADPV（Advertisement Page View）：**载有广告的页面流量。**ADimp（AD impression）：**单个广告的展示次数。**PV 单价：**每次页面访问的收入，衡量页面流量价值。**RPS（Revenue Per Search）：**每搜索产生的收入，评价搜索结果商业价值——这四个是媒体/广告平台侧指标，TikTok Shop 卖家报表里基本不出现。

**CPT（Cost Per Time）：**按时间包段计费（包天/包周），品牌广告采买方式，效果投放不用。

**CTOR（点击打开率）vs CTR：**都是**邮件营销**指标：CTR = 点击人数 ÷ 送达总数（看整封邮件综合表现）；CTOR = 点击人数 ÷ 打开人数（剔除没打开的人，专看邮件内容/CTA 质量）。团队不做邮件营销，**知道和广告 CTR 不是一回事即可**。
