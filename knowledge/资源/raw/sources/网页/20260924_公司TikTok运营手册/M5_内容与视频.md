## 5.1 流量逻辑：兴趣电商与流量池赛马

- 章节ID：`f3e99b68-05d3-486b-b189-e6ee742fd8c8`；原站版本：2；原站更新：2026-09-06T21:29:38.740441+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

TikTok 不是亚马逊那种「人找货」的搜索电商，而是**「货找人」的兴趣电商**——内容是钩子，先激发兴趣再产生购买。平台算法的核心目标是**最大化用户停留时长和平台总 GMV**，它像一个永恒的「赛马机制」：每条视频先丢进小流量池，数据好就推进更大的池。

表 5-1 TikTok 流量池层级（参考值，平台持续调整）

| 流量池 | 播放量级 | 进池靠什么 |
| --- | --- | --- |
| **基础池** | 200 ~ 500 | 新视频的初始曝光，人人有份 |
| 一般池 | 1,000 ~ 5,000 | 完播、互动达标 |
| 中级池 | 1万 ~ 5万 | 互动率、[CTR](#g-ctr)（挂车点击）跟上 |
| 高级池 | 10万 ~ 50万 | 分享转发 + 转化数据 |
| 终极池 | 100万 + | 带货视频看 [GPM](#g-gpm)（千次播放成交额），GPM 高系统给源源不断的推荐 |

**赛马的加权顺序：**完播率 > 互动率（点赞/评论/分享/收藏）> 点击率（CTR）；**分享转发是隐藏王牌**——分享意味着内容成了用户的「社交货币」、带来新用户，权重极高。视频进入精准商业流量池后，GPM 和转化成本成为核心考核。

**一句话：**你所有内容工作都围绕「优化这些指标」展开——拍视频、剪片子、挂车，每做一个动作都要想清楚：这能提升哪个指标？

## 5.2 流量池晋级判断：视频凭什么进下一轮自然流

- 章节ID：`a529fcc3-dc0b-4454-bd65-e3608a8e00bf`；原站版本：2；原站更新：2026-09-07T17:24:39.796569+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**一句话主旨：**TikTok 没有官方固定晋级门槛，自然流是一轮一轮的测试；**播放量是结果，不是晋级条件**。

##### 1. 破除误区：「300→3000→1万」不是官方规则

- 300 / 3000 / 1万 / 10万 / 百万只是运营方便复盘的**经验分层**，不是写死的门槛。

- 国家、类目、用户群体、账号状态、内容竞争度、发布时间都会影响实际分发。

- 该问的不是「我现在多少播放」，而是「**这一轮测试里我的视频表现是否足够优秀、值得扩大分发**」。

##### 2. 系统在看什么：内容消费数据

- 观察停留、完播、点赞、评论、分享、收藏。

- 播放 1000 但用户几秒划走 → 难扩大；播放 1000 但停留长、完播高、互动强 → 仍可晋级下一轮。

##### 3. 挂车视频要多看一个维度：交易表现

表 5-1 挂车视频双维度表现口径

| 维度 | 指标 | 回答的问题 |
| --- | --- | --- |
| **内容表现** | 停留 / 完播 / 点赞 / 评论 / 分享 / 收藏 | 用户愿不愿意继续看？ |
| **电商表现** | 商品点击 / 商品页访问 / 加购 / 成交 / 转化率 / GMV | 用户看完愿不愿意买？ |

##### 4. 挂车视频三种故障的诊断流

- **播放很低** → 先查视频本身（前 3 秒吸引力、开头是否太慢、用户能否马上看懂、节奏是否拖沓、内容与目标人群是否相关），**不要急着改价格**。

- **播放不错但没人点商品** → 购买动机不足：查痛点、场景、产品价值、购买理由是否讲出来。例（运动恢复拖鞋）：只说「这双拖鞋很好看」用户只看不买；改成「跑完步最不想做的就是继续穿硬底鞋」+ 展示换鞋→足弓支撑→缓震→行走，购买动机完全不同。

- **点击多但成交少** → 问题已从内容端转移到商品端：查价格、优惠力度、评价、基础销量、主图、详情、SKU、尺码、配送时间、售后政策。口诀：**点击解决的是兴趣，成交解决的是信任和购买条件**。

##### 5. 最容易被误判的素材

- 5000 播放出 10 单 vs 10 万播放出 3 单：新手会淘汰前者——**错的**。前者流量小但人群精准，后者流量大但购买意愿弱。

- 做 TikTok Shop 不能只追求爆播放，要看**单位流量能不能产生交易**。

**晋级逻辑一句话：**自然流不是「达到某个播放量就晋级」，而是每一轮测试中内容表现和用户价值足够好，系统才有动力继续扩大分发；挂车视频内容表现决定「愿不愿意看」，商品表现决定「愿不愿意买」；广告可以增加付费曝光，但不能简单替代自然内容质量。流量池赛马的整体框架见 [5.1 流量逻辑：兴趣电商与流量池赛马](#m5)，数据复盘口径见 [M7 数据与复盘](#m7)。

- 定位三问：卖什么品类、给谁看（印尼年轻女性/家庭主妇）、什么内容形式（测评 review、教程、剧情、好物 spill）。

- 团队验证有效的人设方向：**测评/好物种草号（review & spill 系）**——真实感、口语化、像闺蜜推荐；广告数据显示这类账号（review.and.spill、Miss Review 等）是出单主力。

- 主页栏目化：固定 2-3 个内容系列，让算法和用户快速识别账号标签。

**大白话：review 和 spill 是什么？**review 就是「测评/试用」——拍一条视频试用某个产品、说好或不好；spill 来自英语俗语 "spill the tea"（爆料/说悄悄话），在短视频语境里就是「好物分享、种草推荐」，像闺蜜跟你说"这个我用了真不错"。**review.and.spill、Miss Review 是团队已经跑出成绩的测评系账号名字**，不是什么工具或功能——新人起号照这个方向取名、做人设即可。

## 5.8 素材从哪来：卖点 / 话题 / 文案 / 画面挖掘法

- 章节ID：`ede26878-832e-479a-945d-41608e96b505`；原站版本：6；原站更新：2026-09-08T15:04:01.549+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**① 视频卖点（关键词）怎么找：**分三类词铺开——**准确词**（产品名称、功效、成分）、**相关词**（和准确词相关的）、**联想词/延伸词**；去三类平台搜：文字类、图片类、视频类。搜的时候用**可视化的短语或句子**，越白话越好，减少专业名词和成语俗语；多用**问句法**：「为什么……」「……怎么办」「经常……」「……有什么危害/会有什么反应」。

**② 视频话题怎么找：**按四个圈扩大范围——同产品爆款视频开头 → 同功效产品爆款开头 → 同品类爆款开头 → **不同类目但相同功能/效果**产品的爆款开头；外加刷**评论区**（用户原话就是最好的选题）。

**③ 视频文案怎么找（四档）：**原爆款文案直接用 → 原爆款文案删减 → 替换产品名称 → 爆款文案仿写。

**④ 视频画面怎么找：**用功能功效关键词搜画面（官方叫法、科普叫法都搜；**倒推画面法**——想要什么效果就搜什么场景），也用产品名称关键词搜。典型问句：「XXX 有什么作用」「缺了 XXX 身体会发生什么变化/有什么危害」「吃什么可以缓解 XXX」。

**音频复用红线：**直接搬爆款音频，被复用次数多了限流概率大；正确做法是**提取爆款文案结构和话术节奏，自己重新录制（可用 AI 配音）**，单纯变速、加背景音只是杯水车薪。

**⑤ 老素材稳定时，新素材走三个「不撞车」方向（换模型而非换包装）：**同一卖点、不同下单动机的素材，系统会判定为另一类人；「状态→使用→时间→发现变化」的内容型成交路径与「痛点→方案→结果→下单」的卖货型成交路径，系统不放在一起赛马。

表 5-9 三个不撞车的新素材方向

| 方向 | 打法与结构要点 | 角色 |
| --- | --- | --- |
| **① 身份切入型** | 不说「产品好」，说「我是某一类人，我在用它」（如「我是每天给别人化妆的，最怕的不是妆不好看，是妆不服帖」）；开头是身份不是痛点，系统优先分发给身份相关人群；后半段只讲「为什么这个身份会选它」。适合达人日常、从业者、伴侣视角、使用者自述 | **拉新池**；哪怕数据不炸，也容易被系统当新模型养 |
| **② 情绪动机反转型**<br>（成功率极高、最易被忽略） | 卖点不变，换下单的心理动机：老素材走焦虑路线（怕不好/怕错过/怕变差），新素材换成省事、安心、不折腾、避免浪费（「保湿不够后面全是问题」→「我现在护肤只留这一个，不想再试来试去」）；开头否定焦虑，中段只讲一个「留下它的理由」，结尾不催单而是「我为什么不换」 | **吃补量** |
| **③ 过程记录型** | 不马上卖、不马上证明，先记录变化（「我本来没打算推荐这个，但用到第三天感觉有点不一样」）；结构「状态→使用→时间→发现变化」，系统视为内容型成交而非卖货型成交；中段强调时间（第几天、哪里变了）而非效果；结尾不需强转化、可留模糊表达 | **养模型**；前期起量慢，但被系统吃透后很稳 |

组合打法：老素材继续跑，三条路同时铺——身份型拉新池、情绪反转型吃补量、过程记录型养模型；某一条稳定出单后再给资源，不要指望单条新素材一上来干掉老素材。

**⑥ 老元素重组：最稳的新素材不是全新创意。**把跑过量的素材拆开看，反复成立的从来不是「某条视频」，而是其中某几个固定元素的组合——用已验证元素重新排列组合，比上完全没跑过的想法稳得多。

- **健康迭代公式：**保留成功逻辑、持续换表达——保留爆款卖点/节奏/人群，换开头钩子、场景、冲突、人设、情绪方向（同一卖点换不同场景/情绪/开头/痛点表达，系统视为新的内容信号）。

- **危险的伪迭代：**只换字幕、换 BGM、镜头重剪、换人念口播，核心结构完全没变——系统看到的是同样信息反复输入，不会扩量。

## 5.10 爆款素材拆解方法：三层拆解法——抄因果链，不抄表象

- 章节ID：`812c148c-fa93-4e72-b9f4-037391306fdd`；原站版本：2；原站更新：2026-09-07T17:24:40.316476+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**一句话主旨：**拆解竞品素材时，90% 的团队死于「表面模仿」——扒下跑得好的视频照着拍，结果水土不服。真正该抄的不是表象（只占成功因素约 10%），而是成功背后的**因果链条**；它需要一层一层往下挖。

##### 1. 三层拆解金字塔

表 5-4 素材拆解的三个层级

| 层级 | 拆什么 | 价值占比 | 复制难度 |
| --- | --- | --- | --- |
| **表层创意** | 看得见的素材、文案、落地页 | 约 10% | 最低（截图就能抄） |
| **策略逻辑** | 看不见的定价、路径、时机 | 约 30% | 中（要推理） |
| **底层系统** | 数据、归因、组织与迭代能力 | 约 60% | 最高（难复制） |

拆解时先自问：我现在停留在哪一层？多数团队的产出（素材跑不动、改版不如从前）就停在第一层。

##### 2. 先有弹药：爆款脚本的四个出处

拆解的前提是手里有值得拆的素材，四个稳定弹药库：

- **TikTok Creative Center（官方创意中心）：**官方免费库，按行业、目标（转化/曝光）、地区筛选高表现广告素材，能看到投放数据（曝光、点击、成本区间），是判断「什么素材值得抄结构」的第一入口。

- **第三方数据平台（如 FastMoss）：**看品类爆款视频榜、带车视频销量榜，直接对标「同品类里谁在出单」。

- **跨平台搜索（抖音 / 快手 / 小红书）：**同一爆款素材常跨平台流转，国内验证过的钩子和脚本结构，改口音和场景即可本地化复用。

- **关键词最热视频：**搜品类核心词、按点赞排序看近期最热内容，判断当下用户对什么表达方式有反应。

##### 3. 第一层：解构表层创意（视频拆解的核心实操）

拿到素材先做**五维拆解**，把一条视频拆成可复用的结构表：

表 5-5 爆款脚本五维拆解表

| 维度 | 拆解要点 | 记录产出 |
| --- | --- | --- |
| **开头钩子** | 前 3 秒用什么抓注意力（冲突 / 悬念 / 反常识 / 结果前置） | 钩子类型 + 原句 |
| **痛点挖掘** | 击中的用户焦虑或渴望，是否具体到场景 | 痛点一句话 |
| **解决方案<br>产品植入** | 产品在第几秒出现、以什么方式植入（演示 / 对比 / 口播） | 植入时点 + 方式 |
| **信任背书** | 用了什么建立信任（实拍 / 数据 / 证书 / 用户证言） | 背书形式 |
| **CTA 引导** | 结尾如何引导点击 / 下单，话术是什么 | CTA 原话 + 时长 |

五维表之外，再带三个深挖动作：

- **视觉钩子分析：**截取素材**前 3 秒**的画面，逐帧标注出冲突点、好奇点、情绪点。例：进度条卡在 99% 制造焦虑、前后对比图制造震撼。

- **文案结构拆解：**把口播/字幕整理成「**痛点 → 方案 → 结果**」三段式，并记录具体用词——用「终于」还是「竟然」？数字是精确值还是约数？这些微差往往决定转化。

- **转化路径还原：**画出从视频到下单的完整流程图：数清步骤数，记录每个按钮的位置、颜色、文案，找到转化断点。

##### 4. 第二层：逆向推导策略逻辑

看完创意继续追问：**对手为什么这么做？**这一层靠推理而非截图，标准动作是「观察现象 → 提出假设 → 小范围测试，让数据说话」。

- **卖点与定价：**分析价格锚点、折扣时机、涨价/降价节点背后的决策门槛设计。

- **用户路径：**还原从触达到付费的完整旅程，标出关键决策点在哪里被促成。

- **变现时机：**记录挂车/口播引导/付费动作出现的时点与间隔，推断节奏设计。

三问递进：看到的是 **What**（卖什么、什么画面），推导的是 **Why**（为什么这么卖），验证的是 **How**（自己小范围测什么）。

##### 5. 第三层：推理底层系统能力

最看不见却最致命的一层：数据埋点、归因系统、测试流程、组织协同、决策速度、迭代频率。可通过外部信号推测：

- 对手 7 天内换了 3 版素材 → 有成熟的素材生产流程与快速决策机制；

- 落地页随用户来源变化 → 有动态参数传递与实时渲染能力；

- 同时在多个渠道跑不同创意 → 有较强的归因体系与预算分配逻辑。

这层短期无法复制，但应识别哪些能力「必须有」、哪些可暂时用人力替代，分阶段补齐。

##### 6. 从拆解到产出：25 秒万能结构与制作红线

拆完别人的，用这个结构快速产出自己的版本：

- **0–3 秒：**强钩子（冲突 / 悬念 / 结果前置）

- **3–10 秒：**放大痛点，让用户对号入座

- **10–20 秒：**给出方案——产品植入 + 信任背书

- **20–25 秒：**效果呈现 + 行动号召

**制作红线：**绝对避免开头 5 秒没有信息量、避免产品出现太晚、避免 CTA 模糊；BGM 跟随视频情绪起伏，在钩子和转化点处加节奏变化。

##### 7. 找对标：4 个维度缺一不可

- **阶段相似性：**用户规模、收入体量、发展阶段相近——拿初创项目对标成熟品牌，结论一定是错的。

- **模式可迁移：**看变现模式、获客方式、内容形态的相似度，而非表面行业分类。

- **数据可观测：**优先选投放动作频繁、素材可抓取、榜单有数据的对象。

- **持续观察期：**至少追踪 30 天以上，看策略变化与迭代节奏，避免被短期行为误导。

##### 8. 把拆解变成日常：最小竞品情报系统

- **建立监控清单：**选 3 个阶段相近的对手，固定追踪其素材与店铺动作。

- **定期复盘：**每周做一次深度扫描（素材频率、效果、主推品、核心卖点、内容框架），每月做一次趋势复盘。

- **按层分工：**创意层看钩子和文案，策略层看卖点和定价，系统层看迭代频率。

**落地节奏建议：**每周用三层法拆 1 次、每次 1 条跑量素材，坚持一个月，对「什么素材能跑」的判断会明显不同。拆解产出直接进入「模仿 → 测试 → 量化 → 复制」的生产循环；测试后的视频能否进下一轮自然流量池，判断口径见 [5.2 流量池晋级判断](#5.2)，数据复盘口径见 [M7 数据与复盘](#m7)。本节方法为通用框架，整理自外部资料（原文含的工具推广内容已剔除）。

## 5.14 带货视频制作

- 章节ID：`d8c06716-47bc-40c0-b200-0f999400f777`；原站版本：4；原站更新：2026-09-08T15:04:55.413+08:00。

- **脚本公式：**痛点钩子 → 产品出场 → 使用展示 → 效果对比 → 价格/赠品 CTA（引导点小黄车）。

- 拍摄要点：本土化场景、真人出镜/手部特写、功效可视化（前后对比、实测过程）；印尼语口播，口语化。

- **前 3 秒定生死：**广告数据实证——出单素材商品点击率（[CTR](#g-ctr)）约 1.2%，零单素材仅 0.4%，差距主要在开头钩子和挂车引导。痛点场景开场，不要产品介绍开场。

- 时长与节奏：铺垫压缩到第 3-5 秒内出产品/效果；带货视频要的是点击下单，不是完播，口播+箭头明确引导挂车。

- 合规：口播和字幕过 2.10 违规词库（不说 menghilangkan/ampuh/obat 等），不做绝对化承诺。

- 一条好带货视频的标准：看完知道**卖什么、有什么用、多少钱、去哪买**。

**① 行为节奏时间轴（广告素材与自然内容通用）：**

表 5-7 3 · 10 · 30 秒行为节奏：前 3 秒留住人 · 前 10 秒产生感觉 · 前 30 秒出现行为

| 时间点 | 任务 | 怎么落地 |
| --- | --- | --- |
| **前 3 秒** | **留住人**（一个素材行不行 90% 看开头） | 强视觉冲击画面（产品特写、使用效果、前后对比，动态 > 静态）、反差画面、引发好奇、共鸣提问句（痛点说得越具体越容易出单：「很多人都有这个问题」用户没感觉，「我就是这个情况」才会停下来）、高能动作、情绪瞬间；前 3 秒还要有**人群筛选能力**——不追求泛点击，让内容本身带明确购买信号 |
| **前 10 秒** | **产生感觉**（情绪决定行为密度） | 钩子抓住人后不要立刻上产品，把痛点放大一层、唤起情绪共鸣（「太懂了」），后面推产品才顺理成章；系统决定是否继续放量看的是行为密度（继续观看、点赞、评论、点详情页） |
| **前 30 秒** | **出现行为**（点击/加购/下单） | 卖点场景化给认可感 → 消费刺激（限时价格、库存紧张、专属福利）→ 明确转化引导；互动密度达标后系统才进入下一阶段测试——转化承接能力 |

**② 单卖点原则：一条素材只攻击一个点。**

- 素材清晰度 × 信号强度 = 起量效率：卖点越杂，系统越难判断核心人群、学习越慢；在 GMV Max 里**明确比丰富重要、聚焦比全面重要、锋利比堆砌重要**。

- 可以做多条素材，但不要在一条素材里讲完所有卖点：**卖点 A → 素材 1、卖点 B → 素材 2、卖点 C → 素材 3**；多卖点拆分可按情绪型 / 工艺型 / 场景型 / 人群型 / 价格型各拍一条，每条只输出一个核心信号。

- 中段主推一个核心卖点并贯穿全片，按人群说话：实用型强调功能/安全；颜值党强调质感/颜色/设计；性价比人群强调价格/对比/节省；痛点人群强调「解决问题」「更方便」。

- **上线前自检三问：**① 这条视频只想让人记住什么？② 如果删掉 80% 内容，剩下的核心是什么？③ 系统会给这条素材贴什么标签？——回答不清楚就说明卖点太杂。

**③ CTA（行动引导）位置：不放开头、不只压最后。**

- **不放最后**：大部分用户不会看完视频，CTA 放最后等于把成交机会交给留存率最低的一批人——这是播放不错但点击率起不来的常见原因。

- **不放开头**：用户刚刷到时还没看到价值、没建立信任，上来就让买只会引发抗拒。

- **最佳位置 = 用户已被吸引但还没流失的节点**，即核心价值点之后（用户已感受到价值、开始对产品有兴趣，此时引导点小黄车/点链接转化率最高）；脚本结尾仍要有清晰指引收口——两者互补。CTA 位置还影响系统放量判断：合理位置能更早拿到商品点击、页面进入、成交信号。

**④ 爽点素材四类型（带货视频的情绪发动机）。**爽点不是剧情刺激、画面炫，而是精准触发用户情绪、让用户产生心理满足感和瞬间共鸣——用户关心的是产品能让自己生活更轻松、更好看、更痛快。

**⑤ 低客单快速转化打法（印尼美妆/保健重点）。**低客单流量便宜、用户决策快，核心是「一眼抓住痛点 + 快速触发购买行动」：

- **内容侧：**每条素材只输出一个核心卖点（牙刷→强洁净、漱口水→清新口气、美妆刷→柔软上妆快），核心卖点直接放**开头 3 秒**，一秒明白商品价值，避免铺垫或复杂叙事；用大白话、避免行业术语（不说「高分子纤维」，说「柔软不掉毛」）；短句 + 强刺激（「3 秒刷干净牙齿」「一喷清新一整天」）；场景化展示（上班族早晨、宝妈外出、户外运动），用户看到就知道自己会用在哪儿。

- **情绪与转化侧：**前 3 秒就是亮点（产品特写、使用效果、前后对比），视觉冲击 + 情绪化文字 + 节奏音乐音效三者同步；明确行动指引（「点链接立刻购买」「立刻加入购物车」）；**紧迫感/稀缺感**（限时、限量、今日特价）——小金额商品用户对紧迫感敏感度高；明确结果展示、立刻见效快速满足（刷完牙齿白了、上妆快又均匀）。

## 5.18 内容数据基准与 A/B 测试

- 章节ID：`ef0e6492-205b-4777-bcfc-67984f6fd3fd`；原站版本：2；原站更新：2026-09-07T17:24:40.82111+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

发布后按阶段看数：**自然流阶段**重点前 3 秒完播率和整体完播率（低=开头/结构问题）；**GMV Max 抓取后**重点 [CTR](#g-ctr)（小黄车点击率；播放高但 CTR 低＝内容有趣但产品引导失败）；**持续观察** [CVR](#g-cvr)（CTR 高 CVR 低＝落地页/价格/信任建设问题，转 M2）。

表 5-6 短视频核心数据参考基准（行业参考 + 团队实测）

| 指标 | 合格/优秀线 | 低了说明什么 / 怎么优化 |
| --- | --- | --- |
| 前 3 秒完播率 | > 50% | 开头钩子不行：更强视觉冲击、更直击痛点的文案 |
| 整体完播率 | > 20%~30% | 节奏拖沓：加快剪辑、每 2-3 秒一个画面、删冗余 |
| 互动率（赞+评+转+藏/播放） | > 5% 良好，> 10% 优秀 | 埋话题点引发评论、埋干货点促使收藏 |
| 分享率 | > 1% 即不错 | 做「利他」内容（实用技巧）或情绪内容 |
| 点赞率 / 评论率 | 点赞 > 3%，评论 > 0.5% | 内容共鸣度不足 |
| **挂车 CTR** | 行业 2%~3%；**团队出单素材实测约 1.2%，零单素材仅 0.4%** | 引导话术不明确：价值承诺要具体（「点这里省 50%」>「点这里看价格」） |
| [GPM](#g-gpm) | 无上限，越高越好 | 千次播放成交额，综合优化以上所有指标 |

**A/B 测试铁律：每次只测一个变量。**测不同开头（痛苦表情 vs 产品特效，看完播和 CTR）、测不同信任背书（成分 vs 专家，看 CVR）、测不同 CTA（半价 vs 赠品，看转化）。不要凭感觉，用测试数据说话。操作闭环：发布视频 → 观察自然流数据（完播/互动）→ 投流测试 → Ads Manager 分析 CTR/CVR → 定位问题（吸引不了点击还是转化不了）→ 针对性迭代下一条。

## 5.19 视频生命周期模型：自然+付费双曲线与阶段动作（校准版）

- 章节ID：`f528d913-d423-4c46-8102-5a914674d637`；原站版本：1；原站更新：2026-09-23T11:30:47.647593+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

**一句话主旨：**每条带货视频都有生命周期——**冷启动 → 起量 → 爆发 → 稳定 → 衰退 → 长尾/沉默**。用「每天的自然播放/GMV 增量 + 广告花费增量」给视频打阶段标签，**广告只在起量期介入、衰退期停投**，不要全程无脑烧钱。阈值来自真实回测：16 店 × 49 天 × 6,914 个视频、34,037 条视频×日记录（2026-09-22 校准）。

##### 1. 怎么读双曲线

- **绿色实线**＝自然播放/GMV 增量；**棕色虚线**＝广告花费（付费介入）。

- **付费驱动型：**广告线全程高企、自然线一直在低位——一关广告就没量，内容本身没跑出来。

- **内容驱动型：**自然线自己往上爬——内容真的好，广告只是放大器；这类视频要重点追拍。

- 关键看点：广告在「起量」介入、「衰退」停投。示意曲线（非真实数据）如下。

        冷启动
        起量
        爆发
        稳定
        衰退
        长尾

        自然播放/GMV 增量
        
        广告花费（付费介入）

##### 2. 阶段判定规则与动作建议（校准版阈值）

表 5-6 视频生命周期六阶段（+沉默）判定与动作

| 阶段 | 判定规则（校准阈值） | 动作建议 |
| --- | --- | --- |
| 冷启动<br>置信度 低 | 发布 0–48h；日曝光低位；无消耗或日消耗 < 预算 30%。**依据：**48h 窗口仅对真正新发布视频成立（占首现样本 55.6%），窗口暂保留待复核。 | **观察不动；**48h 后附首份漏斗诊断（2s/6s/CTR 对比同类目中位数）。 |
| 起量<br>置信度 高 | 连续 2 天日曝光环比 **> +83%**，**且日曝光 ≥ 3,000**；广告开始介入。**依据：**+83% ＝有效视频日环比 P90，连续 2 日频率仅 0.8%（稀有真信号）；初版 +50% 单日频率 16.1% 太常见。 | 提示运营 **可小额测试加投**；同步记录达人与内容类型，供爆发后追拍复用。 |
| 爆发<br>置信度 高 | 日曝光 **≥ 12,000** 或日 GMV **≥ 500rb**，持续 ≥ 2 天；付费+自然双高。**依据：**取活跃视频（峰值曝光 ≥1,000，n=785）窗内峰值 P75；初版曝光 3 万仅 P89.4、GMV 5000rb=P100 无一触发。 | **加投 + 催达人追拍同系列 + 关联品挂载；**每日监控漏斗是否随放量劣化。 |
| 稳定<br>置信度 高 | 高位平台（曝光 ≥ 自身峰值 50%），日波动 **±40%** 以内持续 ≥ 3 天。**依据：**高位平台日 \|环比\| P80=38.9%（n=1,569）；初版 ±25% 仅覆盖 58% 高位日，频繁打断判定。 | **维持预算，监控 ROAS 拐点；**波动连续超带即转入衰退观察。 |
| 衰退<br>置信度 高 | 连续 3 天日曝光环比 **< −46%**。**依据：**−46%＝连续日环比 P25，连续 3 日频率 1.4%；初版 −20% 单日 44.8%、连续 3 日 5.1% 几乎是常态波动会天天误报。 | 按是否仍盈利分级：**降预算 / 停投；**附衰退诊断（区分内容衰退与商品页/竞争问题）。 |
| 长尾<br>部分待回填 | 广告停投 ≥ 7 天（已校准），自然播放仍 > 500/天且有自然出单（待回填）。**依据：**7 天内回流率 88.9%（≤10 天 94.0%），7 天线放过绝大多数假停投；自然播放/出单线依赖联盟历史快照暂不可校准。 | **零成本利润，标记为可翻拍内容资产；**触发达人续约 / 同脚本翻拍建议。 |
| 沉默<br>待回填 | 自然播放 < 200 且 0 单连续 7 天。**依据：**同样依赖联盟自然侧历史暂不可校准；付费侧代理信号＝视频从日快照连续消失。 | **归档，不再投入；**沉淀失败原因标签（钩子弱/导购弱/品问题），反哺选品与选人。 |

**回测实测发现：**大量「广告曝光连续多日为 0、但每天仍稳定出单 10–40 件」的视频（如 45 天龄视频零曝光日 GMV 仍有 100–250rb）——**长尾价值真实且不小**，应优先补联盟自然侧快照，否则这部分价值在系统里完全隐身。

**使用边界：**每槽快照仅抓到报表第一页（约 top 20–60/店），样本偏向有量视频，绝对量阈值（爆发线/起量绝对线）对「未进入投放视野」的视频偏乐观；比率类指标（CTR/CVR/环比/稳定带）受偏差影响小。观察窗仅 49 天，31 天以上长周期估计待新数据滚动修正。GMV 单位 **rb**＝千印尼盾（500rb＝Rp500,000）。
