## 6.1 广告产品体系：团队为什么只跑 GMV Max

- 章节ID：`742898a5-49bc-4bb3-bd05-8edb4c830af7`；原站版本：2；原站更新：2026-09-06T21:29:38.815547+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

- **GMV Max（团队绝对主力）：**智能投放产品，绑定店铺/商品后**系统自动选人、自动从店铺挂车视频（自营 + 已授权达人视频）里挑素材投放**，不用手动建定向，适合几十家店规模化跑量。**团队现阶段全部预算走 GMV Max。**

- **手动 Ads 已经没有了：**平台已下线手动建广告组/手动出价那套产品，**团队全量预算走 GMV Max**——设好 ROI 目标和日预算后，系统跨版位自动竞拍、动态调价、找高转化人群，「一拖多」动态分配预算，实时把钱挪给当下回报最高的商品，追求全店 GMV 最大化，省心且全局最优。

- 直播 GMV Max（给直播间引流）做直播时再用，见 3.6 / 6.10；现阶段以短视频 + 商品卡广告为主。

- **给运营的结论：**新店/新品一律 GMV Max 冷启动；本模块除特别说明，操作和数据都以 GMV Max 为准。

**① 流量分发的底层：[ECPM](#g-ecpm) 竞价与五层筛选漏斗。**

公式：**ECPM = [CTR](#g-ctr) × [CVR](#g-cvr) × Bid × 1000**（CTR 能不能把人吸引住、CVR 点进来能不能成交、Bid 愿意给平台多少钱）。卖家不是在买流量，而是在参与「赚钱能力竞价」——平台只有一个底层逻辑：**谁更赚钱流量就给谁**；同样出价下，系统优先把流量给「能成交的人」而不是「能吸引点击的人」，不存在「被系统限制」。每条广告要过 5 层筛选：

表 6-14 ECPM 竞价五层筛选漏斗：系统在判断什么、过不去的后果

| 层级 | 筛选关 | 系统在判断什么 | 过不去的后果 |
| --- | --- | --- | --- |
| ① | **兴趣匹配** | 用户看过什么内容、点过什么广告、买过什么商品 | 不匹配直接不给曝光（入池资格） |
| ② | **初筛竞价** | 计算 ECPM，与竞争线比较 | 低于竞争线的计划只给零星订单 |
| ③ | **质量过滤** | 出片质量（清晰度/剪辑/节奏）、用户反馈（停留/划走）、投诉与违规风险 | 内容不过关直接限流——**很多人死在这层** |
| ④ | **内容混排** | 在信息流里与其他广告抢位置 | 位置靠后、曝光不足 |
| ⑤ | **最终排序** | 再次计算 ECPM | 谁更赚钱谁拿流量 |

平台评估素材主要看两样：预估点击率 eCTR（**开头决定能否抓住流量**）与出价竞争力；「系统喜欢」的素材 = 能持续消耗的素材。商业化广告流量池一般只占全站流量的 15%~25%，平台不会让广告过度泛滥。

**② 素材三阶段生命周期与人群红利。**

- 任何素材都经历三阶段：**冷启动探索 → 稳定放量 → 边际衰减**。系统先把素材推给最容易被打动、决策最快、转化成本最低的人；这批人不是无限的，被反复触达后「看过不点、买过不需要、看腻没感觉」，吃完后系统被迫向外层扩展——**外层人群转化意愿更弱、成本更高、对素材更挑剔**。

- **数据「突然崩」的本质是：素材没变，人变了。**衰退不是素材突然变差，而是人群红利被消耗；当 CTR、CVR 或 ROI 变差，系统还会把计划分配到更低质量的人群池，形成负循环。

- **计划突然没量 ≠ 人群耗尽：**TikTok 投放池非常大，中小预算计划突然没量，绝大多数是系统的动态调控，常见 4 种触发——① 素材评分下降（6 秒完播、CTR 等前端行为指标下降）② 支付样本不足（系统优化的是**支付行为**而非停留/点击，支付样本太少会主动降量）③ 人群疲劳（同一批高相关用户看过多次，系统先把流量分给新用户）④ 出价/预算触发（预算不足或竞争力不够，实时竞价中降低展示）。

**③ 人群四层流量：你在吃哪一层？**

表 6-15 人群四层流量：数据表现与系统状态

| 流量层 | 数据表现 | 系统在干什么 / 运营心态 |
| --- | --- | --- |
| **探索人群** | 有消耗但很不稳定、偶尔有点击没规律、转化忽有忽无、ROI 波动很大 | 在试「这条素材到底谁会有反应」。冷启动本来就不稳定，**别焦虑、别频繁操作** |
| **广泛人群** | 流量开始起来、CTR 看着还行、但转化不稳定，「有人看但不怎么买」 | 素材能吸引人但还没筛出会买的人，系统在大池子里继续试 |
| **潜在转化人群** | 转化开始稳定、ROI 慢慢接近目标、出单有节奏 | 系统大概知道哪类人更易买，预算往这类人倾斜——计划「刚刚跑顺」 |
| **高价值用户** | 出单稳定、ROI 稳定、放量顺；可能 CPM 不低但整体赚钱 | 已筛出最易转化、最有价值的一批人 |

**不是系统在帮你找人群，是你的素材在帮系统筛人群：**GMV Max 没有传统人群定向，靠素材内容 + 用户行为识别人群。素材强时，不对的人自己划走、对的人停留/点击/转化，系统顺着数据越筛越精准；**一条视频卖点杂乱（颜值、价格、功能、人群、场景全讲）会给系统混合信号** → 人群标签建不起来、学习周期拉长、消耗变慢（单卖点原则见 5.8）。

**④ 冷启动真相与「没进池」。**

- 冷启动不是「新计划前几天」，而是**系统尚未确认「该广告组合在预算放大下能持续产生稳定 GMV」的内部状态**：计划可以新建但不冷启动，老计划也会因素材大换血、价格/库存/履约变化、竞争波动、预算大幅跃迁重新进入冷启动。**学习期（产品层提示）结束 ≠ 冷启动结束。**

- **冷启动结束的信号不是 ROI 好，而是「扩量后 GMV 仍然成立」**：加预算后 GMV 成比例增长、ROI 波动可控、系统开始集中流量而非随机试探。

- 冷启动期有消耗 ≠ 有效流量——很多消耗只是系统在「测试素材」而非卖货；**消耗 → 数据量 → 模型质量 → ROI 上限**是一条传导链，没有消耗就没有学习样本。

- **「没进池」与「没量」是两回事：**计划一直小消耗、没单、流速慢像卡死，多数是前期小范围测试数据不达标（CTR 不行、停留不行、转化反馈差），系统没确认这条内容值得给量——放量逻辑是谁先让系统确认「能稳定赚钱」谁先拿量，不是谁先开计划谁赢。

**⑤ 付费带自然：GMV Max 后期真正的价值。**

- **闭环机制：**广告先把内容和商品推给更多人，用户后续通过搜索、主页、推荐流再次成交（刷到广告没买 → 自然流再看到下单 / 主页搜商品 / 收藏回购）；自然数据变强后商品权重提高、转化标签更稳，广告侧 CTR 更高、CVR 更稳、ECPM 更强——**自然反哺付费**。

- 冷启动期系统会同步判断内容是否具备自然分发潜力：一眼是话术、强刺激、强转化的内容，从第一层起就只被当成「靠钱跑的素材」；**能带自然流的广告前期往往并不爆单，但数据非常稳定**（成交节奏均匀、转化曲线平、退款异常少）。视频卖点、商品卡信息、用户实际体验三者一致，是自然流放大的关键前提（量化基准见 6.11）。

**存量对抗时代的运营定位：**流量没变少，但做广告的人成倍增加，已从「能投就有量」变成「要赢才有量」。GMV Max 下流量分配完全自动化——系统自动找人、自动测试、自动放大或淘汰，**运营唯一能影响的变量是「给系统什么样的素材和结果」**：素材决定入场资格（点击率不够连测试机会都没有）、转化决定能否被放大（系统不因点击高给量，只看这波流量有没有产生 GMV）、模型决定能否持续拿量（有历史成交、标签清晰的账户系统更愿意给流量）。

## 6.3 GMV Max 计划搭建 SOP

- 章节ID：`1d684e3c-484d-4bb3-a292-d6c534b337ec`；原站版本：1；原站更新：2026-09-07T17:24:41.057025+08:00。
- 来源：[原站章节](https://tkshopshouce.coze.site/manual)；正文状态：complete；附件另行登记。

在对应店铺广告后台新建 GMV Max 计划，全程注意下面几个团队实测坑：

- **进后台先关弹窗：**页面顶部的 **Got it** 提示条先关掉，否则会遮挡下方操作元素，导致按钮点不到。

- **计划命名规范：**店铺/主体 + 商品 + 日期 + 策略，例 SHUMA_睡眠贴_0901_冷启；多店多计划全靠名字区分，不许用默认名。

- **绑定商品：**选要推的商品（PID 对齐货盘表），商品必须是**在售、有库存、挂车可售**状态。

- **素材：**GMV Max 自动抓取店铺挂车视频，不用一条条手动传；**想让达人视频也能投，必须先拿到达人广告授权（Spark Ads 授权码，见 4.9）**，否则该视频在报表里就是 Authorization needed 投不出去。

- **设 ROI 目标和日预算：**按 6.4 团队统一参数——**ROI 目标统一设 7、新店日预算 $200**，不拍脑袋。

- **提交后进入学习期：**状态 Exploring，**2-3 天内不频繁改动**（每次大改都会触发重新学习）。

**后台操作三个实测坑：**① 元素点不到/找不到时，**先在页面里往下滚动（最多滚 10 次）**再判断，很多内容是懒加载；② **Analytics（数据分析）入口是没有链接的 SPAN 标签**，不是普通菜单，按计划名关联定位；③ 广告后台是持续加载的动态页面，操作慢一点、等页面刷出来再点，别连点。

**搭建时两个结构细节（决定系统敢不敢花钱、学得快不快）：**
① **「老带新」结构：老素材托底 + 新素材测试。**老素材是已完成风险评估的转化路径，系统清楚哪些人会点会买、敢用它抢量；**不要一次性把老素材全换成新素材**——系统同时面对多条未知路径、感知人群漂移，往往直接收量。新素材可挂在成熟计划下 **3-5 条**借老模型测（信号传播更快）；新素材要「像老素材」：商品一致、转化逻辑一致、使用路径一致，只在情绪、画面、节奏上变化，系统视为已知路径的轻微变体。
② **投放时段是扰动最小的调整方式。**后台可设投放时段时，起量期限定高活跃时段（WIB 晚间）投放——时段本质是「输入样本过滤」，样本一致性高、模型收敛快；24 小时不限时段会让系统混合学习高低活跃时间特征，GMV 起得快但放不稳。各类调整扰动级别：**改 ROI = 改目标函数；改预算 = 改探索强度；换素材 = 改输入结构；重启计划 = 重置学习（触发完整冷启动）；调时段 = 只过滤样本、扰动最小**。

**真实案例（某店 2026-08-29 导出，2401 条创意）：**

- **二八的二八**：82% 视频（1979 条）是 Ineligible 压根没投；真正跑过广告的只有 25 条，其中 **10 条贡献了 85% 的 GMV**（$126.8 / $148.4）。广告不是「每条视频都给机会」，是**海量铺素材 → 系统筛出个位数赢家 → 集中火力**。

- **Ineligible 两大原因**：Unavailable 1584 条 + **Authorization needed 370 条（15%）**——达人视频不拿广告授权，系统想投都投不了。**达人合作必须同步要广告授权**（写进 M4 寄样/邀约话术）。

- **决策动作四档：**ROAS≥2 且消耗稳定 → **加预算**（单次≤50%）/复制到关联店；ROAS 1~2 → 维持观察，改 CVR 端（商品页）；ROAS<1 或有消耗 0 单且过学习期 → **关停**；Ineligible → 按状态处理（授权/违规/视频状态），不在计划层面折腾。

- **介入 vs 不动（关键词「连续异常」）：**四种情况**不要轻易介入**——计划前 48 小时（学习期数据没成型）、ROI 只是短时波动（回传延迟/转化延后）、消耗和转化还正常、素材数据量还不够（样本不足），很多时候系统自己会修复；**必须介入**的是连续异常——长期空耗（有花费没成交、多轮无改善）、素材明显疲劳（CTR 持续衰减、前 3 秒流失增加）、人群严重跑偏（转化成本越来越高、成交人群不对、客单价下降）、CPA 连续失控、ROI 连续崩盘且亏损持续扩大（及时降预算或直接关停问题计划）。

- **一次只动一个变量：**预算、ROI 目标、素材不要同时大幅调整。**没转化时 90% 概率是素材问题**——改进顺序：先换素材（前 3 秒、CTR、情绪、痛点、转化表达）→ 再查商品页承接（价格/评价/详情/库存，转 M2）→ 最后才动计划参数；烂素材加预算 = 扩大亏损。

- **素材每日四分类筛查：**① **高消耗低转化**（花钱快、有点击、不出单，在吸泛流量＝持续空耗，最危险 → 及时处理/排除，见 6.12）；② **低消耗但 ROI 稳**（潜力素材，系统还在试人群 → 继续观察不急着动）；③ **CTR 高 CVR 低**（吸引错人：卖点太泛/内容娱乐化/商品承接不够，最易「假爆」→ 优化素材成交导向或商品页）；④ **稳定跑量素材**（稳定转化、ROI 可接受、波动正常 → **重点保护别乱动**，不要一看到稳定素材就想换素材、加预算、改 ROI）。

- **付费带自然一起看：**广告 ROI 高但自然接不住的店，实际利润可能很差；自然 GMV 占比、付费 vs 自然 ROI 差值、自然播放增长倍数三个量化基准见 6.11。

**③ 测素材三阶段判断法：**

- **一 · 系统愿不愿意给量：**看消耗速度、展现增长速度、CTR。长时间没展现、消耗特别慢、CTR 明显低于账户平均 → 系统兴趣不大，后面即使偶尔出单也难成主力。**注意：消耗快只代表系统愿意继续测试，不代表一定跑得出来。**

- **二 · 用户愿不愿意留下来：**看 3 秒留存、6 秒留存、完播率。CTR 很高但留存很差＝典型「强钩子、弱内容」，前期骗到点击、后期难稳定成交。

- **三 · 成交信号（决定生死）：**看商品点击率、加购率、下单率、ROI。CTR/播放/互动都好但系统不给量，原因就是用户不买。**不找爆款视频，找能持续帮系统拿订单的素材。**

- 不迷信绝对指标：CTR、完播、加购多少算好没有标准答案（高低客单、品牌/白牌、达人/硬广差异都大），要看**是否高于账户平均、高于近期素材平均、优于同类素材**——GMV Max 看竞争结果而非固定标准。

**④ 观察时长与样本量：别让素材「死得冤」。**

- 用样本量而不是时间判生死：不要跑几十美金就关、跑一天就删、看成本高立刻放弃——很多后来成为主力的素材前 24 小时甚至前 48 小时都不算优秀。**每条素材至少观察 24~48 小时**，看展现量、点击量是否足够、是否已拿到转化数据再下结论。

- **值得继续观察的三类：**ROI 接近账户平均但系统还在持续给量；CTR 一般但转化率明显更高（不吸引所有人、但吸引对的人，后期易成利润素材）；前期量不大但 ROI 持续改善（系统正逐步找到正确人群）。

- **应直接淘汰的：**持续空耗（有花费没成交、消耗一直增加但数据没改善）；点击高但长期不转化（CTR 高 CVR 低＝吸引错人，最容易「假爆」）；连续几天没有改善趋势、ROI 长期明显低于账户平均——问题不在学习期而在素材本身。

- 素材「死得冤」的三个外部原因（排查失败先查这些）：**曝光不够、被老素材压住、没给到正确阶段**——不是素材本身不行。

**⑤ 成本阈值与测试纪律：**

- 素材成本超目标 **1.5 倍** → 果断停；在目标 **1.2 倍**左右 → 继续观察、放一小部分预算验证模型反应（计划层红线仍以 6.4 CPA **$0.5~0.6/单、美妆 $0.3~0.5/单**为准）。

- **一次只测试 1~2 条新素材**：同跑太多素材会互相干扰转化信号、每条拿不到足够曝光；每次少量上、快速筛选、优胜劣汰；也可借成熟计划下挂 3~5 条新素材测（见 6.3 老带新）。

- 出现有效素材后集中资源放大，优先保障其流量和预算，让系统形成稳定模型。**拼命堆素材、用数量对冲不确定性** → 数据分散、难形成主力素材。

**⑥ 缩短学习期 / 提高通过率的 5 个实战法：**

- **自然流先测单，出单后再进 Max：**素材先发账号跑自然流量，哪怕只有几千甚至几百播放，只要能出一两单就证明转化逻辑成立；有出单记录再加进 GMV Max，系统识别到内容已有转化背书，学习期容错率大幅提高（同一条素材自然流爆过单后进 Max 很容易直接起量）。

- **单素材加热强行启动学习期：**自然流基础差或不想等慢测时，用 Creative Boost 给素材一笔固定小预算，让系统强行完成人群探索（建议完整 boost 2 天，见 6.7 表 6-2）；救不了真正劣质的内容。

- **用强信号缩短系统识别时间：**一条素材只输出一个核心信号（单卖点、单主张、单人群，见 5.8），系统更快建立人群标签；卖点混杂拉长学习周期。

- **老元素重组降低学习成本：**用已验证元素（某条开头冲突 + 另一条卖点表达 + 某条节奏音乐）组合新素材，每个组成部分系统都见过，人群匹配成本更低（见 5.13）。

- **达人供稿场景：**必须保留一组商家主导的锚点素材（商品一致、转化逻辑一致、节奏稳定）；控制同时进计划的达人素材数量、与达人沟通发布时间分批放开；统一转化逻辑（统一核心卖点、统一购买理由）；学习期不频繁调参数；避免新老素材同时大规模换血。

**学习期正在收敛的信号：**消耗速度逐步提升 → 学习中素材开始明显分层 → 少数素材开始承担主要消耗 → 新素材进入后不再明显拖慢整体节奏。

**冷启动心态与自然流自检（团队口径）：**冷启动期目标是建模——消耗不稳定、点击没规律、转化忽有忽无、ROI 波动大都是正常现象，**不要因早期波动焦虑或频繁操作**；给足新店 $200/日预算和 2-3 天学习期就是探索空间，**不靠乱降 ROI 硬冲、也不在学习期频繁改价/改券/改活动**（价格体系至少稳定 3-5 天，见 6.10）。新品前 3 天看不出太多东西，关键看有没有「慢慢变好」的趋势（CTR 提升、消耗变稳、开始出单、CVR 改善）；若一周下来完全没转化、CTR 持续低、消耗始终很差，问题就不是时间，而是素材、商品、人群表达本身。
**新广告能否吃自然流——上线 24-72 小时内问三句：**① 这条视频，如果我不是卖家，刷到会不会信？② 成交是不是慢一点，但结构很干净？③ 商品卡是否完整兜住了视频里的所有承诺？三点都成立，大概率能吃自然流且跑久。

| **健康**<br>小幅超额 | ROI 略高于目标（如目标 7、实际 7.5），CPM/CPC 正常 | 系统高效完成任务：**逐步加预算**（如日预算 $100 → $150，单次≤50%），观察 3 天稳定再继续加；持续稳定可阶梯上调 ROI 目标保利润 |
| **跑不动**<br>消耗困难 | 钱花不出去、ROI 远低于目标，CPM/CPC 偏高 | 高 CPM/CPC＝竞争激烈或素材 CTR 差；低 GMV＝商品卡/视频转化弱。动作：先查商品卡（差评？主图？）→ 素材 CTR <1% 换视频 → **ROI 目标临时下调**（如从 7 临时降到 6~6.5）让系统有能力竞争流量学习，等消耗正常、ROI 稳回 7 附近再调回标准值 7 |
| **跑飞了**<br>消耗快 ROI 低 | 预算能花完、流量不贵（CPM/CPC 低），但转化差（如 ROI 2.07） | 问题在商品竞争力/商品卡/视频引导转化：查差评、竞品是否降价、视频 CTA 是否明确、优化商品卡；**优化后仍无起色果断暂停该品计划，换表现更好的商品上来** |

**第一大坑：频繁调整。**早上看 ROI 5 把目标改 7、下午不消耗又把预算 $200 降 $100，第二天又换素材——**每次重大调整算法都要 24-48 小时重新学习，频繁操作让计划永远停在「新手期」，效果急剧恶化。**正确节奏：**「3 天一小看，7 天一大调」**，除非极端异常（消耗极快 ROI 为 0），至少观察 3 天再动，且每次只调一个变量（预算、ROI 目标、投放模式三选一）。
**启动清单：**选品（全店/有自然出单的头腰部商品，避开纯新品尾品）→ 商品卡优化到满分 → 建计划设 ROI 目标 7 与日预算（新店 $200，见 6.4）→ 观察 2-3 天整体数据 → 微调。素材弹药量参考：**每个商品备 50-200 条素材**供系统赛马。

**① 计划五阶段模型：对照信号判断计划在哪个阶段。**

表 6-18 计划五阶段模型：判断信号与操作规则

| 阶段 | 判断信号 | 操作规则 |
| --- | --- | --- |
| **冷启动** | 上线时间短、消耗不连续；转化样本少、波动大；同类素材还没跑出分化 | 不频繁调整参数；保证素材数量和类型完整；观察「是否开始稳定出单」而非成本是否好看 |
| **学习稳定** | 每天都有成交但量不多；ROI 有波动但整体可控；素材开始明显强弱分化 | 不被「消耗慢」带节奏乱调；先看净成交成本和后端数据；**重点优化素材而非计划参数**，允许流速慢但要保证方向对 |
| **放量准备** | 计划能在同一 ROI 区间反复跑出结果：ROI 稳定可接受、消耗和成交正相关、素材池有多条可复用素材 | 预算小步同步上调（单次≤50%）；优先复制成功计划；确认素材池承接力；观察放量后转化结构变化 |
| **放量执行** | 健康放量＝可控扩张：ROI 无明显塌陷、新增流量仍产生转化、CTR/CVR 下降可控、消耗不集中到单一素材 | 避免短时间频繁调参数；流速明显提升时盯人群结构；**放量不是目标，可持续的投产结构才是目标** |
| **异常回撤** | ROI 持续走低且调整无效；素材疲劳、新素材接不上；流量变泛、转化结构恶化 | **不硬扛**：及时止损；保留可复用素材和数据资产；重新拆解用户/素材/商品问题；按 6.10 计划切换规则用新计划重新跑模型 |

**② 数据掉了先分清：素材疲劳 vs 人群见底（判断错了越换越差）。**

表 6-19 素材疲劳 vs 人群见底：表现、本质与处理

|  | 素材疲劳 | 人群见底 |
| --- | --- | --- |
| **表现** | CTR 慢慢下降（持续衰减）、点击成本变高、消耗变慢；转化率往往不会第一时间大幅下滑 | CTR 一直不错甚至挺高，但 CVR 开始拐点式下滑（突然开始不赚钱了）、成本越来越高、消耗逐渐变慢 |
| **本质** | 同一批人看同一条内容看多了就不点了——内容对这批人没新鲜感，不是产品不行 | 不是素材不行，而是这条素材能吃到的高转化人群已用完，后面进来的是更难转化的人 |
| **处理** | **不是调人群，而是换素材表达方式**（不是简单换视频）：换开头最优先，其次换节奏镜头、换表达逻辑、增加冲突或对比，核心把 CTR 拉回来 | 换同类型素材意义不大，要**换人群入口**让系统重新找人：换使用场景、换人群表达（学生/打工人/宝妈）、换情绪角度（焦虑/对比/期待）、换语言体系 |

三种最容易判断错的情况：**CTR 和 CVR 一起下降** → 优先按素材疲劳处理（连点击都拿不到，问题首先出在内容）；**CTR 很高但就是不转化** → 不是人群见底，而是素材吸引错人了（标题党、过度夸张、强情绪弱转化），把内容拉回「成交导向」而不是破圈；**突然不消耗**（不是慢慢变差而是突然断掉）→ 系统直接判定这条素材没有扩量价值，不要纠结，直接停。

**③ 衰退前置信号与崩盘预警（别等 ROI 掉了才发现）。**

- **衰退 4 个前置信号**（ROI 明显下滑时往往已是衰退后期）：① **消耗变钝**——预算没变但消耗不再自然增长、加预算反应变慢；② **转化密度稀释**——消耗还在但单位消耗对应转化次数变少；③ **前端稳后端弱**——完播、CTR、互动正常但成交不稳定（内容疲劳型衰退）；④ **放量越来越难**——小幅加预算 ROI 明显波动、缩量后反而恢复。

- 疲劳三阶段进程：① CTR 开始慢慢掉（最早：用户反复刷到同样开头/话术/节奏）→ ② 流量锁圈（「有量但放不大」）→ ③ ROI 越来越不稳定（系统被迫拿更泛人群）。

- **崩盘预警：计划跑顺后约 10-15 天可能出现素材崩盘（80% 以上是素材问题）。**预警信号链：CTR 连降 → CVR 变差 → 频次明显升高 → 消耗忽高忽低，**同时出现 2-3 个即基本确定素材接近上限**。

- **崩盘时的正确处理：不是去救旧素材，而是马上准备新素材**——数据一掉就调 ROI（越调越乱）、加预算想把量拉回来（放大亏损）、频繁动计划（模型直接被打断）都是错的；提前一次性备 **10 条以上**新素材（换开头/换场景/换情绪）接力，梯队管理见 6.12。

**④ 付费带自然：三个量化指标（周报看盘时一起看）。**

表 6-20 付费带自然的 3 个量化指标与基准

| 指标 | 算法 / 基准 | 解读 |
| --- | --- | --- |
| **自然 GMV 占比** | 自然 GMV ÷ 总 GMV；**≥20% 优秀**，10%~20% 正常，<10% 广告依赖过重 | 衡量店铺是否只靠广告强推 |
| **付费 vs 自然 ROI 差值** | 差值 **≤15% 健康**（如广告 3 / 自然 2.7＝人群与内容一致性强；广告 4 / 自然 0.8＝纯靠广告强推、自然接不住） | 广告 ROI 高但自然 ROI 极低，实际利润可能很差 |
| **素材自然播放增长** | 投广告前后自然播放对比：**≥3 倍**有效，**≥5 倍**反哺明显 | 广告是否把内容推进平台生态 |

归因口径：用户第一天刷到广告、第三天自然下单，系统往往只记自然订单，但广告已完成第一次种草；反之有些看似广告成交的订单，用户早就在自然流看过多次。不要只看广告 ROI/消耗/CPA，要看「整个内容生态」的 GMV 增长。

GMV Max 自动模式会把店铺**所有挂车视频（自营 + 已授权达人视频）**抓进素材池赛马，其中会混入 ROI 极低、持续空耗、甚至违规夸大的达人素材。**广告户可以在后台自己屏蔽，不需要找达人下架视频。**共四种管控手段，力度和场景不同：

**三个避坑点：**① 排除只挡**付费流量**，视频自然流量照常跑；要彻底消失得靠达人删视频或解除联盟。② **不要一次排除太多**——GMV Max 靠全素材池实时赛马优化，官方明确素材过少会限制系统优化、可能拉低整体效果；拿不准的宁可留着让系统自然淘汰到 Not delivering。③ 移除排除条件后，之前被关掉的创意加热（Boost）**不会自动重启**，视频也不一定重新投放，操作前确认好。
**版本依据：**2026-09-02 印尼站卖家后台实测——旧教程说的「View creatives → In Use → Remove 单条移除按钮」在当前 UI 不存在，素材卡片仅有 Analytics 和 Boost 两个按钮。

**素材全生命周期管理（管控手段之外，管的是节奏）：**

- **三阶段管不同指标：**测试期优先看**消耗**（系统愿不愿意给量，小批量上新快速筛选）；放量期看**转化效率**（CVR、ROI、CPA，有效素材集中预算放大、头部素材重点保护别乱动）；衰退期看**投产**——投产低于计划均值就停止投放，**主动给新素材腾空间和预算**，不要被动等计划没量才处理。

- **计划内素材数量纪律：**一个计划跑量素材一般 **不超过 20 条**，初期真正跑起来、消耗量大的也就 **2-3 条**；**28 消耗原则**——80% 以上消耗集中在 2-3 条头部素材，其余仅占 10-20%。「计划素材越多起量机会越大」是误区：低效/空耗素材过多 → 系统探索到的人群质量混乱、高价值人群锁不准，**低质素材越多，计划整体拿量能力越弱**（还占预算、拖整体 ROI/CVR、挤占优质素材放量）。

- **删除/暂停量化标准补充（配合表 6-13）：**低消耗低转化持续 **2-3 天**仍达不到标准 → 暂停；**突然不消耗**（突然断掉而非慢慢变差）→ 系统判定无扩量价值，直接停；可短期观察的：CTR 高留存不错且消耗趋势增长、ROI 接近均值但系统持续给量、CTR 一般但转化明显更高、前期量不大但 ROI 持续改善；头部或表现尚可的素材 → 可**单独拉出来新建计划**继续投。

- **梯队管理与提前接力：**账户同时具备**引流素材 + 转化素材 + 破圈素材**三类梯队——破圈素材更生活化、更泛场景、不那么强卖货，目的不是马上转化而是帮账户打开新人群池；只靠 2-3 条素材撑着，一旦失效整体单量就下滑。预警信号出现 2-3 个时（见 6.11）就提前成批备产（一次 10 条以上，换开头/换场景/换情绪），不要等彻底死掉；提前做人群扩展，不要等数据下滑才做破圈。

- **旧素材激活：第一步是拆旧，不是拍新。**被关掉的老素材早就给过答案——按四个维度拆：① 开头 3~5 秒在制造冲突、讲价格还是反常识表达；② 中段在堆功能、讲场景还是做前后对比；③ 整体节奏快剪还是慢剪、单人输出还是对话；④ 结尾有没有明确转化指引、有没有帮用户降低决策门槛。用拆出来的已验证元素重新排列组合是最稳的新素材方式（需求模板见 5.13）；衰退老素材重剪再投通常波动大，适合「老带新」搭配，不适合当主力。

- **素材重复度：不是被惩罚，是没有新增价值。**平台关心的不是重不重复，而是这条内容还能不能继续拿到新成交结果——能稳定出单、打开新人群的「重复」结构系统照样给量。**有效差异＝结构差异**：换背景或字幕不算差异，改变表达逻辑（情绪驱动、问题解决、对比验证等不同结构）才算；只换字幕/BGM/镜头重剪/换人念口播的伪迭代＝同样信息反复输入，系统学不到新东西，不会扩量。行业里都是一样的表达时，系统只把钱给「不一样的那条」。

| **频繁操作类** | ① 频繁改预算/参数、素材刚跑就判断好坏、不断新建/启停计划——系统一直学习、进不了放量阶段；② 在 12/17/22 点 + 次日 10 点节奏之外盯盘，被瞬时数据带着跑，ROI 一掉中午就改（下午恢复但模型已被打断）；③ 看到稳定跑量素材就换素材/加预算/改 ROI（把稳定计划搞崩的典型操作）；④ 数据一掉就调 ROI、加预算想把量拉回来、怀疑系统频繁动计划（崩盘时越调越乱） |
| **参数调整类** | ⑤ 为测新素材/追消耗频繁下调 ROI（团队唯一允许的下调是跑不动时临时 6~6.5 且跑稳调回 7，见 6.4/6.11）；⑥ 起量后硬冲消耗、加预算翻倍猛加（单次≤50%，小步递增最稳）；⑦ 高频乱改售价/优惠券（一天改多次）；冷启动期、刚稳定放量期大改价格（价格体系至少稳定 3-5 天） |
| **素材测试类** | ⑧ 一次堆太多新素材同跑（信号互相干扰，一次只测 1-2 条）；预算/参数/素材同时大幅调整；素材观察不足 24-48 小时、跑几十美金/一天就关删；⑨ 拼命堆素材、用数量对冲不确定性，计划里堆几十上百条素材碰运气（跑量素材 ≤20 条）；⑩ 空耗/低投产素材舍不得删、当潜力股硬养；被动等衰退素材掉量才清理；⑪ 素材跑不动就盲目疯狂要新素材、下「做点不一样的」需求、让剪辑师凭感觉创新；测试素材拍得像品牌 TVC |
| **素材内容类** | ⑫ 一条素材堆砌所有卖点/人群/场景（信号稀释、学习变慢，单卖点原则见 5.8）；⑬ 用强猎奇、强夸张、标题党素材骗点击（有量无转化还喂错模型）；⑭ 复制整条爆款/把同一脚本结构批量套用（看到开头就划走）；只换字幕/BGM/口播人的伪迭代；⑮ 把自然流爆款（搞笑/剧情/热点）直接当广告素材投（自然流爆款 ≠ 广告爆款）；新素材沿用老素材「讲清楚讲明白」的同模型打法；一次性把老素材全换成新素材；⑯ CTA 放视频最后或一开头就硬推（见 5.8）；硬广素材当长期主力、一条素材从冷启动跑到衰退不换类型；素材起量后不管评论区 |
| **结构与人群类** | ⑰ 高客单和低价跑量款放同一个计划（人群模型冲突，系统偏向低价款、高客单被饿死）；组货纪律见 6.10；⑱ 问题层级判断错误：素材烂却疯狂调参数、预算不足却拼命换素材、人群跑偏却继续加预算、没转化（90% 是素材问题）却硬冲消耗；⑲ 数据异常不处理、明显跑偏不干预、亏损扩大不止损；只获取流量不排除低质量流量（劣质素材管控见 6.12） |
| **达人供稿类** | ⑳ 达人视频全部第一时间随机放开进计划；学习期频繁调参数；达人素材与商家素材同时大规模换血；不设商家锚点素材纯靠达人供稿；㉑ 把排队期（48 小时内不消耗）误判为账户故障，慌着删计划/重开 |

表 6-22 常见认知误区与正解

| 误区 | 正解 |
| --- | --- |
| 起量靠运气/创意突然爆 | 起量是结构必然：低门槛理解成本 + 高强度情绪触发带来行为密度达标；可复制可放大的素材能力才是核心（方法论见 5.8/5.12） |
| 卖点越多覆盖人群越广 | 卖点越杂系统越难锁定核心人群；明确/聚焦/锋利才起量（单卖点见 5.8） |
| 素材火 = 能卖货 | 自然流爆款 ≠ 广告爆款：自然流系统优化完播停留，广告系统优化点击成交，两套目标完全不同 |
| 消耗快 = 素材优秀 | 仅代表系统愿意继续测试，不代表跑得出来；烧得快不代表测得准 |
| 重复 = 被限流/权重掉 | 实为内容无新增价值；能稳定出单、打开新人群的「重复」结构照样给量 |
| 老素材不行就该全换 | 老素材是模型锚点；一次性全换新素材系统往往直接收量（老带新见 6.3） |
| ROI 高系统就该给量 | 系统要的是可预测性——扩量时 GMV 是否仍成立；低消耗高 ROI（一天几刀、ROI 8-10）是假象，不代表能规模化赚钱 |
| 成本高的素材一定有问题、成本低的一定是好素材 | 低成本可能只是吃完小人群池（该拓圈）；高成本跑量素材可能是承接问题（该优化脚本/商品页而非淘汰） |
| 以好不好看、高不高级评判素材 | 系统只看成交能否稳定复制；逻辑简单、行为好预测、易扩人群的「普通素材」反而放量 |
| 没量 = 被系统限制 / 人群耗尽 | 人群耗尽是最少见的原因；多为素材评分、支付样本、人群疲劳、出价预算四类机制；小消耗没单可能是「没进池」（见 6.1） |
| 海量素材只过 1% = 素材差/账号没权重 | 1% 左右通过率是当下 GMV Max 正常漏斗水平；应对重心是自然流/加热先拿出单背书 + 拆解式复用（见 6.9） |
| 运营只需要调参数管计划 | 存量时代只会操作后台、只会堆素材数量会被淘汰；运营必须是**内容 + 数据 + 节奏**的复合型操盘手 |

**运营日常三件事：**① 能做出有筛选能力的素材（明确人群、明确场景、明确结果）；② 能看懂数据背后的问题（点击高不转化＝人群错；有转化成本高＝点击不精准；后期变贵＝素材疲劳）；③ 能控制节奏而不是频繁干预——很多账户跑不起来不是因为不会，而是动得太多。**老司机每天花时间最多的不是调参数，而是复盘数据、记录变化、总结素材生命周期、观察系统节奏。**
