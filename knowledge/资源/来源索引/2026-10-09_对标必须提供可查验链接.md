# 对标必须提供可查验链接

- 日期：2026-10-09，北京时间。
- 来源：本次电商运营总控对话，用户直接纠正；原话完整，可读。
- 状态：用户明确要求，作为现有选品证据交付规范的补充；不新增独立 Skill 或销量阈值。
- 范围：给本用户交付的电商商品对标、竞品研究和引用这些对标的选品建议。

> 你找对标的时候一定要给我对标的链接，不然我没办法查验

## 执行规范

1. 找到或推荐对标时，在该对标名称旁直接给可点击的商品详情页链接，列清对应自家 SKU、对标商品名称/店铺和市场。不能只交名称、Product ID、截图、本地文件路径或搜索结果页。
2. 提交 LinkFox 查询时即要求返回商品原始链接和证据页面链接；回读真实结果，核对链接所指商品身份。统计数据保留日期与口径。
3. 用视频、直播、达人或数据页支撑出单方式判断时，给出相应原始证据链接。关联视频只证明关联，不能自动证明订单归因；渠道未知仍标未知。
4. 链接缺失、登录/地区限制、页面下架或本次未能打开时明确标注状态与查验时间，保留待补证；不能猜造 URL、仅按 ID 拼地址后声称已核验，也不能将候选写成已完成可查验对标。
5. 已有交付缺链接，优先从其原始证据补齐，并逐个对应到原候选；不得拿另一商品或泛搜索页凑链接。补不到就标记缺口，其他研究可继续。

推荐展示：`自家SKU → 对标商品名称（商品直达链接） → 渠道/视频证据链接 → 可借鉴点与改进动作`。身份/证据未核实的项目保留待核状态。

## 与现有规范的关系

- 补强10月8日逐SKU市场对标、自家销量交叉核验规范，不改变候选资格、每日数量、日程或外部发布授权。
- 每日机器人摘要不要求用户打开任务表，与提供必要的对标证据链接不冲突；“不发表格”不能解释成“对标不给链接”。
- 同步到 `tiktok-commerce-operations` 的选品执行手册和 `linkfox-research` 的研究交付要求。

## 交付检查示例

- 通过：自家 SKU、对标商品详情 URL 与身份匹配，引用的带货视频也有原链接，已核验和访问受限状态分清。
- 不通过：只有商品名/ID/搜索词、首页或搜索页，没有对标商品直达链接。
- 保留待核：工具给出 URL 但打不开；原样附链接并说明限制，不称已查验或已完成对标。
