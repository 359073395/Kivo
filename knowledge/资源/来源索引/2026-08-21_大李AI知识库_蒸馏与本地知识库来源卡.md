## 已确认的来源观点

- 长期个人知识应保存在用户能直接控制、便于 Agent 读取和迁移的本地文件夹；平台知识库适合内容少、追求快速开始的情况。
- AI Agent 是知识库的主要使用者；Obsidian 可作为 Markdown 浏览器，而不是知识库成立的前提。
- Skill 是可重复使用的工作方法；标准目录以 `SKILL.md` 为核心，描述负责分诊，正文负责步骤、资料、工具、检查与停止。
- 资料蒸馏区分 `what they do`（方法）与 `how they think`（思维框架）。
- 个人技能蒸馏采用真实目标、反复校准、整理成 Skill、持续迭代的四步循环。
- 视频/音频先在本机完整转成带时间戳的 Markdown 逐字稿，再阅读或蒸馏；视频不能直接跳过文字化。
- 书籍/访谈蒸馏接受文字稿、TXT、PDF 和 Markdown；视频应先转文字稿。

## 用户在本轮追加的活动规则

- PDF 也必须先转成完整 Markdown 文字稿并存入 `D:\Knowledge`；原 PDF 留在外部工作目录，从而节省知识库空间。
- 蒸馏必须是独立的 `knowledge-distillation` Skill，不能只是 `knowledge-iteration` 的一个小节。
