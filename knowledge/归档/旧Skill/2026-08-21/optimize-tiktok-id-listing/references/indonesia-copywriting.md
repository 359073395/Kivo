# Indonesian Listing Copywriting

Create conversion-oriented Bahasa Indonesia copy from verified product facts and evidence-backed search language.

## Preparation

Before writing, identify:

- exact product type
- target buyer and primary use case
- strongest verified differentiator
- purchase-critical specifications
- variant and package scope
- primary objection or source of wrong purchases
- evidence-backed Indonesian search terms
- claims, words, and implications that must be excluded

Do not invent a search-volume tier. If live keyword data is unavailable, label keyword selection as semantic and evidence-based rather than volume-based.

## Title rules

- Put the product type and strongest relevant search term early.
- Add only attributes that identify the real variant or improve purchase clarity.
- Prefer clarity over a question hook, slogan, emoji, or exaggerated promise.
- Avoid repeated synonyms and competitor brand names.
- Preserve model numbers, capacity, material, size, quantity, and compatibility exactly.
- Use the current official field limit when it is available. If it is not available, do not claim a fixed platform maximum.

Recommended structure:

```text
[Product Type] + [Primary Differentiator] + [Critical Spec/Variant] + [Primary Use Case]
```

Generate:

1. a balanced recommended title
2. a search-clarity alternative
3. a conversion-clarity alternative

## Benefit highlights

Use benefit-led factual lines:

```text
[Buyer outcome] — [feature or specification that supports it]
```

Each line should answer one buyer question. Avoid combining unrelated benefits.

## Description structure

Use only sections supported by the product evidence:

```text
[One-sentence product and value summary]

Keunggulan Utama
• [Benefit supported by feature/spec]
• [Benefit supported by feature/spec]
• [Benefit supported by feature/spec]

Spesifikasi
• [Verified specification]

Isi Paket
• [Exact included item and quantity]

Cara Penggunaan / Catatan Kompatibilitas
• [Only when needed]

Pilihan Varian
• [Explain material differences]
```

Do not add a call to action that implies false scarcity, guaranteed results, or an unavailable promotion.

The ready-to-use description must contain no `[fill this]` placeholders, asterisks, or unverified specifications. When package contents, instructions, price, or a specification are unknown:

1. omit the unsupported line from the safe copy, or state only a verified limitation;
2. list the missing fact outside the customer-facing copy;
3. optionally provide a separate draft line labeled `use only after verification`.

Do not place an unverified line in the recommended title or highlights even when a footnote is present.

## Keyword groups

Classify evidence-backed terms as:

- **Primary**: exact product type and strongest buyer intent
- **Secondary**: verified feature, material, size, audience, and use case
- **Attribute**: model, capacity, compatibility, color, quantity, or format
- **Question language**: phrases buyers use to resolve an objection

For each term, record the evidence source. Exclude:

- competitor brand names
- unverified trending terms
- unrelated traffic terms
- duplicate variants of the same phrase when they make copy unnatural
- claims that need regulatory or product proof

## Quality check

- Natural Bahasa Indonesia, not literal translation
- Product and variant are immediately recognizable
- No factual drift from the normalized product data
- Critical specifications and package contents are consistent
- Keywords read naturally
- No invented proof, urgency, discount, gift, or certification
- Customer-facing copy is ready to paste after human review
