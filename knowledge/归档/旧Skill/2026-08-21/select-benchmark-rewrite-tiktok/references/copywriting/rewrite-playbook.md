# 爆款结构镜像与原创仿写

## 核心定义

“仿写”默认指高保真结构镜像：保留爆款的结构、节奏、情绪曲线、卖点顺序、证据类型和 CTA 逻辑，但更换具体表达、场景、例子、证明方式和动作。目标是像同一类爆款机制，不是像同一条文案。

## 生成前事实卡

先列出目标 SKU 的：产品名称、规格、成分、已证实卖点、使用方法、适用人群、上架原价、日常售价、活动价、折扣、COD、图片、缺失字段、冲突和禁说项。缺少关键事实时不把参考内容中的卖点移植过来。

## 结构指纹

逐条记录：

1. 总时长与段落数。
2. 每段时间、句数和镜头功能。
3. 0–3 秒 Hook 类型与首帧。
4. 痛点/场景/情绪推进。
5. 产品出现与卖点顺序。
6. 证据：演示、成分、评价、认证、价格、对比。
7. CTA 出现位置与购买理由。
8. 屏幕字幕、音轨和节奏功能。

## 改写步骤

1. 保留结构指纹。
2. 将每个参考卖点映射到当前 SKU 的已证实事实；无法映射的段落删除或换成低风险事实。
3. 重建场景、例子、语序、措辞、手部动作和屏幕文字。
4. 使用自然短句 Bahasa Indonesia；避免正式翻译腔和长句堆卖点。
5. 默认提供逐段中文对照，便于人工核对事实。
6. 生成 2–3 个 CTA 备选；只有已验证的 COD/优惠才能写入。
7. 对照参考做相似度检查并标 `low / medium / high`。

自动回归时可运行 `scripts/check_rewrite_similarity.py`。以下任一条件标为高风险并重写：出现连续 8 个相同词、任一句归一化词集 Jaccard >= 0.58，或输出中 4-gram 复用率 >= 0.35。该脚本只检测词面近抄，不能替代人物身份、音乐、镜头、独特表达和事实迁移的人工检查。

## 常用印尼结构

- 痛点解决：人群/痛点 → 日常困扰 → 转折 → 产品 → 证据/演示 → CTA。
- 反常识：`Kalau kamu masih..., stop dulu` → 常见误区 → 新判断标准 → 产品证据 → CTA。
- 场景代入：高频场景 → 情绪 → 产品出现 → 使用演示 → 信任 → CTA。
- 价格重塑：价格惊讶 → 日常价格类比 → 使用价值 → 真实优惠/COD → CTA。
- Demo-first：问题画面 → 动作演示 → 可见变化/使用感 → 适用范围 → CTA。
- 评论回复：评论问题 → 直接回答 → 演示 → 规格/材质 → 安全 CTA。

## 口语原则

可自然使用 `kamu`, `aku`, `nih`, `deh`, `serius`, `coba`, `buat kamu yang...`, `kalau kamu sering...`, `cek keranjang kuning`。不要机械堆砌固定口头禅；同批文案避免每条都以 `Gila`、`Sumpah` 开头。

## 原创红线

- 不逐句复制或仅替换少量同义词。
- 不复制独特口头禅、真实人物身份、品牌故事、音乐、商标措辞、评论用户名或不可复拍镜头。
- 不假装亲身用过、医生/专家、真实消费者或官方背书，除非有证据和授权。
- 不把参考产品的成分、规格、效果、认证、价格、销量或评价移植到目标 SKU。

## 功效安全

健康、美容、减重、口腔、眼部、鼻腔、睡眠等产品避免 `menyembuhkan`、`pasti sembuh`、`100% berhasil`、`dijamin`、永久/立刻/几天见效等保证。优先使用有事实支持的 `membantu`、`mendukung`、`cocok untuk`、`hasil tiap orang bisa berbeda`、`pakai sesuai petunjuk`。

## 默认交付

- 参考结构拆解与结构指纹。
- Bahasa Indonesia 完整口播。
- 中文逐段对照。
- 屏幕字幕版。
- 分镜/镜头功能。
- CTA 备选。
- 产品事实引用与未使用的高风险卖点。
- 相似度风险与合规状态。
