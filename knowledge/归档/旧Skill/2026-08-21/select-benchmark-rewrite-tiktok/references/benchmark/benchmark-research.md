# 对标查找与筛选

## 搜索目标

为同一 SKU 或同功效产品找到可以解释“为什么有效、为什么可复拍”的内容样本，而不是只收集高播放链接。

## 来源顺序

1. TikTok 站内搜索、TikTok Creative Center、同类商品页与达人内容。
2. LinkFox/FastMoss 的同类商品、达人和带货视频证据。
3. 自己账号/店铺历史高数据视频。
4. Reels、YouTube Shorts、抖音、小红书等跨平台结构参考；不得把跨市场销量当印尼 TikTok 证据。
5. 用户提供的视频、转录、截图或导出。

## 查询组合

围绕目标 SKU 生成多组 Bahasa Indonesia 查询：

- 产品通用名 + 功效/痛点；
- 产品类型 + `review` / `cara pakai` / `hasil` / `COD` / `promo`；
- 目标人群 + 场景；
- 核心成分/材质 + 使用场景；
- 竞品品牌/类目词 + `keranjang kuning`。

同时保留中文/英文同类目搜索用于发现结构，不把其他市场的价格或合规口径直接移植到印尼。

## 候选记录字段

每条记录：

- `benchmark_id`
- URL、平台、作者/店铺、发布时间、观察时间
- 国家/语言、商品/类目/功效、售价/促销（如可见）
- 播放、赞、评、转、订单/GMV（仅记录可验证数据）
- 首帧、Hook、痛点、产品出现时间、卖点顺序、证据、CTA
- 视频总时长、段落/句数、镜头功能、字幕/BGM
- 产品匹配、市场匹配、可复拍性、合规/权利风险
- 数据来源和缺失项

## 有效性门禁

优先收集 5–10 个候选，至少 3 个有效。有效对标应满足：

- 产品、功效或核心痛点与目标相关；
- 有可分析的销售文案、屏幕文字或演示结构；
- 数据/观察时间可追溯；
- 能用当前产品事实复拍；
- 没有明显违规、误导、搬运水印或不可获得的名人/场景依赖。

`skip_bgm_only`：无人声且无明确销售字幕/屏幕文案。

`needs_manual_audio_review`：声音微弱、语言不清或疑似有人声，暂不判定。

## 排序逻辑

按以下顺序解释排序，不必在数据不足时强造综合分：

1. SKU/功效/痛点匹配。
2. 印尼市场与语言匹配。
3. 数据新鲜度和证据完整度。
4. 购买意图和商品关联，而非仅娱乐播放。
5. 结构可复拍、产品可展示、可做多版本。
6. 原创与合规风险可控。

正式选品证据优先 48 小时内数据。内容结构可使用较旧样本，但标为 `historical_pattern`，不能冒充当前爆款。

## 无实时工具时

输出搜索词、平台、筛选表和缺失资料清单，请用户提供链接/导出。不得生成虚构 URL、作者、播放量、订单或 GMV。
