# TikTok 基础运营规则

来源: `sources/tiktok_from_beginner_to_master_extracted.md`

## 1. 平台底层逻辑

TikTok 是兴趣电商，不是搜索电商。内容先激发兴趣，再把用户带到商品和购买动作。文案不能像详情页说明书，必须先解决“为什么停下来”和“为什么现在点”。

流量池是赛马机制。视频发布后先进入小流量池，平台根据数据决定是否继续放大:

| 层级 | 参考播放量 |
| --- | --- |
| 基础流量池 | 200-500 |
| 一般流量池 | 1000-5000 |
| 中级流量池 | 10000-50000 |
| 高级流量池 | 100000-500000 |
| 终极流量池 | 100w+ |

核心排序: 完播率优先，其次互动率、分享率、CTR；带货视频进入商业流量后，GPM 和转化成本会影响持续推荐。

## 2. 核心指标

| 指标 | 作用 | 参考阈值 |
| --- | --- | --- |
| 播放量 | 判断初始曝光 | 500+ 进入基础流量池 |
| 完播率 | 判断内容吸引力 | 30%+ 是重要门槛 |
| 点赞率 | 初步认可 | 3%+ |
| 评论率 | 互动和话题性 | 0.5%+ |
| 转发率 | 内容分享价值 | 0.5%+ |
| 吸粉率 | 长期账号价值 | 0.3%+ |
| 综合互动率 | 共鸣程度 | 5%+ 良好，10%+ 优秀 |
| 视频带货 CTR | 小黄车点击能力 | 2%-3%+ |
| 商品卡 CTR | 主图、标题、价格吸引力 | 3%-8% 优秀区间 |
| 商品卡 CVR | 详情页、评论、价格说服力 | 1% 基础，3%+ 优秀 |

## 3. 爆款短视频结构

高转化视频优先使用这个骨架:

1. 0-3 秒: 精准人群 + 剧烈痛点 + 视觉冲击。
2. 3-10 秒: 痛点共鸣，让用户觉得“这说的是我”。
3. 10-20 秒: 产品引入 + 证据。证据可选成分、权威背书、真实效果、对比演示。
4. 结尾: 转化引导。用价格重塑、限时优惠、退换保障、赠品或库存提醒推动点击。

绝对避免开头慢悠悠铺垫、无关风景、品牌 Logo 先行、空泛口号。

## 4. 数据诊断

| 数据表现 | 主要问题 | 优先动作 |
| --- | --- | --- |
| 前 3 秒或整体完播低 | 开头不抓人，节奏拖 | 换 hook、换首帧、前置痛点或结果 |
| 播放高但 CTR 低 | 内容有趣但购买欲弱 | 加强产品关联、展示使用场景、明确点击理由 |
| CTR 高但 CVR 低 | 商品页、价格或信任不足 | 优化详情页、评论、优惠、价格锚点 |
| 商品曝光高但 CTR < 3% | 主图、标题、价格不吸引 | 换首图、标题关键词、促销标签 |
| 点击多但 CVR < 2% | 承接页不能说服 | 强化卖点、好评、证据、优惠券 |

每次 A/B 测试只改一个变量: 开头、信任背书、CTA、封面、标题、BGM 或商品卡主图。

## 5. 商品卡优化

商品卡是成交最后一站。视频爆了但商品卡弱，会把流量浪费掉。

主图建议 10 张图各司其职:

1. 首图: 功能演示 + 使用场景。
2. 第二张: 核心卖点或对比。
3. 第三张: 细节特写。
4. 第四张: 组件或包装。
5. 第五张: 尺寸和参照物。
6. 第六、七张: 不同人群和场景。
7. 第八张: 15 秒短视频。
8. 第九、十张: 认证、品牌、包装、信任信息。

标题公式: 核心关键词 + 产品名称 + 核心卖点/材质 + 适用场景/人群。

价格策略: 设置价格锚点、优惠券、多件更划算、满减或赠品，让用户产生“占便宜”的感觉。

## 6. 对标和素材库

爆款来源:

- TikTok Creative Center。
- TikTok 搜索核心关键词，按最热视频排序。
- 竞品账号和达人账号。
- 抖音、快手、小红书、Reels、YouTube Shorts 的同类目爆款。
- 自己店铺历史高数据视频。

拆解爆款时记录:

- 首帧画面。
- 0-3 秒 hook。
- 痛点和卖点顺序。
- 证据类型。
- 镜头节奏和 BGM。
- 小黄车引导方式。
- 评论区用户在问什么。

素材库按产品建立一级文件夹，再按痛点、产品特写、使用过程、效果展示、评价截图、包装认证分类。

## 7. 达人和投放

达人合作不要只看粉丝量，要看近期 GMV、平均播放、粉丝画像和垂类匹配。前期优先纯佣或低成本寄样测试，再把预算集中到已验证的优质达人。

GMV Max 更适合已有订单、评论和商品卡承接能力的成熟商品。新商品零数据直接投放，系统缺少学习信号，容易花不出去或转化差。

保本 ROI 公式: `保本 ROI = 1 / 利润率`。保健品类常需要更高 ROI 底线，投放前必须结合实际成本、退货、平台扣点和物流计算。

## 8. 合规红线

尤其是健康、美容、减肥类产品:

- 不说“治好”“保证”“100% 有效”“7 天改变”等绝对化承诺。
- 不滥用夸张前后对比。
- 不使用未经授权的音乐、影视、图片或带水印搬运素材。
- 不做诱导互动话术，如强制点赞评论。
- 不诋毁竞品。
- 不展示危险行为。

安全表达应强调“帮助”“支持”“适合某类场景”“效果因人而异”“按说明使用”。

## 9. SOP 闭环

标准流程:

1. 明确目标: 测新品、冲主推款、清库存或放大爆款。
2. 找对标: 建立 5-10 个高质量参考。
3. 拆爆款: 提炼结构，不复制表达。
4. 整素材: 按痛点、产品、使用、效果分类。
5. 剪辑: 黄金 3 秒、字幕花字、节奏和音效。
6. 发布: 封面、标题、标签、商品卡、发布时间、A/B 版本。
7. 观测: 完播、互动、CTR、CVR、GMV。
8. 复盘: 定位问题，形成下一版假设。
9. 复制: 同产品横向复制，不同产品纵向复用。

发布文案参考结构: 1 个情绪符号/语气钩子 + 1 个问题或感叹句 + 1 个行动指令。

标签参考结构: 1 个泛流量词 + 2 个精准词 + 1 个品牌词。

## 10. AI 工作流

AI 的定位是内容副驾，不替代人工判断。有效指令 = 任务 + 背景信息 + 格式要求。

批量生产建议:

1. 一次生成 5 个脚本角度。
2. 同一产品做不同 hook、不同信任点、不同 CTA。
3. 批量生成配音和字幕。
4. 用 CapCut 模板快速合成。
5. 发布后把数据反馈给下一轮脚本生成。
