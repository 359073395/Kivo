## 分类标签

- `hook-pain`: 痛点开场。
- `hook-curiosity`: 好奇/悬念开场。
- `hook-contrarian`: 反常识开场。
- `hook-result`: 结果先行。
- `proof-ingredient`: 成分证明。
- `proof-demo`: 使用演示。
- `proof-review`: 用户评价。
- `proof-authority`: 认证/专家/检测。
- `cta-discount`: 优惠/领券。
- `cta-urgency`: 限时/库存。
- `cta-risk-reversal`: 退换/保障。
- `risk-health-claim`: 健康功效风险。
- `risk-copying`: 表达相似度风险。
- `scar-care`: 疤痕护理类素材。
- `silicone-scar-sheet`: 硅胶疤痕贴/疤痕贴片。
- `plester-silikon`: 印尼本地常用疤痕贴关键词。
- `bekas-luka`: 旧疤、伤疤、术后痕迹场景。
- `bekas-SC`: 剖腹产疤痕场景。
- `comment-reply`: 评论提问回复结构。
- `demo-first`: 第一秒或前 3 秒先用画面证明。
