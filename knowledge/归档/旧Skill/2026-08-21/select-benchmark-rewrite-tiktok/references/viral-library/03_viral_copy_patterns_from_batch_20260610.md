# 2026-06-10 爆款文案模式沉淀

本文件总结本批次 6 个产品簇的可复用文案机制，用于后续生成印尼 TikTok Shop 带货文案。

## 1. 高频 Hook 类型

| Hook 类型 | 适用产品 | 机制 | 印尼表达方向 |
| --- | --- | --- | --- |
| 价格震惊 | 护肤、身体乳、洗发水、防晒 | 先制造“现在很便宜”的情绪，再给理由 | `Gila, harga segini...`, `mumpung lagi promo`, `sebelum harga balik normal` |
| 一品多用 | 素颜霜、防晒、身体乳 | 省步骤、省时间、anti-ribet | `nggak perlu pakai bedak lagi`, `cukup pakai satu ini`, `buat kamu yang anti ribet` |
| 问题反问 | 防晒、黑发、护肤 | 让用户自查问题 | `Sunscreen kamu SPF berapa?`, `Masih ribet semir rambut?`, `Kulit masih kusam?` |
| 现场演示 | 喷漆、染发、护肤涂抹 | 画面先证明，口播解释 | `lihat bedanya`, `aku coba langsung`, `sekali semprot/oles` |
| 大容量/省钱 | 黑发洗发水、喷漆、身体乳 | 解决价格顾虑 | `segede ini`, `500ml`, `cukup 2 minggu sekali`, `awet banget` |
| 限时促销 | 全部 | 制造行动理由 | `harga bisa berubah`, `promo terbatas`, `ready stock`, `COD + gratis ongkir` |

## 2. 可复用结构公式

### 公式 A: 价格震惊 + 一品多用

适合: 素颜霜、防晒、身体乳、低价高感知价值产品。

结构:

1. 价格/促销开头。
2. 用户场景: 出门、上班、带娃、赶时间。
3. 产品一句话定位: skincare + makeup / sunscreen + tone up。
4. 使用展示: 涂抹、blend、对比。
5. 结果感: glowing、lembap、nggak lengket、nggak white cast。
6. CTA: 小黄车、COD、免邮、价格随时变。

### 公式 B: 痛点焦虑 + 简单解决

适合: 白发洗发水、防晒、痘印/暗沉护理。

结构:

1. 点名痛点: uban、kusam、belang、kering、flek。
2. 反常识: 不用去 salon / 不用粉饼 / 可能 SPF 不够。
3. 产品引入。
4. 步骤演示。
5. 使用频率或省事理由。
6. 信任点: 评论、草本、BPOM、销量、真实对比。
7. CTA。

### 公式 C: Demo-First 视觉冲击

适合: 喷漆、清洁修复、遮瑕、防晒 tone-up、染发。

结构:

1. 先展示“问题画面”。
2. 现场使用，动作简单。
3. 展示立刻对比。
4. 解释适用范围。
5. 强化价格和购买方式。

### 公式 D: 评论/复购背书

适合: 护肤、防晒、身体乳、染发。

结构:

1. 引用用户反馈或复购。
2. 解释为什么好用。
3. 展示产品细节。
4. 强化适用人群。
5. CTA。

### 公式 E: 评论提问 + 疤痕贴演示

适合: silicone scar sheet、plester silikon、scar tape、术后/旧疤护理周边。

结构:

1. 评论贴纸开场: 用户问“这个贴片是干嘛的 / 防水吗 / bekas SC 能不能用 / 怎么剪”。
2. 第一秒给疤痕或贴片近景，不先拍精致产品图。
3. 手部操作演示: 撕开、剪裁、贴上、按压边缘。
4. 字幕回答核心用途: `bantu rawat tampilan bekas luka`, `bisa dipotong sesuai ukuran`, `tipis dan nyaman dipakai`。
5. 展示卷装或包装，让用户知道容量、材质和规格。
6. CTA: `cek keranjang kuning`, `bisa COD`, `pakai rutin sesuai petunjuk`。

注意: 如果参考视频只有画面和 BGM，就按无口播素材拆解，重点学习第一帧、手部动作、字幕位置和产品出现时机，不分析 BGM。

## 4. 产品类型映射

| 产品类型 | 优先调用公式 | 核心情绪 | 必备画面 |
| --- | --- | --- | --- |
| 素颜霜/tone-up cream | A + D | 省事、变好看、怕错过低价 | 手背/脸部涂抹，对比，不用粉饼 |
| 黑发洗发水 | B + C | 白发焦虑、怕染发麻烦、想省钱 | 白发前后，干发涂抹，等待冲洗 |
| 身体乳 | A + B + D | 皮肤干暗、肤色不均、想香软亮 | 手臂/腿部涂抹，大瓶，质地 |
| 高 SPF 防晒 | A + B + D | 怕晒黑、怕暗沉、想防晒兼底妆 | SPF 标签，脸颈对比，户外场景 |
| 修复喷漆 | C | 旧物变新、低成本维修 | 生锈/暗淡物体，喷前喷后对比 |
| 疤痕贴/硅胶贴 | E + B + C | bekas luka 明显、bekas SC、怕贴片不服帖、想省事护理 | 疤痕/贴片近景，剪裁，撕开，贴合，卷装或包装 |

## 5. 合规和降风险规则

- 美白、淡斑、抗老、遮白发都要避免绝对承诺。
- 不写 `pasti`, `100%`, `selamanya`, `langsung hilang permanen`, `menyembuhkan`。
- 使用更安全表达: `membantu`, `terlihat`, `tampak`, `bisa bantu`, `hasil bisa berbeda`。
- 防晒类必须按真实包装写 SPF/PA，不擅自升级。
- 染发/洗发类不承诺治疗头皮或修复发根。
- 喷漆类不承诺永久防锈，不夸大适用所有材质。
- 疤痕贴类不写 `penghilang keloid`, `hilang total`, `pasti rata`, `sembuh`, `dijamin`, `ga jadi keloid`；改用 `membantu menyamarkan tampilan bekas luka`, `area bekas luka terasa lebih terlindungi`, `hasil tiap orang bisa berbeda`。

## 6. 后续生成时的调用顺序

1. 先判断产品类型。
2. 从产品类型映射里选 1-2 个公式。
3. 结合用户给的痛点、卖点和价格。
4. 输出 3 个版本: 价格刺激版、痛点解决版、演示证明版。
5. 每个版本检查相似度和合规风险。
