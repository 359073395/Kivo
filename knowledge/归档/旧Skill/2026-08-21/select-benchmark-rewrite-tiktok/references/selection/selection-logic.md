# 选品逻辑（可移植快照）

来源快照：本地 xuanpin 系统及规则，主要形成于 2026-07 至 2026-08。实际使用时记录规则版本和数据日期。

## 决策链

`平台数据 + 自有历史/库存/利润 + 可审计规则评分 + 记忆复盘 = 自动选品决策`

市场机会可以脱离自有 SKU 先跑；自有 SKU 负责判断有没有货、能否上架、库存/利润/店铺是否承接。

## 三种模式

- `market`：只评市场产品，输出市场机会/观察/补数据/淘汰；不得直接排发布。
- `hybrid`：先评市场，再精确匹配 Y 仓 SKU，补充库存、利润、价格、店铺与历史判断。
- `owned_sku`：从自有 SKU 出发，用同功效市场证据验证。

## 平台证据质量门禁

正式候选必须同时满足：

- 不是 gift、sample、tester、affiliate、not for sale 等无效商品；
- 近 7 日销量大于 0；
- 有竞品商品链接；
- 有类目或功效；
- 数据可信度至少 0.68；
- 观察时间不超过 2 天（48 小时）。

不满足时按问题进入 `rejected` 或 `hold`，不能静默进入高分池。

## Prism 市场分

当前系统快照使用：

```text
sales_score      = clamp(sales_7d / 20000 * 30, 0, 30)
gmv_score        = clamp(gmv_7d / 800000000 * 17, 0, 17)
growth_score     = clamp(growth_rate * 36, 0, 18)
price_score      = 同地区目标价与竞品价差分，约 3–14 分；缺目标价时按约 45,000 IDR 价格带保守估计
confidence_score = clamp(data_confidence * 10, 1, 10)
freshness_score  = 0–2天:11；3–5天:8；6–8天:5；更旧:0
prism            = 六项相加
```

绝不为了得到高分伪造销量、GMV、增长、价格或可信度。

## Furnace 自有经营分

匹配自有 SKU 后按以下快照计算：

- 库存：`>=100` 得 20；`>0` 得 10；否则 -15。
- 毛利：`clamp(margin_rate * 55, 0, 25)`。
- 店铺覆盖：`clamp(有效链接店铺数 * 4, 0, 18)`。
- 内容可拍性：`clamp(content_feasibility / 100 * 17, 0, 17)`。
- 反馈：样本充分且订单 >=3 或 ROAS 达保本线得 18；有样本但不足得 5；否则 0。
- VCP 记忆：`clamp(15 + memory_impact / 6, 0, 22)`。
- 命中历史/合规/上架硬风险再减 35；重复占用测试坑位风险减 16。

`保本 ROAS = 1 / 毛利率`。

样本充分条件满足任一项：视频数 >=5、播放 >=1000，或广告花费 >= `max(120000 IDR, 售价*3)`。

## 方法规则包

现有权重：商品差异化 25、市场缺口 20、利润 25、竞品价格 15、内容策略 15。各项加权分形成方法分；对总分的调整为：

```text
method_adjustment = clamp((method_score - 50) * 0.12, -6, 6)
```

缺少供给/达人密度时，市场缺口保持中性；缺成本/毛利时，利润项降权；跨地区不套固定价格带。

## 双轨分数

```text
optimistic  = prism*0.58 + furnace*0.42 + 有证据时4分 + method_adjustment
pessimistic = (prism*0.43 + furnace*0.57) * reliability_multiplier
              + method_adjustment * reliability_multiplier
```

数据弱或缺失时 `reliability_multiplier` 最高只取 0.72。

## 分池

- `淘汰池`：硬风险；或样本充分且悲观分 <42。
- `补数据池`：无有效市场证据或可信度 <0.68。
- `补上架池`：已匹配 SKU 但店铺承接未就绪。
- `放大池`：样本充分且订单 >=3 或 ROAS 达到保本线。
- `市场机会池`：未匹配自有 SKU，悲观分 >=62 且乐观分 >=70。
- `高分池`：已匹配 SKU，悲观分 >=68、乐观分 >=74，且没有重复测试风险。
- `观察池`：其余候选或需要继续小样本验证。

## AI 第二门槛

只有规则高分候选才进入结构化 AI 评估：

```text
llm_score = 功效匹配*0.35 + 内容可拍*0.25 + 竞品可复制*0.25 + (100-合规风险)*0.15
```

最终通过要求：`llm_score >=70`、`confidence >=0.7`、`compliance_risk <=45`。超时、无结构化结果或低置信度进入观察/补数据，不得强行放行。

## 无实时市场数据时的固定降级

如果用户要求“选 3 款”，但当前没有 48 小时内市场证据，可运行 `scripts/preliminary_shortlist.py`，仅按内部数据完整度做初筛：资料完整度 40、在线店铺快照 20、COD 明确值 10（未知/待确认不加分）、图片 10、刊登卖点素材 10、18店快照上架 10；数据冲突减 15，高风险刊登话术每类减 8（最多减 30）。

输出最多 3 个 `preliminary_candidate`，全部标记 `decision_pool=补数据池` 和 `not_a_current_recommendation=true`。这个分数只用来决定先查谁，不是市场分、正式推荐或发布顺序。

## 记忆与历史排除

保留最近、可解释的失败原因、有效店铺-SKU 组合、脚本方向、品类经验和数据异常。历史具体 SKU 排除只作为 VCP 记忆，必须核对当前用户指令和新证据，不能永久硬编码。

## 每个候选必须输出

- 模式、SKU/商品、类目/功效；
- 市场链接、观察时间、销量/GMV/增长和可信度；
- SKU 匹配、库存、毛利、保本 ROAS、价格/COD、店铺承接；
- Prism、Furnace、乐观/悲观、方法分、AI 门槛和版本；
- 加分、扣分、分池、下一步、缺失数据；
- 已确认事实、计算结果和推断分开写。
