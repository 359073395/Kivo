# 建联 Playbook（原版 PDF 对齐版 v2.0）

## 生成前门禁

对外草稿只能使用已确认事实：达人名字、近期内容、品牌、产品、目标人群、使用场景、卖点证据、Offer、交付物、使用权和时间线。

- `offer.confirmed` 不是 `true` 时，不能写入现金、佣金或样品承诺。
- 个性化观察无法核验时，填写 `personalization_needs_verification`，不得写“我看过你的某条视频”。
- 禁用词与功效边界见 [prohibited-claims.md](prohibited-claims.md)。
- 所有内容默认 `pending_review` / `NOT_SENT`。

## 合作策略

Codex 只给“建议合作方式”，报价、授权期限、内容使用范围、付款条件和合同由人工确认。

| 达人类型 | 建议方式 | 核心沟通点 |
|---|---|---|
| 新锐潜力达人 | 寄样 + 纯佣 | 产品匹配、创作空间、长期合作机会 |
| 稳定出片达人 | 寄样 + 阶梯佣金 | 明确佣金、素材方向和复投机制 |
| 高质量内容达人 | 付费 + 佣金 | 创意价值、素材授权和交付标准 |
| 直播型达人 | 佣金 + 直播优惠 | 库存、价格机制、排期和样品测试 |
| 高量级达人 | 定制商务方案 | 预算、排他、授权、投放和履约条款 |

## 个性化邀约四段结构

1. **真实观察**：一个可核验的近期内容特点。
2. **匹配理由**：产品与达人受众、内容形式或使用场景的关系。
3. **合作价值**：经确认的样品、佣金、付费或资源支持。
4. **低门槛行动**：询问是否愿意查看 Brief、领取样品或讨论合作。

A 级达人深度个性化；B 级达人可用模板加一个真实匹配点。私信应自然、简短、适合手机阅读。

每位达人输出：建议合作方式及理由、TikTok 私信、邮件主题与正文、48–72 小时未回复跟进、感兴趣后的样品沟通、仍需人工核验的个性化信息。

## 跟进状态

统一状态：`pending_review` → `sent` → `read_no_reply` → `replied` → `pending_collaboration` → `pending_sample` → `sample_sent` → `sample_received` → `pending_content` → `content_published` → `reviewed`。

终止状态：`not_cooperating`、`do_not_contact`。出现 “not interested”“stop” 或明确拒绝后，立即停止触达并更新状态。

常见节点：首次邀约 48–72 小时未回复、有兴趣但未提交合规收样信息、寄出物流提醒、签收后体验时间、临近出片提醒、发布后感谢与复投讨论。

## 复盘

回填发送时间和话术版本、回复耗时与态度、样品成本和物流、是否按期出片、素材质量、播放/互动/点击/订单/GMV、是否二次合作，以及评分与真实结果是否一致。
