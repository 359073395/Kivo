# 本地会话交接

用于用户明确要求“备份这个会话”“保存当前会话”“换电脑继续”或把选定工作沉淀成项目交接时。它不是自动记录所有聊天。

## 创建步骤

1. 从对话推断标题和类别；只有无法可靠推断时才询问。
2. 运行 `scripts/New-SessionHandoff.ps1 -Title <标题> -Category <类别>`，使用脚本输出的目录。
3. 完成目录中的 `HANDOFF.md`，至少写入：
   - 目的和范围；
   - 当前进度；
   - 已确认决定和最新规则；
   - 关键文件、知识页和外部素材路径；
   - 使用的Skill、工具、插件和外部依赖；
   - 已完成验证；
   - 未完成事项和明确下一步；
   - 风险、停止条件和恢复注意事项。
4. 更新 `metadata.json` 的状态和关联项目，必要时记录关键文件哈希。
5. 在知识库日志追加一条会话交接记录。

## 边界

- 默认只保存结构化交接摘要，不声称复制了Codex原生聊天记录。
- 只有用户明确提供聊天文本并要求保留时，才另存 `聊天记录.md`。
- 禁止写入密码、Cookie、API Key、访问令牌或私人登录信息。
- 大型素材不复制到交接目录；只记录外部路径、哈希、状态和恢复条件。
- 外部消息、发布、上传和云端备份不属于本流程。
