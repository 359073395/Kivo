# 内部执行手册：涨粉视频

> 本文件不是独立 Skill。只有 `tiktok-content-system` 路由到 `follow_growth` 时才读取。旧 `fans-skill` 仅在归档中追溯。

## 目标

把已验证的短视频参考转成原创的印尼语涨粉内容、静态图和可编辑 CapCut 草稿。复用机制和节奏，不复制原文、原图、人物身份、音乐或无授权素材。

## 路径

- 从 `machine-paths.local.json` 读取 `fansProjectRoot` 与 `capcutDraftRoot`。
- 未配置时可先交付结构分析和文案，但不得自创盘符或写入知识库/Skill。
- 图片、音频、manifest、草稿和成片存入外部工作目录；知识库只保存方法、项目摘要和复盘。

## 流程

1. 分析参考的时长、首帧、钩子、字幕节奏、贴纸、音频、CTA 和留存机制。
2. 根据用户指定数量生成原创角度；用户未指定时先做一个可验证样稿，不把旧项目的“10 条/14 段”等数量当永久默认。
3. 健康类文案使用克制表达，不作治愈、保证结果、疾病治疗或剂量承诺；食材/植物需符合印尼常见性。
4. 图片使用 9:16、无内嵌文字，并为字幕保留安全区。
5. 只有用户明确要求 `0703` 样式时才读取 [0703-capcut-style.md](references/0703-capcut-style.md) 并套用对应贴纸、字幕和音乐结构。
6. 生成 CapCut 草稿后解析 JSON 验证媒体、文本、贴纸和音频轨；不要用字符串替换破坏草稿结构。
7. 人声清晰度优先于背景音乐；具体音量以当前模板和试听验证为准，不把旧数值机械套给所有项目。

## 停止条件

参考版权/授权不明、素材缺失、健康表达不合规、草稿路径未配置或模板身份不清时停止受影响部分。没有用户明确要求时不批量、不发布。
