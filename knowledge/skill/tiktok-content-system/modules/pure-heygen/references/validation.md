# 本地后期与校验

## 原始视频校验

使用 FFprobe/FFmpeg 检查：

- 文件存在且非零字节。
- 视频流可识别。
- 画面为竖屏。
- 文件可以完整解码。
- 音轨存在且口播可听。
- 人物、产品和包装没有明显换款或严重变形。
- 人物符合当前 SKU 与目标用户，不是跨 SKU 复用的通用脸。
- 人物年龄、造型、环境和动作能回到当前 SKU 的真实卖点、目标人群与使用场景，不是随机换脸。
- 自然皮肤/发丝、生活环境纹理、柔和自然光、中等饱和度、低对比度和手机/CCD 柔和感通过；过度磨皮、强滤镜、塑料质感和过锐判废。
- 白底商品源的光影和透视已单独评估；商品与场景主光方向、色温、明暗比、透视轴、材质反射和真实接触阴影一致，且未为适配动作扭曲包装或标签。
- 肩/肘/前臂/腕/手指链路、关节角、握持受力和商品重心符合现实人体工学；不出现断腕、穿插、孤立指尖或不可保持的展示姿势。
- 开头、中段、结尾三处均无占位残影、悬浮贴片、脱手、复制或形变，且拇指/前景手指在商品前、支撑手指在后。

不因轻微口型、字幕或动作差异反复消耗额度；产品换款、严重包装错误、损坏文件和权利问题必须阻断。

## 本地后期

纯 HeyGen 默认不增加 ChatCut 混剪。只有用户本次明确要求字幕或本地包装时，才使用当前项目已验证的脚本/工具；不存在时报告依赖，不从旧电脑路径恢复脚本。

允许的后期可包含安全区字幕、短钩子或关键词高亮，但必须与当前文案和用户要求一致。

禁止：

- 插入产品使用 B-roll。
- 删除或遮挡平台水印、AI 标记。
- 改写造成事实、价格、功效或披露信息失真。

工具不存在时，先报告缺失并保留已校验原始视频；不要在 Skill 目录生成替代脚本或缓存。

## 结果

每条记录：

- 原始视频绝对路径。
- 发布版绝对路径。
- 时长、宽、高、编解码检查。
- 产品/人物人工质检结论。
- `M-CNT-PURE-HEYGEN-001` 方法版本、样片批准状态和禁止回归项检查结果。
- AIGC 与商业披露待发布检查。

只有文件校验通过且 `human_qc_completed=true` 时才可标为 `ready_to_publish`。
