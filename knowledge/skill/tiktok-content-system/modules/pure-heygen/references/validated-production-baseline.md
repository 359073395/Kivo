# 已验证生产基准：`M-CNT-PURE-HEYGEN-001`

本页是纯 HeyGen 执行时必须读取的当前基准。详细证据、历史冲突和回归见 `vault_root/资产/带货视频/纯HeyGen数字人口播已验证生产方法_2026-08-29.md`。

## 开始即执行

1. 运行 `scripts/workspace_state.py recover` 找到知识库、进行中项目与 `ACTIVE_TASK.json`。
2. 运行 `scripts/workspace_state.py plan <task_dir>`；按返回的 `next_action` 执行，不重新发明路线。
3. 读取最新批量批准标准：只有用户明确批量批准才恢复剩余串行任务；只有样片批准时返回 `await_batch_approval`。额度、权限或远端状态阻断时保留状态停止。

## 人物与商品

- 每 SKU 一位独立人物，同 SKU 内一致，跨 SKU 不同脸。
- 人物、场景与动作随 SKU 的真实卖点、目标受众和使用场景改变；默认印尼本地日常真实感、自然皮肤发丝、柔和自然光、生活纹理、轻微杂质、中饱和、低对比、手机/CCD 感。
- 人物底图不承担真实包装生成；真实商品是锁定源层。
- 白底图先判断真实拍摄、修图抠图或渲染/来源不确定；只把包装身份当锁定事实，不盲目继承其光影和透视，也不扭曲标签迁就场景。
- 商品完全覆盖占位，拇指/前景手指在前，支撑手指在后；完整肢体链、关节角、受力、重心与接触阴影符合现实人体工学。残影、浮贴、脱手、复制、形变、穿插、孤立指尖或断腕感判废。
- 详细执行与两级自检见 [商品人物图标准](../../../references/product-presenter-image-standard.md)。

## 视频与门禁

- 默认 720×1280、9:16、25fps、柔和手机感、小幅正面微动作。
- 审核文案/锁定音频精确映射，不裁剪、重排、替换或变速。
- 图片批准只对用户实际看到的精确 `SKU + 路径 + 版本 + SHA-256` 生效；跨SKU、旧稿、后制派生稿或哈希变化一律回到图片审核门。
- 提交前必须把批准图哈希与 HeyGen 实际远端 `avatar_id`/asset ID 绑定，并核对远端缩略图中的人物、商品和场景；不得沿用当前选中项、最近使用项或旧形象。无法取得可核验的远端输入即停止。
- 首条返回后必须把开头/中段/结尾与批准图逐项对照，确认同一人物、同一SKU真实包装和同一场景。错人物、错商品、旧形象、灰色占位块、贴片或包装漂移立即判废并冻结批量；技术解码通过不等于视觉通过。
- 严格串行；有远端 ID 只查询，不重复创建。
- 新项目先一条样片；样片通过后等待一次批量指令。已有同范围批量批准记录时自动采用最新标准，不重复询问或要求用户复述。
- 完整解码并抽查开头、中段、结尾后才进入成片状态。

## 绝不采用

空手人物、模型重画商品、左上角另贴商品、通用跨 SKU 人物、只换脸不匹配卖点/人群、盲用白底图假光影/假透视、非人体工学动作、错误姿势上叠蒙版、过锐 1080p、近重复任务目录、重复样片批准、额度不足时换路线。
