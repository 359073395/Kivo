# 内容与素材生产流程

## 输入盘点

按 SKU 建立清单，至少确认：

- 目标店铺名。
- 内部 SKU、店铺 SKU/SKU ID、产品 ID 或其他稳定映射键。
- 该店铺当前商品标题。
- 该店铺当前 TikTok 产品描述；先把 HTML 清洗为可读文本。
- SKU 总表中的功效/卖点、日常售价和活动价。
- 产品原图，优先白底或透明图。
- 产品规格、成分、已证实功效/卖点、使用方法、禁忌和目标人群。
- 可验证的价格、折扣、COD 等促销信息。
- 需要的视频形式与每个 SKU 的数量。
- 爆款参考文案、视频、链接或转录（如有）。

产品图缺失时，暂停该 SKU 并要求补图。产品图不是白底/透明图时，只做可验证的抠图或背景清理；不得重画包装。

目标店铺已经指定但缺少该店铺标题或产品描述时，标记 `missing_store_listing_data` 并暂停。只有用户明确要求“通用产品文案”时，才允许不绑定店铺，并记录 `content_scope=generic`。

## 数据合并与优先级

以 `标准化店铺名 + 内部 SKU` 为主匹配键；存在重复时再用 `sku ID + 产品 ID` 消歧。禁止只按相似标题匹配，禁止把一个店铺的标题/描述套给另一个店铺。

按用途使用数据：

1. 产品图/包装：锁定真实外观、规格、标签和 Logo。
2. SKU 总表：确认 SKU、日常售价、活动价和批准的卖点/功效底座。
3. 该店铺商品标题与产品描述：提取该店实际上架名称、规格、成分、用法、目标人群、搜索关键词和内容角度。
4. SKU 功效自动分类表：只用于内容方向初筛，不直接当作广告功效。
5. 爆款参考：只学习结构、节奏和 CTA。

店铺描述中的功效仍必须与总表、包装和可靠资料交叉检查，不可因为上架描述里存在就原样宣传。出现以下情况时停止并记录 `source_conflict`：

- SKU、规格、成分或包装对应不上。
- 店铺标题/描述与总表卖点明显冲突。
- 当前价格、活动价或 COD 状态不一致。
- 功效只有自动分类或高风险描述支持，缺少可靠事实来源。

能确认的共同事实可以继续使用；有冲突的功效、价格或促销不写入文案，等待用户核对。

## 爆款学习

只提炼：

- 开场钩子类型。
- 痛点与情绪推进。
- 卖点排序。
- 证据或演示方式。
- 节奏与句长。
- CTA 逻辑。

不得复刻原句、独特镜头、人物身份、商标表达、音乐或其他受保护元素。每条输出必须是新的印尼语表达。

## 文案生成

每条文案至少包含：

1. 0–3 秒钩子。
2. 用户痛点或具体使用情境。
3. 1–3 个有来源的核心卖点。
4. 自然 CTA。

默认使用自然、短句、口语化 Bahasa Indonesia。不要写 SKU、内部代码、中文或无法证实的承诺。美容、健康、减重类禁止医疗化建议、保证结果、虚假前后对比和绝对化见效。

同一个内部 SKU 上架到多个店铺时，按 `店铺名 + SKU` 分别生成。可以共享经过验证的产品事实，但必须使用对应店铺的标题、描述、价格和定位，不得交叉污染。店铺标题和描述用于提取事实与关键词，不要整句照抄成视频文案。

## 数字人口播素材

- 使用图像能力制作 9:16 印尼本地人物/场景底图和自然持物姿势，再把真实产品作为锁定图层确定性合成。
- 真人参考必须有必要权利与同意。
- 人脸清晰，适合口型；手部自然；真实产品标签正面清楚。
- 不使用 HeyGen 生图。
- 不让图像模型重画包装、Logo、文字、规格或产品数量。
- 不制作产品使用 B-roll。
- 动作提示词按开场、中段、CTA、结尾安排 3–5 个微动作。
- 禁止大幅挥手、转身、遮嘴、遮挡产品或改变包装。

## 图片质检

逐张检查：

- 产品是否换款、拉伸、缩放失真或重新设计。
- 标签、Logo、颜色、容器、数量和比例是否一致。
- 是否虚构文字、认证、成分、价格或评价。
- 人脸、手指和持握是否自然。
- 是否包含中文、SKU、文件名、无关长文字或伪造水印。

失败时只修复当前图片并重新检查。无法保持产品时暂停并要求更清晰产品图。

## 工具路由

- 创建或编辑 Excel 时使用 Spreadsheets 能力，并在保存后重新读取关键单元格验证。
- 生成或编辑人物/场景时使用当前可用的 Image Generation 能力；产品原图是锁定事实源，不是允许模型重绘的素材。
- 参考来源是链接时，只提取必要内容；需要最新官方规则时访问官方页面。
- 不在内容准备阶段调用付费视频生成。
