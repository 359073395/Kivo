# 内部执行手册：内容与素材准备

> 本文件不是独立 Skill。只有 `tiktok-content-system` 路由到 `content_preparation` 时才读取。Seedance 已停用，旧 `tiktok-content-factory` 只在归档中追溯。

## 适用结果

- 学习对标视频的结构并原创印尼语带货文案。
- 为纯 HeyGen 或 B-roll 完整视频准备产品事实、文案、人物/画面任务和执行表。
- 建立可续跑的本地任务状态，但不在本阶段自动提交 HeyGen、ChatCut 或其他付费生成。

## 输入门禁

1. 明确店铺、精确 SKU、产品标题/描述、规格、真实卖点、价格/促销有效期和真实产品图。
2. 店铺已指定但缺少该店当前 Listing 事实时，暂停对应项目；不得借用其他店铺资料。
3. 产品图缺失时暂停，不猜测包装、Logo、颜色、规格或数量。
4. 参考内容只提取结构、节奏、钩子、痛点/卖点顺序、CTA 和镜头功能；不复制原句、人物身份、音乐或素材。

## 执行

1. 从知识库活动规则与当前 SKU 事实卡取证；旧聊天、旧项目目录和历史执行表仅作证据。
2. 读取 `../../references/distilled-method-routing.md`，根据当前瓶颈只选择适用的方法 ID；没有触发条件时不强套。
3. 生成自然、短句、口语化 Bahasa Indonesia 文案，并保留中文逐句释义供审核。
4. 所有产品声明回到当前证据；高风险功效、价格、促销和 COD 冲突时删除或阻断。
5. 按目标模式生成素材说明：纯 HeyGen 只需稳定人物口播；B-roll 模式按文案功能拆分人物、痛点、产品、使用、证明和 CTA 画面。
6. 需要人物或场景图时，先按真实卖点、目标人群和使用场景写出“产品—人群—动作”简报，再由 AI 负责人物、环境和姿势；真实产品作为锁定来源图层。不得让模型重新绘制包装文字、Logo 或数量。人物持有、承托、使用或展示商品时，读取并执行 [商品人物图标准](../../references/product-presenter-image-standard.md)：白底图的包装身份可锁定，但其光影和透视必须先评估；动作必须通过现实人体工学检查。
7. 只把提交给用户看的最终候选登记为待审文件；审核记录必须绑定精确 `SKU + 文件路径 + 版本 + SHA-256`。一个SKU的批准不得扩展到其他SKU，批准后的任何派生、压缩、重新合成或改名文件都必须重新核对哈希并重新审核。
8. 保存任务执行表和 `ACTIVE_TASK.json` 到外部任务目录，回读路径和关键字段，并登记使用的方法 ID、版本差异与停止线。

需要详细字段时读取：

- [workflow.md](references/workflow.md)
- [schemas.md](references/schemas.md)
- [policy-gate.md](references/policy-gate.md)

## 路径与续跑

只使用用户本次明确给出的目录，或 `machine-paths.local.json` 的 `productionWorkRoot`。两者都没有时先完成纯文本分析，再报告缺少路径；不得回退到旧盘符、旧 `%USERPROFILE%` 配置或 Skill 目录。

目录结构属于具体项目，不属于永久用户规则。只有用户明确说“初始化/开始这个批次”时才创建任务目录；旧对话中的 `00_product_white`、`06_presenter_gpt`、`08_v1_heygen` 等名字不会自动套用到新项目。

## 停止条件

事实、产品图、权利、模式或输出位置不足以安全继续时，停止受影响条目并列出最小缺口。内容准备完成不等于授权远程生成或发布。
