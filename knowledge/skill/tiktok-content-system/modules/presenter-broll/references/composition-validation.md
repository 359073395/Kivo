# ChatCut 成片校验

## 时间线与工程校验

- ChatCut 工程必须能重新打开，项目 ID、工程链接或可恢复标识写入 Excel 和 `ACTIVE_TASK.json`。
- V1 以 HeyGen 对口型底片为主轨，保留用户最终语音；不得截断、重排、复制或替换该音频。
- V2/V3 只按 Excel 标记的时间点覆盖 B-roll、产品图或文字，不改变主音频时长。
- 每个已标记 `broll_ready` 的片段都应出现在对应语义区间；缺失素材必须标记 `needs_asset`，不得用无关画面填充。
- ChatCut 中的字幕、转场、缩放、音量和素材替换应与 Excel 执行表一致；人工调整后同步回写最终时间码。
- 默认 9:16；人物、字幕、商品和 CTA 位于 TikTok 安全区。

## 剪辑原则

- 钩子、主要产品亮相和结尾 CTA 优先保留数字人或数字人与产品同框。
- B-roll 与对应句子的语义起点对齐，优先使用硬切、短叠化或轻微推拉。
- 背景音乐必须低于口播，不得造成削波；音效不得遮挡关键词。
- 不删除或遮挡水印、AI 标记或必要披露。
- 用户自行收集的 B-roll 必须具有必要使用权；来源与授权状态记录在 Excel。来源或授权不明时，不得标记可发布。

## 导出文件校验

使用 FFprobe/FFmpeg 检查：

- 文件存在且非零字节，容器可读取并可完整解码。
- 默认导出 1080×1920、H.264 视频和 AAC 音频的 MP4；如平台要求变化，在 Excel 记录实际参数。
- 音轨存在、口播清晰，无明显断裂、重复、爆音或意外静音。
- 成片时长与锁定用户音频一致，不存在意外黑帧、冻结帧或静音尾巴。
- 字幕未越出安全区，印尼语字幕与锁定发布稿一致。

## 画面与合规质检

- 数字人口型自然，人物身份、服装、背景和产品前后一致。
- 产品未换款；包装、Logo、颜色、比例和使用方式与白底参考图一致。
- B-roll 与当前句子相符，没有无关镜头或未经授权的人脸、商标与平台水印。
- 没有虚假前后对比、夸大病灶、医疗建议、虚构认证、评价、价格或库存。
- 完整播放一次 ChatCut 导出成片，并在手机竖屏尺寸下检查可读性与节奏。

只有 `human_qc_completed=true`、`rights_confirmed=true`、披露检查完成，且工程与文件校验均通过时，才标记 `ready_to_publish`。
