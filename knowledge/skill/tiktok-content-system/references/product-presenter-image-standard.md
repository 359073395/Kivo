# 商品人物图：语义、光影、透视与人体工学标准

本标准适用于 TikTok 商品人物图、纯 HeyGen 人物底图和带 B-roll 视频中的人物商品合成图。它补充真实包装锁定规则，不授权视频生成、发布或投放。

## 触发

只要画面中人物拿着、托着、使用或展示当前 SKU，就在生成提示词、合成和人工审核三个阶段执行本标准。

## 最低输入

- 当前 SKU 的可核验产品事实、真实卖点和真实使用方式；
- 目标人群：年龄段、使用问题、日常情境和购买动机；
- 用户提供或确认的商品源图；
- 目标画幅、视频模式和当前项目审核门。

缺卖点、人群、使用方式或商品源图时停止受影响 SKU，不用通用人物或相似商品补齐。

## 一、先做“产品—人群—动作”简报

在生成图片前明确写出：

1. 商品是什么、解决什么可验证问题；
2. 谁最可能在什么生活场景使用；
3. 人物年龄段、性别表达、服装和环境为什么与该人群一致；
4. 展示、握持或使用动作怎样体现真实卖点；
5. 哪些包装、规格、数量、颜色和标签字段必须锁定。

人物不同不等于人物正确。年龄、形象和房间不能只为“每 SKU 新人”而随机生成；它们必须能回到当前 SKU 的卖点、人群和使用场景。

## 二、白底图先分“身份事实”和“场景事实”

白底/透明图可能来自真实拍摄、抠图、修图、渲染或 AI 制作。先标记：

- `verified_photo`：真实照片且视角、材质和边缘可用；
- `edited_cutout`：真实商品但有抠图/修图痕迹；
- `render_or_uncertain`：渲染、AI或来源不确定。

包装轮廓、品牌、文字、容量、数量和主色仍是身份锁定依据；白底图中的光向、色温、阴影、反射和透视不自动成为目标场景事实。

执行顺序：

1. 优先生成人物姿势和相机视角，使它们匹配商品源图的正面/侧面视角；
2. 真实商品完全覆盖生成占位物；
3. 只允许把目标场景的低频明暗、色温和接触阴影作用于商品，不从生成占位物复制标签、Logo或高频纹理；
4. 不通过拉伸、倾斜、液化或透视扭曲来迁就错误手势，因为这会破坏文字、比例和包装几何；
5. 若必须明显扭曲商品才能匹配手和镜头，停止并索取更合适角度的真实商品图。

## 三、动作必须通过人体工学门

先确定真实受力方式，再写姿势。检查完整链路：肩/上臂 → 肘 → 前臂 → 腕 → 手掌 → 手指 → 商品。

- 肘部、前臂和腕部角度应是普通人在该时长内可舒适保持的姿势；
- 腕部应与前臂自然连续，除非真实使用动作确实需要弯曲；
- 握持必须有明确支点和受力：夹持、侧握、掌托或双手承托按商品尺寸选择；
- 拇指/前景手指在前，支撑手指在后；手指只在真实接触区出现；
- 商品重心、接触面和接触阴影必须一致，不能悬浮、脱手或只靠孤立指尖粘住；
- 生成时尽量保留足够的前臂与腕部，便于判断关节链；不以只截手部来掩盖错误。

以下直接判废：不可实现的关节角、断腕感、极端尺偏/桡偏、手指穿入包装、孤立指尖、重复手指、无支点悬浮、开放手掌被强行抬平、动作与产品用途无关。

## 四、光影、透视和材质

- 商品与人物的主光方向、明暗比、色温和阴影软硬一致；
- 商品垂直轴、相机俯仰、尺寸和旋转与手部和场景相符；
- 接触阴影只出现在真实接触点，不能给整件商品套一圈黑色光晕；
- 高光随塑料、玻璃、金属或软管材质变化；白底图的假高光不能原样搬入新场景；
- 最终720×1280柔和手机感可以降低过锐感，但不能用整体模糊掩盖错误边缘、手指或标签。

## 五、两级自检与失败恢复

提交用户前同时检查：

1. **全图**：卖点、人群、场景、完整肢体链、构图和手机真实感；
2. **局部**：包装保真、占位覆盖、商品透视、手指前后、接触点、接触阴影、材质反光和边缘。

任一项不通过即标记 `rejected`，不得进入 HeyGen。动作或手指错误时从人物姿势重新生成，不在错误姿势上继续叠加多层蒙版；光影/透视无法在不扭曲包装的前提下修复时，索取更合适角度的商品图。

## 六、状态和反馈

每张候选至少记录：SKU、卖点、人群、使用场景、商品源分类与哈希、人物 ID、姿势说明、人体工学结论、光影/透视结论、包装结论、用户审核状态和 HeyGen 提交数。用户否决时保留版本与原因；只有用户明确批准的图才能进入当前项目的可用状态。若批准来自“其他的可以”等上下文表达，记录中必须保存批准消息前实际展示的精确图片集合；不得把后来生成、重压、换包装或二次合成的文件冒充为当时通过图。

通过图确定后，生产目录实行单一真源：每个SKU的生成图目录只留一张用户通过的精确原文件，不改尺寸、不重压、不另存多个“最终版”；其他候选、底图、蒙版、参考图、裁切图和派生图直接删除。失败证据只保存文字、版本、哈希、否决原因和删除时间，不保存失败媒体。商品白底原图等用户输入保留在产品资料目录，不能随生成垃圾清理。
