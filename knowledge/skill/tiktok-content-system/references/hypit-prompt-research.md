# Hypit Prompt 技术研究参考

状态：技术能力已在 2026-09-18 本机验证；内容效果和业务迁移为 `candidate`。不改变既有内容生产默认后端。

触发：用户明确讨论 Hypit、其 Prompt Kit、文本组装或恢复本次实验。

先读 [技术报告](../../../资产/报告/20260918_Hypit安装与Prompt生成机制拆解.md) 和 [项目摘要](../../../项目/进行中/20260918_Hypit安装与Prompt研究.md)。本机路径从项目和 machine-paths.local.json 核对，不把本机 F 盘写成跨机器固定要求。

本次恢复入口为生产目录下的 `hypit-lab`：检查 `hypit --version`、Runtime endpoints、`prompts.svrun`，然后用 `hypit plan` 确认文本目标为 0 外部请求。可独立导出文本审阅，不能把命令成功当作模型成片效果通过。

最小输入：当前版本、要分析的模板、参数/配方、台词和引用事实。实际生成另需当前项目素材、账号、费用与审核权限。

已验证：Text Render、参数覆盖、Script dialogue 连接、29 项相关上游测试、纯本地 MP4 渲染。未验证：该用户账号下云端图片/视频/语音调用、印尼文生成质量、真实 SKU 保真和业务转化。

创意候选：四段式图片方向、固定约束与动态内容分离、意义驱动动作、先导出完整 Prompt 后审阅引用。只在明确测试任务中评估，不升级为所有视频的默认规范。

继续遵守真实商品锁层、每 SKU 人物匹配、最终音频和样片批准等现行规则。安装 Hypit 不等于恢复旧 Seedance 生产路线。官方 Skill 里的服务推荐和审美倾向是来源建议。

停止对应分支：源码版本与已验证版本不同且接口未复核；出现未预期外部请求；真实素材/账号/费用权限不足；生成视频尚未通过商品、身份、音频和画面检查。

输出与反馈：完整 Prompt、Template/Recipe/Param、真实参考顺序与哈希、模型服务和版本、产物路径、未验证项及用户反馈。
