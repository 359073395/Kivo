# 已蒸馏方法自动路由：TikTok 内容

本页承接用户已确认自动使用的 TikTok 内容方法。它们是带触发和停止条件的工具，不是每条视频都要全部套用的模板。

技术研究参考：用户明确讨论 Hypit 或其 Prompt 时读取 [Hypit Prompt 技术研究](hypit-prompt-research.md)。本地工具能力已验证，内容效果和业务迁移仍为候选；本引用不改变下述活动方法或生产默认后端。

## 调用顺序

1. 先确认 SKU 事实、目标市场、受众、内容阶段、自然流量/付费投流用途和当前瓶颈。
2. 只选择能解释当前问题的方法；通常一次主测一个核心假设。
3. 先过事实、原创、产品真实性、合规和权利门禁，再写脚本或生成素材。
4. 交付中标明方法 ID、版本差异、成功信号和停止线。

## 方法路由

### `M-CNT-PURE-HEYGEN-001` 真实商品数字人口播已验证基准

- 触发：用户要求纯 HeyGen 商品口播，或恢复已有纯 HeyGen 批次。
- 先恢复：从项目摘要和 `ACTIVE_TASK.json` 找到唯一正确任务；已有样片批准不得重新询问，额度阻断不得重提任务。
- 缺人物但真实商品、事实和审核文案/锁定音频齐全：自动生成一个与 SKU/受众匹配的印尼本地真实感人物候选，锁定真实商品层并本地质检；不让用户选择内部制作路线。
- 当前视觉基准：每 SKU 独立人物、同 SKU 一致，并由真实卖点、目标人群和使用场景决定年龄、形象、环境与动作；自然皮肤/发丝、生活化环境、柔和自然光、手机/CCD 感；白底图只锁包装身份，光影/透视先评估；真实商品完全覆盖占位，手指深度与人体工学正确；720×1280 柔和输出。详细门禁见 [商品人物图标准](product-presenter-image-standard.md)。
- 批准与远端强绑定：每个SKU的图片批准只对应精确路径、版本和SHA-256；提交前必须保存实际HeyGen avatar/asset ID并回读预览，禁止沿用旧形象或跨SKU复用。首条三段帧必须与批准图核对人物、精确SKU商品和场景；任一错配冻结批量。详细门禁见纯HeyGen RUNBOOK与`CNT-012`。
- 批量门：无现成批准基准时先做一个样片；用户或项目状态已经批准后按剩余清单串行继续。
- 停止：缺真实商品/事实/锁定音频、商品握持不合格、批准门未过、远端状态不明、权限/额度不足。
- 禁止回归：空手、模型重画商品、浮贴商品、占位残影、跨 SKU 同脸、随机换脸不匹配卖点/人群、盲用白底图假光影/假透视、非人体工学动作、在错误姿势上堆蒙版、过锐 1080p、把一个SKU批准扩大到其他SKU、只记录本地意图不核验远端avatar/asset ID、使用页面默认/旧形象、只做技术解码而不对照批准图、找不到知识库后临时自创路径。
- 详细证据与替代关系见 `vault_root/资产/带货视频/纯HeyGen数字人口播已验证生产方法_2026-08-29.md`。

### `K-TK-20260828-02` 宽入口、窄承接

- 触发：精准产品开场转化尚可，但曝光、停留或付费消耗持续受限。
- 执行：保留同一 SKU/卖点，A 版直接产品问题，B 版从相邻场景/情绪/更广人群进入并迅速桥接到产品。
- 判胜：B 版扩大有效观看/点击，同时不显著伤害点击后转化、订单质量、投产和评论相关性。
- 停止：高播放低有效点击、受众错配、承接断裂、负面误解或违规风险。
- 禁止改写成“无关素材”或“所有素材必须打泛”。

### `K-TK-20260828-03` 差异化命题

- 触发：产品或素材卖点与同类高度同质。
- 顺序：真实产品/成分概念 → 使用方式 → 便利性/体验 → 叙事定位。
- 只保留用户可感知、可演示、可验证、与购买障碍相关的差异。
- 停止：夸大效果、偷换健康概念、照搬竞品、只换新词没有真实差异。

### `K-TK-20260828-06` 受控组合量

- 触发：版本过少、偶然性强，无法判断哪个机制有效。
- 每个版本必须有唯一假设 ID，说明新增验证了什么；保持 SKU 事实和测试口径一致。
- 质量、事实、重复、归因或平台风险失控时停止扩量；不采用来源固定日产量。

### `K-TK-20260828-07` 伦理化痒点

- 优先：差一点、预拥有、身份痒，但必须真实、可实现并尊重用户。
- 神秘痒：只允许诚实留白，不隐藏关键条件，不伪造敏感提示。
- 亏欠痒：默认高风险、非首选；母婴、老人、健康等场景进一步收紧。
- 假库存、假人数、恐吓、羞辱、阶层歧视、健康暗示或道德绑架直接判废。

## 投流语境

`千川` 在本库等同付费投流语境。千川课程中的钩子、差异化、素材组合和承接机制可以作为 TikTok 投流素材方法；千川平台按钮、固定阈值、审核规避和算法断言不能迁移。涉及消耗、ROI、ECPM 或 GMV Max 数据诊断时，交给 `tiktok-commerce-operations` 的 `paid_traffic_diagnosis`。

## M-COM-PLAN-20260924：购买理由与周期协同（active，COM-014）

自营视频/投流素材服务于打品或跟品计划时，读取[总控方法](../../../资产/方法论/电商运营总控_打品与跟品周期规划.md)，恢复具体计划，用卖点—人群—场景说明每条素材为什么存在，统一SKU事实、承接链接和周期排期。准备三套基础标题/封面/详情版本不等于视频量已足；数量、周期依本批证据确定。真实素材/功效缺失停止相关分支，保留原样片和批量门。
