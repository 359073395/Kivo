# 迁移与恢复

首次在新电脑操作时，先阅读根目录 [START-HERE.md](../../START-HERE.md)。本文件保留迁移边界和简要步骤；完整命令、Skill 用法、外部依赖和故障排查以该手册为准。

## 可以完整搬走的内容

- Skill、规则、方法说明和检查清单；
- 视频/音频最终逐字稿、PDF/文档全文稿、网页正文稿和 OCR 文字稿；
- 已蒸馏知识、来源索引和轻量证据；
- 项目摘要、任务状态摘要、manifest 和最终复盘；
- 恢复、验证和Skill注册脚本。

使用 [笔记本一键迁移](笔记本一键迁移.md) 生成完整套件时，还会在知识库外单独打包当前 SKU/价格 Excel、店铺表、执行表、CSV/JSON/文案/字幕、必要商品图片和安全的 TikTok 工作区文件。它们不会混入 `Knowledge`，但可由同一条安装命令恢复。

## 不随知识库自动搬走

- 原视频、原音频、原 PDF/大型文档、抽帧、临时转录/OCR 缓存、B-roll、HeyGen底片、ChatCut工程和成片；
- CapCut、FFmpeg、ChatCut、浏览器、店小秘等软件；
- HeyGen、ChatCut、飞书、LinkFox等账号授权与API环境；
- 当前电脑的绝对路径和登录状态。
- `<productionWorkRoot>/rule-effects/pending/` 下的原始规则效果信号；知识库只迁移 `辅助/规则效果/` 中的 schema、聚合结论和审查候选。

项目摘要应记录外部素材目录、关键文件哈希、完成状态和恢复条件。换电脑后重新指定素材位置，不允许因为素材缺失而编造任务已完成。

## 迁移步骤

推荐方式是在旧电脑运行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\辅助\迁移\New-LaptopMigrationKit.ps1"
```

把生成的 `Knowledge-LaptopKit_<时间>` 整个文件夹复制到笔记本，然后在套件目录运行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\INSTALL-ON-LAPTOP.ps1"
```

下面是只迁移核心 `Knowledge` 文件夹时的手工流程：

1. 在旧电脑运行 `Update-PortableManifest.ps1`。
2. 运行 `Verify-PortableManifest.ps1`，确认无缺失或哈希错误。
3. 完整复制 `D:\Knowledge` 到备份介质或新电脑。
4. 在新电脑再次运行验证脚本。
5. 运行根目录 `RESTORE-KNOWLEDGE.ps1`。
6. 填写 `辅助/配置/machine-paths.local.json`。
7. 首次运行 `辅助/维护/Update-RuleEffectSummary.ps1 -ValidateOnly`，在新机器的 `productionWorkRoot` 下重建本地信号目录。
8. 重新安装/登录外部工具和插件。
9. 重启 Codex，新建对话测试主要 Skill。

旧电脑已停用的 Skill 注册入口不需要复制；真正需要迁移的最新 Skill 必须位于本知识库的 `skill/` 下。

## 新对话可用性

恢复脚本会将 `skill/` 下带有效 `SKILL.md` 的目录注册到 Codex 用户 Skill 目录。之后任意新对话都可以按描述自动发现，或使用 `$skill-name` 明确调用。

其他AI软件即使不支持自动Skill发现，也可以先读取根目录 `AGENTS.md` 和指定 `SKILL.md`，按同一规则执行。外部工具调用方式需要使用该软件对应的适配器。
