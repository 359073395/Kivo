# 笔记本一键迁移

这套迁移包面向 Windows 笔记本，目标是用一条命令恢复知识库、七个主 Skill、当前 SKU/价格 Excel、店铺表、执行表、项目 JSON/CSV/文案/字幕、必要商品图片和安全的工作文件。软件环境在笔记本重新安装，继续与数据文件分开。

## 旧电脑生成套件

在知识库根目录运行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\辅助\迁移\New-LaptopMigrationKit.ps1"
```

套件生成在 `D:\Knowledge-Backups\Knowledge-LaptopKit_<时间>`。完整复制这个文件夹到笔记本，不要只复制其中一个 ZIP。

## 笔记本只运行这一条命令

在复制后的套件文件夹中打开终端：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\INSTALL-ON-LAPTOP.ps1"
```

安装器会先校验两个 ZIP 的整体 SHA-256 与逐文件清单，再安装：

- 完整 `Knowledge` 及七个主 Skill；
- 当前店铺表、仓库 SKU/价格源、输出结果和工作脚本；
- 生产目录中的 Excel、CSV、JSON、Markdown、字幕、PDF/DOCX、必要商品图和轻量任务状态；
- TikTok 工作区中不含登录信息和软件环境的业务文件；
- 新电脑本地工作目录、机器路径配置与用户级知识库路径变量；
- Skill 注册、规则溯源、活动规则面和便携清单验收。

笔记本默认固定安装到 `G:` 盘，并恢复为 `G:\Knowledge`、`G:\820`、`G:\codex\TikTokSKU` 和 `G:\codex\TikTok`。如果 `G:` 盘不存在，安装器会明确停止，不会悄悄改到系统盘。

仅在以后确实要改盘符时，才显式指定目录：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ".\INSTALL-ON-LAPTOP.ps1" -BaseDirectory "E:\AI"
```

## 不随文件包自动搬走的内容

以下内容需要在笔记本重新安装、登录或另行备份：

- Codex 应用本体与 ChatGPT 登录；
- Python/FFmpeg/Whisper/OCR 等运行环境；
- HeyGen、ChatCut、飞书、店小秘、LinkFox 和战斧浏览器的安装或登录；
- API Key、OAuth、Cookie、密码和浏览器配置；
- MP4、MP3、WAV、ZIP、原视频、B-roll、HeyGen 底片、成片和剪辑工程；
- Codex 应用中的每日自动任务开关。

安装完成后，重新安装需要的环境并把路径填入 `Knowledge/辅助/配置/machine-paths.local.json`，再运行 `Knowledge/辅助/维护/Test-OperationalKnowledge.ps1`。完全退出并重启 Codex，然后新建对话。每日 22 点审计按 `辅助/自动任务/每日22点规则审计.md` 在笔记本重新创建。

## 安全与失败策略

- 目标目录已存在且非空时停止，不覆盖原文件；
- 任一 ZIP 或内部文件哈希不一致时停止；
- 不包含或迁移密码、令牌、Cookie；
- 不删除旧电脑的知识库、素材或账号；
- 运行失败时保留已经安装的目标目录供检查，不静默覆盖。
