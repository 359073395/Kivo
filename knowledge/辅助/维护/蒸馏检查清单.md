# 蒸馏检查清单

## 开始前

- [ ] 已登记全部来源、路径/URL、日期和处理状态。
- [ ] 已确认是否能完整读取，而非只看到标题、封面或片段。
- [ ] 已盘点视频、音频、文档、表格、图片和不可读文件数量。
- [ ] 视频/音频已规划完整转写；PDF/文档已规划全文提取或全页 OCR。
- [ ] 已检查隐私、版权和外部上传边界。
- [ ] 已搜索现有知识，避免建立重复页面。

## 提取时

- [ ] 事实、用户规则、作者观点、AI 推断、假设、冲突和未知已分开。
- [ ] 关键字段已分别标注出身、核验程度与执行权；来源核验没有被当作自动晋升活动规则。
- [ ] 每个扫描锚点分别记录 OCR 页标与印刷页码；没有印刷页码时为 `null`，没有猜填或批量冒充“已核验”。
- [ ] 易变信息标明日期和重新验证条件。
- [ ] 每条方法有触发情境、适用/不适用范围和最低输入。
- [ ] 已补执行步骤、判断标准、检查清单和停止条件。
- [ ] 已保留反例、失败条件和证据缺口。
- [ ] 会影响结论且无法由现有权威裁决的冲突已列出双方、来源、影响和选项，并在用户确认前标为 `conflict_pending_user`。

## 写入时

- [ ] 视频/音频已生成覆盖完整时长并带时间戳的 Markdown 逐字稿。
- [ ] PDF/文档已生成覆盖全部页、保留页码/结构/表格的 Markdown 文字稿。
- [ ] 最终文字稿存入 `资源/raw/`；原始大文件和临时转录/OCR 缓存在知识库外。
- [ ] 抽样、局部转录或缺页来源仍标记 `partial`，没有进入完整蒸馏。
- [ ] 更新了最窄的权威页面，而不是制造近义重复。
- [ ] 项目状态、业务知识、来源证据和 Skill 规则写入正确目录。
- [ ] 原始大型媒体、原 PDF 和临时任务文件没有进入知识库；最终文字稿已经进入知识库。
- [ ] 候选规则没有未经验证直接升级为活动规则。
- [ ] 拟新增活动规则已通过六项编译门；不满足时已进入正确的非活动去向。
- [ ] 每个可执行方法已指定现有主 Skill 与模式；用户确认/验证的方法已同步执行层，纯候选没有混入自动调用。
- [ ] 关联来源和版本可追溯。

## 完成前

- [ ] 来源覆盖范围和未处理部分已明确。
- [ ] 阻断和下一问题已写入摄入队列。
- [ ] 知识库日志已更新。
- [ ] 交付报告明确列出：已同步的 Skill、仍为候选的内容、被拒绝内容和等待用户裁决的冲突。
- [ ] Manifest 已重新生成并验证。
- [ ] 没有声称学习了无法访问的网页、视频或附件。
