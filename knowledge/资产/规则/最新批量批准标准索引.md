# 最新批量批准标准索引

本页记录有“测试→用户批准→批量执行”门禁的工作流当前标准。它不是按文件修改时间选最新版，而是按用户最后一次明确批量执行指令选定同范围版本。

## 判定规则

1. 新测试、新样片或 AI 自评通过只进入 `candidate`。
2. 用户明确说“批量执行”“开始全部生成”或同义指令时，该已测试版本晋升为同一 `workflow + mode + scope` 的活动标准。
3. 晋升时保存标准 ID、批准时间、任务 ID、用户证据、方法版本、样片/输入哈希、质量门和被替代版本。
4. 同范围后续任务自动使用活动标准，不要求用户重复说明。
5. 更晚但未获批批量的测试稿不能覆盖；用户当前明确回滚、修改或缩小范围时，以当前指令更新。
6. 批量批准不扩大外部权限：发送、发布、付款、改线上数据等仍按各 Skill 权限门禁执行。
