# 本地知识库搭建复盘

## 目标

建立一个只需完整复制 `Knowledge` 文件夹即可搬走规则、Skill、知识、项目摘要、manifest 和复盘的本地系统，并把杂乱、重叠的工作 Skill 合并成清晰入口。

## 已完成

- 建立七个知识库主目录和存储边界。
- 建立七个活动主 Skill，其中 `knowledge-distillation` 专门负责文字化与蒸馏，`knowledge-iteration` 负责维护与迁移。
- 归档 13 个旧 Skill 快照，Seedance 停用但未删除。
- 建立 Windows 恢复、Skill 注册、manifest 更新和完整性验证脚本。
- 旧百度会话备份入口被本地会话交接替代。
- 新增新电脑总手册、蒸馏总规则和蒸馏检查清单。
- 修正存储边界：最终 Markdown 逐字稿/PDF 全文稿属于可搬家知识，原始大文件和临时转换缓存才放在库外。
- 把本次对话的系统决定、视频规则、商品规则、达人规则和 IP 决策原则编译成知识资产。

## 本轮发现的关键缺口

最初只完成了目录、Skill、恢复脚本和会话交接，但 `资产/` 与 `资源/来源索引/` 为空。会话交接只能帮助续跑，不能代替知识蒸馏。用户及时指出后，已补建权威蒸馏规则和对话知识资产。

这条失败经验形成活动规则：

> 知识库搭建任务不能以“目录和 Skill 已存在”为完成标准；必须检查来源卡、权威知识资产、蒸馏结果、缺口队列和日志是否都实际产生内容。

## 验证标准

- 根目录有明确新电脑入口；
- 七个主 Skill 可注册；
- 全局蒸馏规则存在；
- 至少一个真实来源卡和一组权威知识资产存在；
- 未读取外部来源被明确标记为阻断；
- Manifest 无缺失、哈希错误和未审核文件；
- 没有大型媒体和凭证进入知识库。
