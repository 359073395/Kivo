1. “千川其实就是投流”，相关知识应进入现有 TikTok Skill，而不是建立独立系统。

5. 自动调用必须结合用户当前具体问题分析，不能让用户再次提醒，也不能只输出通用方法。

## 新增活动规则

- `SYS-008`：七个主 Skill 自动选择入口并定向读取活动知识。
- `COM-008`：`千川` 统一映射为付费投流/广告投放；素材和数据分别路由内容/商品运营。
- `COM-009`：七条视频蒸馏出的 7 个边界化方法进入自动方法路由。
- `DST-003`：以后蒸馏必须交付并执行现有 Skill 路由/同步结论。
- `DST-004`：无法由权威裁决的冲突先询问用户，答复前标记 `conflict_pending_user`。
- `SYS-009`：所有自动调用从当前具体问题、对象、阶段、证据和瓶颈出发，只选择适用知识形成针对性执行。

## 七个 Skill 重构后的运营方式

### 1. `knowledge-distillation`

- 自动触发：视频、音频、PDF、网页、书籍、课程、工作经验蒸馏。
- 新流程：完整文字化 → 方法编译 → 查重/冲突 → 状态 → 匹配现有 Skill → 同步执行层 → 验证/日志/manifest。
- 新完成门禁：不能只交付文字稿和总结，必须说明同步到哪个 Skill、哪些仍候选、哪些被拒绝、哪些等待用户裁决。
- 停止：覆盖不完整、冲突待用户确认、范围不清或会覆盖活动规则。

### 2. `knowledge-iteration`

- 自动检查：蒸馏产物是否有 Skill 路由、活动方法是否可被对应 Skill 到达、候选是否被误当成活动知识。
- 维护范围增加：自动知识调用协议、跨 Skill 总图和冲突等待状态。
- 不改变：删除、实质合并和高影响变更仍需授权。

### 3. `tiktok-commerce-operations`

- 新触发词：投流、千川、GMV Max、ECPM、广告消耗、ROI、空烧、跑飞。
- 新内部模式：`paid_traffic_diagnosis`。
- 自动方法：四能力诊断、候选池/最小测试/淘汰、差异化命题、投流因果检查和受控组合量。
- 关键边界：精确 ECPM 公式、权重和阈值仍待当前平台验证；投流数据不自动触发定价/Flash Deal，`COM-004` 继续有效。

### 4. `tiktok-content-system`

- 新触发词：投流素材、千川素材、广告创意、放量素材。
- 自动方法：宽入口/窄承接 A/B、差异化命题、受控组合量和伦理化痒点。
- 自动判断：只选择当前瓶颈需要的方法，不把所有方法塞进一条视频。
- 关键边界：不得把“宽入口”做成无关骗停留；神秘痒必须诚实，亏欠痒默认高风险；真实商品和最终音频规则不变。

### 5. `tiktok-creator-outreach`

- 深审达人内容时自动参考用户/商品匹配、差异化、钩子—产品承接和伦理文案方法。
- 只评价达人已展示的能力，不把方法假设写成达人能力。
- 不改变评分权重、A/B 阈值和外部权限；消息仍为 `NOT_SENT`。

### 6. `ip-commerce-decision-system`

- 自动读取适用的活动方法，不要求用户点名课程或方法卡。
- 跨域决策会从对应商品/内容/达人 Skill 取方法，从 LinkFox 取当前外部证据。
- 候选只能生成测试，不能静默驱动最终建议。

### 7. `linkfox-research`

- 自动继承请求 Skill 的决策问题、方法 ID、证据条件、市场和时间范围。
- 千川统一按付费投流研究语境；如果最终决策针对 TikTok，必须研究当前 TikTok 证据，不能拿千川阈值替代。
- 仍只提供证据，不替业务 Skill 做最终决定或线上操作。

## 自动跨 Skill 工作链

```text
用户目标
→ 自动选择一个主 Skill
→ 读取活动规则、当前项目事实和相关活动方法
→ 需要当前外部证据时调用 LinkFox
→ 商品事实/选品/Listing/投流数据由商品运营处理
→ 文案/素材/视频由内容系统处理
→ 达人合作由达人建联处理
→ 真实结果回到知识迭代和下一次蒸馏
```

新资料始终先进入 `knowledge-distillation`；可用方法再回写上述相应执行层。

## 冲突处理

- 已有明确高优先级规则可以裁决：直接遵守并记录，不重复询问。例如来源提出用价格优化 Listing，但 `COM-004` 已明确永久排除，继续按 `COM-004`。
- 无法裁决且会改变结论：列出冲突双方、来源、影响和选项，询问用户；答复前只做非冲突部分。
- 用户答复后：登记范围和替代关系，再完成总结和 Skill 同步。
