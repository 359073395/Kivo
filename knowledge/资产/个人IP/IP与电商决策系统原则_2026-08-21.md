# IP 与电商决策系统原则

## 定位

知识库不是资料收藏夹。它要把书籍、课程、网页、项目经验和用户反馈编译成可判断、可执行、可验证、可停止的决策系统。

## 决策分类

- `personal_ip`：人的身份、专业、信任、受众和长期商业价值是主要资产。
- `commerce_video`：产品需求、商品卡、店铺、直播或成交路径是主要资产。
- `combined`：IP 同时承担产品或服务转化。

## 固定决策流程

1. 定义情境、目标、时间范围和决策人。
2. 列出已验证事实、用户主张、假设、冲突和未知。
3. 检索适用方法卡，判断适用与不适用范围。
4. 先检查合规、事实、资源和不可逆风险等硬门禁。
5. 生成方案，包括安全默认项和停止/不做选项。
6. 推荐一个方案，说明为什么不选其他方案。
7. 给出负责人、顺序、成功信号、检查点和停止条件。
8. 用真实数据复盘预期与实际。
9. 把结果写成候选规则，验证并经用户确认后再升级。

## 来源优先级

1. 当前用户确认和项目真实结果；
2. 当前平台、市场和业务数据；
3. 经复盘的私有方法卡；
4. 便携主手册；
5. 历史课程、案例和转录；
6. 未验证观点和 AI 推断。

低优先级来源不能静默覆盖高优先级来源。

## 输出要求

每次决策至少包括：

- 当前事实；
- 未知和冲突；
- 适用经验及适用原因；
- 硬门禁；
- 推荐行动；
- 判断指标；
- 风险与停止条件；
- 会改变决定的新证据；
- 复盘时间和回写位置。

## 规则更新

一本书、一个视频、一次聊天或一次成功不能自动成为普适规则。新知识先进入候选，经过反例检查、真实任务、回测或用户明确确认后再激活。
