# TikTok 素材、选品与营销方法（2026-08-29 已接入活动 Skill）

## 使用边界

- 来源：2026-08-28 用户提供的 7 条抖音电商/TikTok 视频。
- 权限：本文件最初于 2026-08-28 以候选层建立；用户于 2026-08-29 明确要求根据这些知识自动分析执行。当前以 `COM-009` 为活动入口，按每个方法的触发、边界和停止条件自动使用；来源中的未筛选观点仍不生效。
- 调用方式：可用于提出测试假设、制作诊断清单和设计 A/B；未经用户确认或真实业务数据验证，不得写成“必须”“统一默认”或平台事实。
- 平台边界：来源混合千川、抖音、货架电商、Shopee 与 TikTok 语境。`千川` 在本库统一解释为付费投流；只迁移经过筛选的机制，平台参数和固定数量不能直接迁移。

## 综合结论

七条视频可以合并成一条较稳健的工作链：

`扩大候选池 → 用最小测试筛选 → 明确差异化命题 → 设计入口钩子与承接 → 观察广告/内容数据 → 保留胜出版本 → 停止弱候选`

真正值得进入知识库的，不是“每天上多少条”或“前五秒一定做什么”，而是四个可检验机制：

1. 不要把后端优化能力浪费在没有基本需求证据的弱产品上。
2. 素材入口可以适当扩大注意力，但承接必须迅速回到真实产品、目标用户和购买理由。
3. 差异化应来自真实产品/使用/定位差异，不能靠改名规避审核。
4. 产量应服务于假设覆盖和学习速度，不能演变成重复铺货、随机拼装或无效堆量。

## 活动方法单元

### `K-TK-20260828-01` 操盘手四能力诊断

- 状态：`active`
- 路由：`tiktok-commerce-operations` 为主，`tiktok-content-system` 为辅。
- 触发：复盘为什么团队“动作很多但拿不到结果”，或准备拆分岗位责任时。
- 输入：选品/测品记录、内容策略与样片、广告数据、日常运营和达人 BD 交付证据。
- 执行：分别检查选品测品、用户/内容理解、广告数据诊断、常规运营/达人协同四个面；只根据缺口分配补强任务。
- 判断：如果没有产品测试证据，先补选品；没有“人群—阶段—素材”映射，先补内容策略；有投放异常但无原因假设，补数据诊断；前三者清楚后再优化日常操作效率。
- 检查：每个能力面都必须能指向实际证据，而不是按职位名称打分。
- 停止：证据不足时只登记未知；不因一条视频把团队固定为“一名操盘手 + 一名助手”。

### `K-TK-20260828-02` “宽入口、窄承接”素材 A/B

- 状态：`active`（以 A/B 测试方式执行）
- 路由：`tiktok-content-system`。
- 触发：精准产品开场转化尚可，但曝光、停留或消耗持续受限；且产品事实卡、素材质量已通过。
- 输入：同一 SKU、同一核心卖点、两个仅入口不同的版本，以及同口径曝光、观看/停留、点击、点击后转化、订单和投产数据。
- A 版：直接进入目标用户的产品问题与解决方案。
- B 版：前几秒从相邻场景、情绪或更广人群进入，随后明确桥接回产品问题与卖点。
- 判断：B 版只有在扩大有效观看/点击的同时，不显著损害点击后转化、订单质量、投产和评论相关性，才算胜出。
- 检查：广入口与后续产品承诺必须语义相关；不得用与产品无关的猎奇片段骗停留。
- 停止：出现“高播放低有效点击”、负面误解、违规风险、受众严重错配或承接断裂，立即停 B 版；不得把“素材必须打泛”变成全局规则。

### `K-TK-20260828-03` 差异化命题矩阵

- 状态：`active`
- 路由：内容与商品运营共同使用。
- 触发：同类素材卖点高度同质、点击或转化弱，且基础商品事实已完整。
- 输入：SKU 事实卡、竞品公开卖点样本、用户问题、使用步骤、合规边界。
- 执行：按四层寻找真实差异：产品/成分概念、使用方式、便利性/体验结果、素材定位/叙事视角；每个候选都要回指事实证据。
- 判断：优先选择用户能感知、能演示、能验证、与购买障碍相关的差异，不把“新词”本身当差异。
- 检查：真实产品锁定、功效证据、平台合规、竞品表达去重、用户问题关联性。
- 停止：如果差异只能靠夸大效果、偷换健康概念、隐去限制或照搬竞品资产，就判废；“专属流量坑位”不作为可验证结果。

### `K-TK-20260828-04` 候选池—最小测试—淘汰

- 状态：`active`
- 路由：`tiktok-commerce-operations/modules/selection-engine`。
- 触发：团队反复在单个弱品上改图、改标题、加广告，但缺少早期正向数据。
- 输入：市场机会、店内适配、供货/合规、达人内容可表达性、最小测试结果。
- 执行：观察正在增长的新款和低资源店铺中的小爆品作为线索；建立多个候选；先做最小验证；按同口径数据保留、复测或淘汰。
- 判断：把“筛选质量”和“后端优化质量”分开。产品未通过基础需求验证时，不允许用无限 Listing/广告调整掩盖选品问题。
- 检查：候选来源、产品差异、供应约束、真实图片/属性、测试窗口与停止线都要记录。
- 停止：达到项目预先定义的测试窗口仍无最低需求证据，停止继续雕花；但不得采用视频中的“每天十个、先上三百个”作为默认数量。
- 合规：观察公开市场信号不等于复制标题、图片、商标、专利、评论或受保护表达。

### `K-TK-20260828-05` 付费投流/ECPM 因果检查表

- 状态：因果诊断框架为 `active`；精确 ECPM 公式、权重、阈值和赛马机制为 `needs_reconfirm`
- 路由：广告数据诊断参考，不作为官方公式。
- 触发：广告出现花不出去、消耗异常、ROI/投产弱或素材衰减，需要整理假设时。
- 输入：当前平台可取得的竞价、曝光、内容点击、点击后转化、订单、素材版本和产品数据。
- 执行：把问题拆成竞价条件、预估点击倾向、预估转化倾向和同场竞争四类；分别追查产品、内容和承接证据。
- 判断：来源只支持“Bid、预估点击、预估转化共同影响竞争力”的简化解释；具体公式、权重和赛马机制必须查当前官方资料或真实账户数据。
- 检查：内容点击与 Listing 点击、内容转化与商品承接不得混为同一指标；指标口径必须在项目内统一。
- 停止：没有当前平台定义或账户证据时，不输出确定公式、阈值或“同行高低”结论。
- 与现行规则的冲突：来源把价格列为转化优化项；用户现行 `COM-004` 明确价格、折扣、优惠券、促销和补贴永久排除出 Listing 诊断，因此该分支直接拒绝。

### `K-TK-20260828-06` 受控素材/商品组合量

- 状态：`active`（以可归因组合测试执行）
- 路由：内容生产组合与选品测试池。
- 触发：少量版本无法覆盖主要人群、卖点和钩子假设，或偶然性太强，难以复盘。
- 输入：唯一假设 ID、SKU 事实卡、版本差异、去重规则、测试预算/时间、回填数据。
- 执行：先做“不同假设的组合量”，而不是“相同内容的重复量”；结构化生成后做人工事实、重复、质量与合规检查；定期按数据淘汰并复用胜出机制。
- 判断：产量的价值等于新增可区分假设和学习速度。无法说明某版本比上一版多验证了什么，就不应生产。
- 检查：重复度、事实一致性、素材质量、链接/商品唯一性、平台限制和人力承载。
- 停止：出现重复铺货、随机拼装错误、质量下降、无法归因或平台风险时停止扩量。
- 拒绝迁移：视频中的“前 50/100/500 UV”“每天一百多条链接”“几十万条视频”和 API/插件限流断言，全部保留为来源个案，不作为本系统阈值或平台事实。

### `K-TK-20260828-07` 痒点五式的伦理化使用

- 状态：`active`
- 路由：`tiktok-content-system` 的钩子和文案候选工具。
- 低风险候选：
  - 差一点：指出用户已有基础与一个真实缺口；必须有证据，不能伪造“你已经快成功”。
  - 预拥有：用具体场景让用户预演使用后的生活；产品是道具，用户是主角；结果必须可实现。
  - 身份痒：把产品连接到用户愿意表达的身份/态度；不制造阶层羞辱或虚假权威。
- 条件使用：
  - 神秘痒：允许真实留白、反差和好奇；关键信息、限制和风险不能隐藏，不得用虚假敏感提示骗人点击。
  - 亏欠痒：默认高风险、非首选。只有在不恐吓、不羞辱、不道德绑架且能真实帮助用户关怀对象时，才可提出候选；母婴、健康、老人等高敏领域进一步收紧。
- 检查：真实性、可证实性、用户尊严、产品关联、平台政策、是否利用脆弱群体。
- 停止：假稀缺、伪造库存/人数、内疚操纵、恐惧威胁、健康功效暗示、身份歧视、隐瞒关键条件，任一出现即判废。

## 去重与路由结果

- 没有新建“ECPM Skill”“痒点 Skill”“差异化 Skill”“千川 Skill”或“铺量 Skill”。这些都是现有 TikTok 内容/商品工作系统的内部活动方法，不具备独立 Skill 的必要性。
- 与已有“对标与仿写、真实产品锁定、选品引擎、广告诊断、内容复盘”重叠的部分只做补充，不复制既有流程。
- 7 个方法单元都包含触发、输入、执行、判断、检查和停止条件，并已通过 `COM-009` 接入活动 Skill；只在触发条件匹配时使用，不是每项任务全部套用。

## 自动调用与后续验证

用户已确认这些边界化方法进入相关主 Skill 自动调用。后续每次使用仍必须满足：

1. 当前情境符合方法触发；精确平台公式和时效事实另行核实。
2. 能说明适用 SKU、市场、内容模式和测试窗口。
3. 有反例和停止条件，不依赖绝对化口号。
4. 不与 `COM-004`、`COM-005`、内容真实产品门禁及其他活动规则冲突。
5. 真实结果回写后，根据反例继续收紧、修订或废弃；不能因一次胜出扩大为所有 SKU 默认。
