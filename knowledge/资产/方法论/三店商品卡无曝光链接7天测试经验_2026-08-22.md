## 本轮经验

### 1. 无曝光链接先看“是否被激活”，不能直接看转化

诊断顺序应固定为：

`是否有曝光 → CTR → 加购 → 订单/点击后订单率`

- 0 曝光时，CTR 和 CVR 不存在，不能把它们写成 0% 后继续诊断主图或详情。
- 有曝光但 0 点击时，才进入标题相关性与主图吸引力诊断。
- 有点击后，才看加购和订单；点击量很小不得强判详情成功或失败。

### 2. 标题类型没有通用赢家，产品语义比标签更重要

- B 搜索标题在 Sudocrem 和 Hitam Rambut 上都提高了 CTR，但当前没有订单。
- C 转化标题在 Sudocrem 产生 2 单，并让 Korper 从 0 曝光变成 51 曝光；但在 Hitam Rambut 上只有 57 曝光。
- 因此“搜索标题拉流量、转化标题拉成交”只能作为本轮方向性观察，不能作为跨 SKU 固定规则。
- 下一轮应保留真正起作用的词组，而不是只复制“B”或“C”标签。

### 3. 三种标题都为0曝光时，先停止内容归因

Carlight 的 A/B/C 三版均为 0 曝光。此时继续写更多标题无法证明有效，先按以下顺序排查：

1. 发布和审核状态；
2. 前台搜索是否可见、Product ID 是否可访问；
3. 类目是否准确；
4. 必填属性和变体是否完整；
5. 库存是否可售；
6. 标题是否包含准确的类目词；
7. 主图和详情是否完整、合规。

只有恢复曝光后，才重新进入 CTR 和 CVR 诊断。

### 4. 从0曝光到有曝光但0点击时，下一轮固定标题只改主图

Korper C 获得 51 曝光但 0 点击，而 A/B 仍为 0 曝光。下一轮应：

- 保持 C 标题不变；
- 保持详情不变；
- 只优化真实主图；
- 主图精确保留包装、Logo、瓶型、颜色、`650ml` 和刷头；
- 突出产品主体、容量、刷头和 `Dashboard / Jok / Sofa` 使用场景；
- 禁止生成模型重画包装或伪造前后对比。

### 5. 一单和零单都可能只是小样本噪声

- Sudocrem C 的 2 单来自 12 次点击；DRYMR A 的 1 单来自 3 次点击。
- 这些结果可以产生候选赢家，但不能直接全量复制。
- 候选操作门槛：点击少于 30 时只做方向判断；30 次点击只是最低观察门槛，不等于统计显著。
- 最少要做一次链接位次互换复测：标题换到另一条链接，主图、详情和其他非价格条件保持一致。

### 6. 7天汇总重复行必须去重，空白不能补0

- 同一链接 D1/D2/D3 三行是同一份 7 天汇总，求和会把所有指标放大 3 倍。
- 去重键为 `店铺 + SKU + 标题版本 + 链接`。
- 核心字段全部空白时标记 `unknown/未回传`；只有后台明确给出数字 0 才视为真实 0。
- 百分比不能求和；来源占比异常时隔离该字段，保留原始曝光、点击、加购和订单。

## 下一轮候选执行协议

### 触发

- 新链接原本无曝光，已完成一轮 A/B/C 标题测试；或已有 7 天曝光、点击、加购、订单数据。

### 执行

1. 按链接去重并核对统计窗口；
2. 先区分缺失与真实 0；
3. 同店铺、同 SKU 内比较 A/B/C，不跨产品比赢家；
4. 0 曝光先做资格/索引排查；
5. 有曝光无点击时固定标题测试主图；
6. 有点击后才诊断详情；
7. 每条每轮只改一个主模块并观察完整 7 天。

### 判断

- `曝光=0`：未激活，CTR/CVR不判断。
- `曝光>0、点击=0`：标题匹配或主图吸引力为下一层问题；如同组只有某标题获得曝光，优先固定该标题测试主图。
- `点击<30`：仅输出候选结论。
- `点击>=30、CTR有改善但加购/订单持续弱`：再进入详情、属性、规格/变体、包装内容、用法和信任诊断。

### 检查

- 是否把 7 天值重复相加；
- 是否把缺失当 0；
- 是否同时改了标题、主图和详情；
- 是否把链接初始权重误归因给标题；
- 是否让包装、Logo、颜色、容量、数量或配件漂移；
- 是否引入价格或促销因素。

### 停止

- Product ID、发布、索引、类目、必填属性或库存可售状态未通过时，停止内容归因。
- 核心数据未回传时，停止评分和赢家判断。
- 一轮结果没有完成链接位次复测时，停止升级为长期规则。

### 复盘

- 复测后比较绝对曝光、CTR、加购、订单和点击后订单率，同时保留样本量。
- 同一标题在换链接位次后再次胜出，才从“候选”升级为“较可信经验”。
- 至少在多个 SKU 重复成立后，才考虑注册为活动规则。
