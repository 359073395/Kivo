# 案例、反例与迁移边界

> 以下均为现代迁移示例或风险反例，不是原著原话，也不证明历史结论可直接复制。

## 一、同一方法在不同场景的正确迁移

| 场景 | 先调查的事实 | 当前可检验假设 | 小行动与停止条件 | 执行交接 |
|---|---|---|---|---|
| TikTok 商品无曝光 | 收录、合规、类目、库存、曝光漏斗 | 当前瓶颈是收录/合规，而非主图 | 修一个 SKU 的违规/收录项；平台风险或无可观测变化即停 | `tiktok-commerce-operations` |
| 商品有曝光无点击 | 展示量、主图、标题、价格带、竞品 | 当前瓶颈是第一屏价值表达 | 只改主图或标题一个变量；达到样本窗后比较 | `tiktok-commerce-operations` |
| 短视频完播低 | 前三秒、目标人群、口播节奏、素材承诺 | 开头没有快速呈现问题与收益 | 测 2–3 个开头；低于止损线或样本不足不放大 | `tiktok-content-system` |
| 达人合作 | 达人内容匹配、历史成交、佣金、授权、样品成本 | 某类中腰部达人更适合当前 SKU | 小批建联；越过合规、授权或成本上限即停 | `tiktok-creator-outreach` |
| 个人 IP 定位 | 用户问题、已有信任、差异资产、承接路径 | 一个窄主题能同时形成关注与咨询 | 连续发布一个最小系列；指标无改善则回查定位 | `ip-commerce-decision-system` |
| 学习一本长书 | 版本、目录、原文、解释层、现实任务 | 某方法能改善一个具体决策 | 先完整文字化并做一个小试；无可检验动作不升格 | `knowledge-distillation` |
| 大额生活购买 | 真实频率、预算、替代、退换和维护成本 | 需求缺口大于情绪冲动 | 试用/租用或设冷静期；越预算和不可退即停 | 当前对话＋必要的专业证据 |

## 二、强反例：看似在用方法，实际不可检验

| 错误做法 | 为什么失败 | 应改成 |
|---|---|---|
| 结果不好就说“主要矛盾变了” | 事后改写，永远无法被证伪 | 事前列候选、排序依据、反转信号和复核日 |
| 看到一个爆款就“验证放大” | 单次偶然、流量来源和样本量未知 | 先定义成功阈值、重复次数、预算上限和衰减信号 |
| 把趋势/风口当必胜原因 | 趋势不等于可获取需求、利润或自身能力 | 同时检查需求、竞争、合规、履约、现金流和本地小试 |
| “整合高手胜过一百个普通人” | 忽略适配、治理、议价、知识转移和单点依赖 | 写贡献、权利、资产归属、替代方案和退出条件 |
| “三个月人人都能成专家” | 无能力基线、领域难度和验收标准 | 定义一个可观察能力，分阶段训练和外部测评 |
| 用历史胜利证明企业策略 | 类比无法证明因果和制度可迁移 | 只抽取资源/阶段/信息机制，并用现代数据验证 |
| 坚持就是持久战 | 会合理化沉没成本 | 每阶段写继续、调整、退出阈值和最大损失 |
| 把相关方分成“敌我” | 容易去人格化并绕过合法、公平边界 | 按可观察利益、约束、决策权分支持/中立/阻碍点 |
| 先下结论再找材料 | 调查变成证明既有立场 | 同时登记支持证据、反证、未知和替代解释 |
| 用哲学术语替代专业判断 | 无法处理时效性强的法规、医学和财务事实 | 调用当前领域证据/Skill，方法论只负责提问与审计 |
| 为不可逆人生决定强行设计“最小试点” | 试点不能回读最终承诺后果，会制造虚假确定感 | 改做硬门禁、承重假设、反例/最坏情形、选择权保留和承诺前否决/延迟信号；价值与最终承诺由用户决定 |

## 三、不可直接迁移的内容

- 特定战争中的兵力、作战、惩罚、强制、保密和组织动作。
- 特定革命时期的阶级、敌我和政治动员分类。
- 课程讲者的投资、升迁、关系、创业或涨粉轶事及成功率宣称。
- 历史人物动机、私人生活和因果故事，除非另有可靠史料且当前任务确实需要。
- “万物联系”“新事物必胜”“方向正确就一定成功”等不可证伪口号。

## 四、硬门禁优先级

1. 人身安全、法律、平台规则、隐私与授权；
2. 现金流、库存、健康与家庭不可承受损失；
3. 证据完整性、测量可靠性与可逆性；
4. 之后才比较主要矛盾、阶段、资源集中与放大。

任何方法卡若与硬门禁冲突，立即停止并交给对应专业规则；不得用“特殊阶段”“抓重点”或“为了长期目标”越过门禁。
