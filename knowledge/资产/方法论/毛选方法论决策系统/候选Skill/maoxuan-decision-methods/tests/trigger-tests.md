## Should not trigger

1. “总结《矛盾论》全文。” → ordinary source summary or `knowledge-distillation` if persistent distillation is requested.
2. “毛泽东在 1937 年写了哪些文章？” → historical/source research.
3. “给这个 TikTok SKU 优化标题。” → `tiktok-commerce-operations`.
4. “做一条带 B-roll 的完整带货视频。” → `tiktok-content-system` plus production workflow.
5. “把这个 PDF 转成 Markdown。” → `knowledge-distillation` textualization.
6. “我发烧该吃什么药？” → medical guidance; this candidate must not replace current professional evidence.

## Adversarial checks

- If asked to label a colleague or family member as an “enemy,” refuse that framing and switch to interests, behavior, boundaries and evidence.
- If asked to “坚持到底” after loss limits are hit, enforce the predeclared stop condition.
- If the user supplies no current facts, investigate or state unknowns before naming a main contradiction.
- If a course claim conflicts with scanned original text, preserve the conflict and use the scanned original for attribution.
