# Mao Selected Works Decision Methods

> Candidate only. This copy is not an active Skill and must not be installed or implicitly invoked until its trigger tests, source audit and user confirmation pass.

This Skill transfers abstract methods, not historical political, military or interpersonal labels. It turns “what should I do?” into a falsifiable decision protocol.

## Resolve and read

Find the nearest `knowledge-base.json` and treat its directory as `vault_root`. Never depend on an old computer's absolute paths.

Read before analysis:

- `references/source-policy.md` for evidence levels and safety boundaries;
- `references/method-cards.md` for the nine candidate methods;
- `references/domain-handoff.md` when the decision concerns IP, e-commerce or TikTok operations.

## Trigger boundary

Use this candidate only when the user explicitly requests this methodology or names one of its distinctive methods. Route source learning, book/video/PDF distillation and Skill creation to `knowledge-distillation`. Route historical questions to ordinary source research. Route routine domain execution directly to the relevant active domain Skill.

## Decision protocol

1. Define the decision owner, objective, time horizon, affected people and irreversible risks.
2. Separate verified facts, user reports, assumptions, interpretations, unknowns and current hard constraints.
3. If decisive facts are missing, run the investigation card first; do not manufacture a diagnosis.
4. List competing problem definitions. Select the current main contradiction only after safety, legality, platform policy and cash-flow gates.
5. Choose the smallest applicable set of method cards. State why each applies and why nearby cards do not.
6. Produce at least two feasible options plus a safe default or stop/do-nothing option where relevant.
7. Select a staged action: owner, resources, first reversible test, observation window, prediction, success signal, failure signal and stop condition.
8. Before action, record alternative explanations so the result cannot be rationalized after the fact.
9. After results, distinguish diagnosis error, execution error and changed conditions. The result creates a candidate lesson only; never silently upgrades a long-term rule.

## Required output

Return:

- fact sheet and unknowns;
- candidate contradictions and selected main contradiction;
- applicable method cards with source level;
- recommendation, rejected alternatives and staged execution;
- measurable checks, review date, failure signals and stop conditions;
- domain handoff, if operational execution belongs to another Skill.

## Hard boundaries

- Never transfer historical military acts, coercion, punishment or enemy labels into business, family, friendship or daily life.
- Treat “main contradiction” as a revisable resource-priority hypothesis, not a license to ignore other risks.
- Treat “protracted” as staged validation, not permission for endless sunk-cost spending.
- Do not replace current law, medicine, finance, platform policy or qualified professional review.
- Do not present course commentary, OCR text or AI migration as original quotations.
- Stop and request current domain facts when the decision could materially change but the evidence is missing.
