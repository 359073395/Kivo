# 概念与术语索引

> 本文件只用于来源追溯和内部索引。面向用户的第一性原理模块禁止输出概念阐述，只执行 `IP-004` 的三个固定检查点。

## 来源追溯术语

| 术语 | 本系统定义 | 防误用边界 |
|---|---|---|
| 第一性原理 | 在当前决策层级审计惯例、经验和未经验证假设，回到可验证事实、硬约束、激励和目标，重新推导并验证 | 不保证正确，不等于所有事情从零开始 |
| 承重假设 | 一旦为假，会改变方案排序、关键动作或风险判断的前提 | 不审计无关细节，不为质疑而质疑 |
| 底层拆解 | 拆到足以改变可选动作或可验证预测的目标、因果、资源、成本、约束、激励和变量 | “底层”相对于当前决策，不宣称终极真理 |
| 方案重构 | 从已确认事实、约束、激励和目标重新组合方案 | 不是旧模板换词或只调一个参数 |
| 最小判别性验证 | 用最低合理成本区分关键假设/方案，并事前规定会怎样更新决策 | 不是只求“跑一个小测试”，必须能证伪 |
| 验证修正 | 比较事前预测与实际，定位数据、执行、假设、模型、优先级或目标偏差 | 不用事后叙事把失败合理化 |
| 主要矛盾 | 当前阶段最制约目标、解决后最可能改变结果的核心矛盾/瓶颈 | 不是永恒唯一原因，阶段变化后重判 |

## 来源课程常用概念

| 术语 | 课程大意 | 当前状态 |
|---|---|---|
| 类比思维 | 参考他人、先例或过去经验快速决策 | 中性工具；低风险/稳定任务可用 |
| “一”战略 | 课程用来指组织或个人最核心、统一的战略原则 | `source_view`；不同案例含义可能变化，不能当统一活动规则 |
| 隐含假设 | 未被看见却支撑当前做法的默认前提 | 可用于候选审计 |
| 公理思维 | 从少数前提出发进行演绎 | 前提错误会导致系统性错误，需现实检验 |
| 归纳法 | 从经验观察总结规律 | 结论受样本、条件与时效限制 |
| 演绎法 | 从前提经逻辑推出结论 | 逻辑有效不等于前提真实 |
| 本体论 | 课程中的哲学追问路径 | 只作背景，不直接驱动业务动作 |
| What/How/Why | 课程用来拆解产物、路径和动机/使命 | 可作提问框架，不替代证据和目标权衡 |
| 破—立—推 | 课程对打破旧前提、建立新前提并演绎的表达 | `source_view`；不得替代 `IP-004` 三检查点 |
| “越来越”效应 | 课程描述网络、反馈或累积优势的表达 | 只作为可能的反馈结构；没有当前数据时不得断言存在，更不能据此淘汰非网络业务 |
| 逻辑比现实更真实 | 课程反复出现的哲学立场 | `rejected_as_rule`；逻辑只产生条件性预测，现实反馈优先修正模型 |
| 基石假设/公理 | 课程对承载后续推导的少数前提的称呼 | 在业务中仍是硬约束、价值边界或待验证假设；名称不授予真实性 |
| 机械论/进化论 | 课程分别用来说明可分解预测和适应选择的世界观 | `source_view`；不能固定映射为管理/创新，也不能替代当前系统证据 |

## 知识状态术语

- `active`：范围明确且已由用户确认/真实验证，可在触发时自动使用。
- `active_project`：只在指定项目、SKU、批次或时间范围自动使用。
- `candidate_method`：有来源与可执行结构，但尚缺用户确认或真实复用。
- `candidate_test`：只能作为清楚标注的测试假设。
- `source_view`：只代表作者/讲者说法。
- `conflict_pending_user`：同等级冲突会改变执行，现有权威无法裁决，等待用户。
- `rejected_as_rule`：保留追溯，但禁止自动执行。
